# VEP Recommendation

**Date:** 2026-06-23T08:59:45.699318

## User Query
Prioritize rare protein-altering variants in a patient with a suspected Mendelian disorder.

## Recommendation
### 1. Detected Use Case
**Category:** `rare_disease_germline`
**Reason:** The user's goal is to identify pathogenic variants in a patient with a Mendelian disorder. This requires high-sensitivity annotations including population frequency (to ensure rarity), pathogenicity predictors (to assess protein impact), and clinical database comparisons (ClinVar/Phenotype) to link variants to disease.

### 2. Recommended Options
✓ **transcript_set** [source: transcript_set, priority=critical] confidence: high
  Reason: Using the default Ensembl/GENCODE set provides the most comprehensive annotation required for medical decisions.

✓ **mane_select** [source: mane_select, priority=recommended] confidence: high
  Reason: Reduces redundancy by focusing on a single representative transcript (MANE Select), which is standard practice in clinical interpretation.

✓ **canonical** [source: canonical, priority=recommended] confidence: high
  Reason: Helps identify the primary transcript version, aiding in the prioritization of likely functional variants.

✓ **sift** [source: sift b, priority=critical] confidence: high
  Reason: Essential tool for predicting the impact of amino acid substitutions on protein function in a germline context.

✓ **polyphen** [source: polyphen b, priority=critical] confidence: high
  Reason: Critical for human species analysis to assess the structural and functional impact of missense variants.

✓ **cadd** [source: cadd, priority=recommended] confidence: medium
  Reason: Provides an integrated score across multiple annotations to help rank potentially deleterious variants.

✓ **alphamissense** [source: alphamissense, priority=recommended] confidence: high
  Reason: State-of-the-art AI-based predictor for missense pathogenicity in humans (GRCh38).

✓ **revel** [source: revel, priority=optional] confidence: medium
  Reason: An ensemble method that provides highly reliable pathogenicity predictions for exonic variants.

✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Essential to check if the identified variant has been previously reported with a known clinical significance.

✓ **check_existing** [source: check_existing, priority=critical] confidence: high
  Reason: Allows for identification of known variants (rsIDs) and existing clinical annotations.

✓ **gnomad_af** [source: gnomad_af, priority=critical] confidence: high
  Reason: Crucial for filtering out common variants; Mendelian disease variants must be extremely rare in the population.

✓ **spliceai** [source: spliceai, priority=recommended] confidence: medium
  Reason: Essential for finding variants that might not look like "missense" at the DNA level but cause protein-altering effects via splicing disruption.

✓ **hgvs** [source: hgvs, priority=critical] confidence: high
  Reason: Required for standardized clinical reporting of variant nomenclature (c. and p. notation).

✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Provides readable gene names (e.g., *BRCA1*) instead of Ensembl IDs, which is vital for phenotype correlation.

✓ **domains** [source: domains, priority=recommended] confidence: medium
  Reason: Adds context regarding whether a mutation falls within a known functional protein domain.

✓ **gene_phenotype** [source: gene_phenotype, priority=recommended] confidence: high
  Reason: Links the variant to known diseases and phenotypes (e.g., OMIM), directly assisting in Mendelian disorder diagnosis.

✗ **pick** [source: pick] confidence: medium
  Reason: Disabled to allow for manual review of all relevant transcripts; strict filtering is better handled during downstream analysis.

✗ **per_gene** [source: per_gene] confidence: high
  Reason: Disabled because we need to see all transcript-level consequences (e.g., a variant might be missense in one transcript and synonymous in another).

✗ **most_severe** [source: most_severe] confidence: high
  Reason: Incompatible with the required pathogenicity predictors (SIFT, PolyPhen, HGVS) which require per-transcript data.

✗ **summary** [source: summary] confidence: high
  Reason: Incompatible with transcript-specific annotations; we need detailed data, not a collapsed view.

✗ **af_1kg** [source: af_1kg] confidence: high
  Reason: gnomAD is the more modern and comprehensive standard for human population frequency.

✗ **gnomad_sv** [source: gnomad_sv] confidence: high
  Reason: The focus is on protein-altering (SNV/Indel) variants, not structural variants.

✗ **regulatory** [source: regulatory] confidence: medium
  Reason: Excluded to reduce runtime; the primary investigation is focused on coding impacts rather than distal enhancers.

### 3. Generated VEP Command
```bash
vep --input_file patient_variants.vcf --output_file annotated_variants.txt --cache \
--transcript_set gencode_basic \
--mane_select \
--canonical \
--sift b \
--polyphen b \
--plugin CADD,snv=/path/to/SNVs.tsv.gz,indels=/path/to/InDels.tsv.gz \
--plugin AlphaMissense,file=/path/to/AlphaMissense_hg38.tsv.gz \
--plugin REVEL,file=/path/to/revel_scores.tsv.gz \
--check_existing \
--af_gnomade \
--plugin SpliceAI,snv=/path/to/spliceai_scores.vcf.gz,indel=/path/to/spliceai_scores.vcf.gz \
--hgvs \
--symbol \
--domains \
--gene_phenotype
```

**Note for Web Interface users:** When using the Ensembl VEP web interface, ensure you check the boxes for **MANE Select**, **SIFT**, **PolyPhen**, **ClinVar**, and **gnomAD**. For advanced plugins like CADD or SpliceAI, you must use the command-line version as the web interface has limited plugin support.
