### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to distinguish between protein-coding, miRNA, and other non-coding features.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most representative transcript for pathogenicity assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for identifying if these somatic mutations overlap with known mouse variation databases.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to drive the consequence calculation using the primary Ensembl annotation set.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Provides names of protein domains (Pfam, etc.) to help assess if a mutation hits a functional site.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized nomenclature for the identified variants, crucial for reporting.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for splice site impact, which is critical for pathogenicity assessment.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering context for the variant position.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: medium
  Reason: If mouse phenotype data is available in the Ensembl database, it aids in functional interpretation.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Explicitly requested to identify overlaps with promoters, enhancers, and other regulatory elements.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides a sequence-homology-based prediction of whether a missense mutation affects protein function in species with SIFT data (like mouse).
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make the output readable and interpretable for biological context.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option is incompatible with --hgvs, --sift, and --symbol, which are required for this detailed clinical assessment.

  Reason: ClinVar data is human-only.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only meta-resource.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --biotype --canonical --check_existing --core_type --domains --hgvs --maxentscan --numbers --phenotypes --regulatory --sift [b|p|s] --symbol
```
*(Note: For the `--sift` flag, you must choose a mode: `b` for banal, `p` for possibly damaging, or `s` for significant/damaging. In web interface, this is selected via a dropdown.)*
