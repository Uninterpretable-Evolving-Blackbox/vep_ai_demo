- **region_focus**: coding, regulatory-noncoding (explicitly requested both)
- **analysis_goal**: clinical-interpretation (preliminary pathogenicity assessment)

### 3. Generated VEP Command
```
vep --input_file input.vcf --output_file output.txt --cache --format vcf --everything --regulatory --sift --maxentscan --phenotypes --plugin NMD --symbol --hgvs --protein --canonical --domains --biotype --numbers
```
*(Note: `--everything` is a shortcut, but for precision in a command line, the individual flags for symbol, hgvs, protein, canonical, domains, biotype, numbers, sift, maxentscan, phenotypes, and regulatory should be used. In the web interface, ensure "Regulatory" and "Plugins" are specifically selected.)*
