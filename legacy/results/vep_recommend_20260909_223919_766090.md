## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard and recommended approach for driving consequence calculations in human studies.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for a "top-line call" as it adds HGNC gene symbols (e.g., TP53) to make results human-readable.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps confirm if the disrupted regions are indeed protein-coding or other transcript types.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help gauge the reliability of the annotated transcripts.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Useful for identifying functionally important isoforms in the context of gene disruption.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNV/structural variant analysis to determine if the loss/gain of a gene dosage is clinically significant (e.g., via pHaplo scores).
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores which help assess the constraint of the gene being disrupted.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is useful for understanding the scale of disruption within a gene.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically recommended for structural variants to compare identified CNVs against known gnomAD structural variant frequencies.
✓ most_severe [source: most_severe, priority=optional] confidence: medium
  Reason: Since the user wants a "quick top-line call" and not an "exhaustive breakdown," this helps simplify the output to the most impactful consequence.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is designed for small-scale nucleotide changes; it is not applicable/useful for large-scale structural/CNV analysis.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is for missense (SNV) pathogenicity predictions and is not applicable to structural variants or CNVs.
✗ spliceai [source: spliceai] confidence: high
  Reason: This is a deep learning tool for predicting splice-site alterations in small variants, which is not the focus for CNV/structural analysis.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, disabling this allows the user to see if a structural variant disrupts a gene's regulatory architecture or non-coding regions which might indirectly affect coding output.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --tsl --appris --dosage_sensitivity --plugin LOEUF --numbers --custom gnomad_sv,path/to/gnomad_sv.vcf.gz,type=exact,overlap_cutoff=exact --most_severe
```
*Note: In the web interface, select "Ensembl" core, enable "Gene Symbol", "Transcript Support Level", "Biotype", "Dosage Sensitivity", and use the Custom tab to upload a gnomAD SV file.*
