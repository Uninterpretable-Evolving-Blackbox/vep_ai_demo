# VEP Recommendation

**Date:** 2026-09-15T09:44:09.325170

## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse model)
- **origin**: somatic (tumor tissue)
- **variant_size_class**: small (single letter changes and small additions/removals)
- **region_focus**: coding, regulatory-noncoding (impact on protein-coding and control regions)
- **analysis_goal**: clinical-interpretation (identifying drivers of tumor progression)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to use the Ensembl/GENCODE core annotation set for the mouse species to drive consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides gene symbols for easier biological interpretation of results.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature to help standardize the reporting of the identified changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and other features like lincRNA or miRNA in the regulatory regions.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Necessary to identify overlaps with regulatory regions (promoters, enhancers) as requested for control regions.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps assess the impact of coding variants by identifying if they fall within known protein domains.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides protein-level identifiers (ENSP) which is critical for interpreting protein-coding impacts.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to precisely localize the variants within the transcripts.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based conservation scores for missense variants available for this species.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Predicts the impact of variants on splice sites, which is important for both coding and regulatory regions.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link identified gene changes to known biological phenotypes.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if any of the identified changes have been previously cataloged in mouse variation databases.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Predicts if a variant might escape nonsense-mediated decay, helping to prioritize driver candidates.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is human-only; it will not provide data for a mouse model.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is human-only and not applicable to mouse sequencing.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ most_severe [source: most_severe] confidence: high
  Reason: Should be disabled to ensure the full range of consequences (coding and regulatory) is visible for driver identification.
✗ summary [source: summary] confidence: high
  Reason: Should be disabled to avoid losing detailed per-transcript and per-feature information.

### 3. Generated VEP Command
```
vep --input_file tumor_variants.vcf --output_file annotated_tumor_variants.txt --cache --symbol --hgvs --biotype --regulatory --domains --canonical --protein --numbers --sift --maxentscan --plugin Phenotypes --check_existing --plugin NMD
```
*Note: On the Ensembl VEP web interface, ensure you select the "Mouse" species and check the boxes for Symbol, HGVS, Biotype, Regulatory, Domains, Canonical, Protein, Numbers, SIFT, and MaxEntScan. The Phenotypes and NMD options are available via the "Plugins" section.*
