## User Query
somatic point mutations from a mouse tumour

## Recommendation
### 1. Detected Use Case
**non_human / somatic_cancer**: The analysis involves a non-human species (mouse) in a cancer context (identifying mutations in a tumor). This requires selecting tools compatible with *Mus musculus* and avoiding human-only databases like ClinVar, gnomAD, or AlphaMissense.

### 2. Recommended Options
✓ symbol [source: symbol, priority=recommended for all] confidence: high
  Reason: Adding HGNC/mouse gene symbols makes the results much more readable for identifying potential drivers.

✓ hgvs [source: hgvs, priority=recommended for non_human] confidence: high
  Reason: Provides standard nomenclature for variants which is essential for reporting DNA and protein changes.

✓ check_existing [source: check_existing, priority=critical for non_human] confidence: high
  Reason: Essential to see if the detected somatic mutations overlap with known mouse genetic variation or previously documented alleles.

✓ sift [source: sift, priority=recommended for non_human] confidence: high
  Reason: SIFT is available for mouse and helps predict whether amino acid substitutions are deleterious.

✓ domains [source: domains, priority=recommended for non_human] confidence: high
  Reason: Useful for identifying if a mutation falls within a known functional protein domain (e.g., kinase domain) in the mouse protein.

✓ biotype [source: biotype, priority=recommended for all] confidence: high
  Reason: Helps distinguish whether the mutation affects a protein-coding gene or a non-coding feature like lincRNA.

✓ canonical [source: canonical, priority=recommended for non_human] confidence: high
  Reason: Simplifies analysis by highlighting the primary transcript, which is helpful when not using MANE-specific transcripts.

✓ protein [source: protein, priority=optional for non_human] confidence: medium
  Reason: Provides Ensembl protein IDs (ENSP) which can be used to cross-reference mouse-specific proteomic databases.

✓ pick [source: pick, priority=recommended for quick_lookup/somatic] confidence: high
  Reason: Reduces redundancy by selecting one transcript per variant, making it easier to parse large tumor VCF files.

✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen-2 is a human-only prediction tool and will not work for mouse data.

✗ cadd [source: cadd] confidence: high
  Reason: CADD integration is restricted to human (GRCh37/38) datasets.

✗ alphamissense [source: alphamissense] confidence: high
  Reason: AlphaMissense predictions are currently only available for human sequences.

✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar clinical significance data is specifically provided for human variants in this VEP configuration.

✗ gnomad_af [source: af_gnomade] confidence: high
  Reason: gnomAD allele frequencies are restricted to human populations and are not applicable to mouse tumor analysis.

✗ revel [source: revel] confidence: high
  Reason: REVEL is an ensemble method optimized for human rare disease/somatic assessment.
