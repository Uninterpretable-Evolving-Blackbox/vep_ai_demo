## User Query
Mouse germline WGS, SNV and indel variants; rapid top-line functional annotation for protein-coding and regulatory regions.

- **species**: non-human (Mouse)

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --hgvs --biotype --canonical --regulatory --protein --domains --numbers --check_existing
```
*Note: On the Ensembl VEP Web Interface, select "Mouse" as the species, enable "Gene Symbol", "HGVS nomenclature", "Transcript biotype", "Canonical transcript", "Regulatory regions", "Protein ID", "Protein domains", and "Exon/intron numbering". Do not select any human-specific plugins like CADD, ClinVar, or gnomAD.*
