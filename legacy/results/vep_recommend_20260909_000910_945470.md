## User Query
I am analyzing somatic SNVs and indels from a mouse tumor WES to quickly identify any high-impact protein-coding variants.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor WES)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (protein-coding variants)
- **analysis_goal**: basic-consequence (quickly identify high-impact variants)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to use the Ensembl/GENCODE core annotation set to drive consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds the gene symbol to the output, which is critical for identifying the genes affected by the somatic variants.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, which is necessary for reporting and verifying the coding consequences of the SNVs and indels.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene, which is useful for a "quick" identification of impact.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP) to link results to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds transcript biotype, allowing you to confirm the variants are indeed hitting protein-coding transcripts.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is a key way to assess the "high-impact" nature of a coding variant.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, essential for localizing the variant within the coding sequence.
✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Since the goal is to focus on protein-coding variants, this restricts the output to relevant consequences.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled to avoid conflicts with --hgvs and --symbol, and to ensure full transcript detail is available for impact assessment.
✗ summary [source: summary] confidence: high
  Reason: Disabled to ensure detailed consequence information is provided rather than a collapsed summary.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: NOT APPLICABLE; gnomAD is human-only.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is human-only.
✗ polyphen [source: polyphen] confidence: high
  Reason: NOT APPLICABLE; PolyPhen is human-only.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is human-only.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --canonical --protein --biotype --domains --numbers --coding_only
```
*Note: Web interface equivalent involves selecting "Gene Symbol", "HGVS nomenclature", "Canonical transcript", "Protein ID", "Transcript biotype", "Protein domains", and "Exon/intron numbering" in the optional settings.*
