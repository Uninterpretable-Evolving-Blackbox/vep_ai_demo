### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is recommended for driving consequence calculations in human species.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making the results more human-readable for clinical/biological review.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to confirm the functional nature of the transcripts being impacted by the CNVs.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize high-confidence transcripts.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify the most functionally important isoforms (principal transcripts) for the coding regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is critical for mapping CNV boundaries within coding regions.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs; provides pHaplo and pCNV scores to assess if a gene is sensitive to copy number changes.
✓ frequency [source: frequency, priority=recommended] confidence: high
  Reason: Enables frequency-based filtering to assess how common these variants are in the population.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Adds gnomAD LOEUF scores, which help determine if the gene is tolerant to loss-of-function events.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically provides allele frequencies for structural variants from the gnomAD SV dataset, directly addressing the user's goal.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Enables the lookup of existing variant IDs (rsIDs) to see if the CNVs are already cataloged.
✓ clinvar [source: clinvar, priority=optional] confidence: medium
  Reason: Provides clinical significance data, which is helpful when reviewing germline results.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for short variants (SNVs/indels); not the priority for CNV-focused analysis.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a resource for missense variants; it is not applicable to structural CNVs.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, disabling this entirely might hide the exact genomic coordinates/boundaries of the CNV relative to the gene; it is better to use `biotype` or `symbol` to interpret results.
✗ most_severe [source: most_severe] confidence: high
  Reason: This flag conflicts with several other useful annotation flags like `symbol` and `tsl`.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --tsl --appris --numbers --plugin DosageSensitivity --plugin LOEUF --plugin ClinVar --check_existing --custom gnomad_sv,gnomad_sv.vcf.gz,exact
```
*Note: On the Ensembl Web Interface, ensure you select "Human" as the species and enable the "Dosage Sensitivity" and "gnomAD SV" plugins/datasets via the advanced options.*
