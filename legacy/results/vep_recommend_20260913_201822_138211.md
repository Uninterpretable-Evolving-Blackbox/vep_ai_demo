## User Query
I am analyzing genome sequencing from a mouse model to determine if any small spelling changes in protein-coding or gene control regions are likely causing the observed disease.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse model)
- **origin**: germline/implied (not specified as somatic, assuming model organism context)
- **variant_size_class**: small (spelling changes)
- **region_focus**: coding, regulatory-noncoding (protein-coding or gene control regions)
- **analysis_goal**: clinical-interpretation (determine if changes are likely causing observed disease)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set that drives consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making results much more human/researcher-readable.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature based on Ensembl identifiers for standardized reporting of coding/non-coding changes.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds names of overlapping protein matches/domains, useful for assessing impact on coding regions.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Necessary to identify overlaps with regulatory regions (promoters, enhancers) to assess "gene control" impacts.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds transcript/regulatory feature biotype (e.g., protein_coding, lincRNA) to provide context for the variant.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript, helping prioritize the most biologically relevant isoform for interpretation.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP), useful for linking coding variants to protein-level consequences.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Scores donor and acceptor splice sites, which is critical for assessing potential splicing disruption in coding/regulatory regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to localize variants within the gene structure.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves overlapping phenotype associations to help link variants to the "observed disease."
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides species-specific (mouse) sequence homology-based predictions for missense substitutions.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to check if the "spelling changes" are already catalogued in known mouse variation databases.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Predicts if a premature termination codon escapes nonsense-mediated decay, relevant for disease causation.
✓ uniprot [source: uniprot, priority=optional] confidence: medium
  Reason: Provides protein-level links to UniProt databases for functional context.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with hgvs, symbol, and sift; for clinical-style interpretation, you need full per-transcript detail rather than a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with most detailed annotation options; summary mode hides the granular data needed to assess disease causation.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is a human-specific clinical database.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: NOT APPLICABLE; gnomAD is human-only.
✗ polyphen [source: polyphen] confidence: high
  Reason: NOT APPLICABLE; PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is human-only.

### 3. Generated VEP Command
```
vep --input_file mouse_variants.vcf --output_file mouse_annotated.txt --cache --format vcf --vcf --symbol --hgvs --domains --regulatory --biotype --canonical --protein --maxentscan --numbers --phenotypes --sift --check_existing --plugin NMD --plugin UniProt
```
*Note: On the Ensembl Web Interface, ensure you select the mouse species and check the boxes for Symbol, HGVS, Domains, Regulatory, Biotype, Canonical, Protein, MaxEntScan, Numbers, Phenotypes, SIFT, and the NMD/UniProt plugins.*
