### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the biotype of the transcript or regulatory feature, which is essential for distinguishing between protein-coding, miRNA, and other elements in a top-line assessment.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most reliable transcript for the variant's consequence.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Ensures the use of the standard Ensembl/GENCODE annotation set to drive consequence calculations.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Provides names of overlapping protein domains, adding functional context to coding variants.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature for standardized reporting of the variant effects.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon and intron numbering (e.g., 7/27), which is critical for a basic functional overview.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to assess the impact on regulatory regions.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make the output human/animal-readable and easier to interpret.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP) to facilitate protein-level analysis.
✗ most_severe [source: most_severe] confidence: high
  Reason: This is a restrictive option that would hide the full breadth of consequences required for a "top-line" functional assessment, and it conflicts with several recommended options like hgvs and symbol.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: Human-only allele frequency data.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Human-only meta-resource.
✗ clinvar [source: clinvar] confidence: high
  Reason: Human-only clinical significance data.
✗ polyphen [source: polyphen] confidence: high
  Reason: Human-only pathogenicity predictor.
✗ cadd [source: cadd] confidence: high
  Reason: Human-only deleteriousness score.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --biotype --canonical --core_type --domains --hgvs --numbers --regulatory --symbol --protein
```
