### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --tsl --appris --regulatory --dosage_sensitivity --mane --biotype --numbers --plugin LOEUF --plugin Mastermind --plugin Phenotypes --plugin CADD --custom gnomad_sv,gnomAD_SV_VCF.vcf.gz,type=exact,overlap_cutoff=exact --check_existing --pubmed
```
*Note: In the web interface, ensure you select "Human" as the species and enable the "Regulatory" and "Dosage Sensitivity" plugins. For the `--custom` gnomAD SV flag, you must provide the path to the local gnomAD SV VCF file.*
