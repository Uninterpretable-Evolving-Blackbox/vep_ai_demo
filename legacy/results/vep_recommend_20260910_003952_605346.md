## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. ### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for identifying the type of transcript (e.g., protein_coding) being disrupted by the CNV.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Standard practice to use the Ensembl/GENCODE core annotation to drive consequence calculations for human coding regions.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs as it provides pHaplo scores to indicate if a gene is sensitive to dosage changes (e.g., haploinsufficiency).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variants to see if the observed CNVs appear in the gnomAD structural variant database.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which helps in visualizing the scope of the genomic disruption.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols, making the "top-line call" on disrupted genes human-readable and practical.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help prioritize results from high-confidence transcripts.
✓ appris [source: appris, priority=recommended] confidence: medium
  Reason: Helps identify functionally important isoforms, which is useful when determining which gene models are disrupted.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --tsl --appris --dosage_sensitivity --gnomad_sv --numbers --core_type
```
*Note: The `--gnomad_sv` flag requires the gnomAD SV custom VCF to be provided via `--custom`. On the Ensembl Web Interface, ensure "Gene Symbol", "Transcript Support Level", "Biotype", and "Dosage Sensitivity" are checked.*
