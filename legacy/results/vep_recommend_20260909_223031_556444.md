# VEP Recommendation

**Date:** 2026-09-09T22:30:31.556789

## User Query
I am currently processing a set of somatic mutations identified from mouse tumor sequencing to identify potential driver candidates in this model. We have a collection of SNVs and small indels derived from both WES and some supplemental WGS data, and I need to perform an initial, high-level annotation pass. The goal is to quickly categorize these variants based on their functional impact, specifically distinguishing between those falling within protein-coding sequences and those residing in regulatory or non-coding regions, so I can prioritize which mutations are worth more rigorous downstream analysis.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (specifically mouse)
- **origin**: somatic (derived from tumor sequencing)
- **variant_size_class**: small (SNVs and small indels)
- **region_focus**: coding, regulatory-noncoding (aiming to distinguish between these)
- **analysis_goal**: basic-consequence (initial, high-level annotation pass to categorize impact)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for providing the base Ensembl/GENCODE transcript/gene annotation driving the consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides gene symbols to help categorize variants into specific biological pathways/genes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Necessary to distinguish between protein-coding, lincRNA, and other transcript types for high-level categorization.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds standardized nomenclature for coding variants, useful for documenting driver candidates.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link coding variants to protein-level consequences.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize consequences on the most functionally relevant transcript.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically required to identify variants in regulatory regions (promoters, enhancers) as requested.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is critical for assessing the functional impact of coding mutations.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which helps localize variants within the gene structure.

  Reason: Conflicts with --hgvs, --symbol, and --domains; keeping full detail is better for identifying specific driver consequences.

  Reason: Collapses data; a high-level pass still requires the specific consequence details to distinguish coding from non-coding.

  Reason: NOT APPLICABLE; dbNSFP is human-only.

  Reason: NOT APPLICABLE; PolyPhen is human-only.

  Reason: NOT APPLICABLE; CADD is human-only.
✗ sift [source: sift] confidence: medium
  Reason: While available for some species, for an "initial, high-level pass" in mouse, it is optional; I have excluded it to prioritize speed as requested for a "quick" pass, but it could be added if SIFT data exists for the specific mouse assembly.

### 3. Generated VEP Command
```
vep --input_file somatic_mouse.vcf --output_file annotation_output.txt --cache --format vcf --vcf --symbol --hgvs --biotype --protein --canonical --regulatory --domains --numbers
```
*Note: On the Ensembl Web Interface, ensure you select the mouse genome assembly and check the boxes for Symbol, HGVS, Biotype, Protein, Canonical, Regulatory, Domains, and Numbers.*
