# VEP Recommendation

**Date:** 2026-09-15T11:26:21.286422

## User Query
I am working with whole exome sequencing data from a cohort of zebrafish tumor models where I have identified several somatic SNVs and small indels by comparing the tumor DNA to matched germline samples. My primary goal is to identify which of these mutations in the protein-coding regions are likely to be pathogenic, so I need a way to assess their potential impact on the amino acid sequence and overall protein function to help prioritize candidate driver mutations for further study.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Zebrafish/Danio rerio)
- **origin**: somatic (Comparing tumor DNA to matched germline)
- **variant_size_class**: small (SNVs and small indels)
- **region_focus**: coding (Protein-coding regions)
- **analysis_goal**: clinical-interpretation (Identifying pathogenic driver mutations to prioritize candidates)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Standard requirement to drive consequence calculation using Ensembl/GENCODE annotations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, essential for identifying candidate driver genes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized nomenclature for the amino acid changes, necessary for reporting and downstream study.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Confirms the transcript type (e.g., protein_coding), ensuring the focus remains on functional coding regions.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene to simplify driver identification.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level consequences.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is critical for localizing the impact within the coding sequence.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: SIFT is available for species with variation data like zebrafish and helps predict the impact of amino acid substitutions.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Identifies if a mutation hits a known protein domain (e.g., Pfam), which is vital for assessing driver potential.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves overlapping phenotype associations to help link mutations to biological functions/diseases.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Checks for known variants in zebrafish to see if the mutation has been previously recorded.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Useful for assessing the impact of small indels on splice sites, which can affect coding sequences.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Predicts if a mutation leads to nonsense-mediated decay, a key mechanism for loss-of-function drivers.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only resource and is not applicable to zebrafish.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only database.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this allows for per-transcript detail, which is necessary for a thorough driver analysis rather than a collapsed summary.
✗ summary [source: summary] confidence: high
  Reason: Disabling this ensures full annotation detail is available for each variant.

### 3. Generated VEP Command
```
vep --input_file zebrafish_somatic.vcf --output_file zebrafish_annotated.txt --cache --format vcf --vcf --symbol --hgvs --biotype --canonical --protein --numbers --sift --domains --phenotypes --check_existing --maxentscan --nmd
```
*Note: On the Ensembl Web Interface, ensure you select the zebrafish species and check the boxes for Symbol, HGVS, Canonical, Protein, SIFT, Domains, Phenotypes, and MaxEntScan, while ensuring human-specific plugins like PolyPhen or ClinVar are unchecked.*
