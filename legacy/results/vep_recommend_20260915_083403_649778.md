## User Query
I am starting to set up the pipeline for our human tumor-only whole genome sequencing data from a large cancer cohort, but I am still a bit unsure about how to best capture all the relevant information. We have identified several structural variants and copy number alterations, and my goal is to get a quick top-line summary of their functional consequences. Specifically, I need to see how these changes affect protein-coding regions—ideally identifying impacts on the most reliable transcripts—but I also want to capture any potential disruptions to regulatory or non-coding elements. Additionally, it would be really helpful if the results provided context regarding population allele frequencies so I can distinguish these somatic hits from common germline variation.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for driving consequence calculations using the Ensembl/GENCODE core annotation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols for human-readable results.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish if variants hit protein-coding genes, lincRNAs, or other regulatory elements.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps identify impacts on the most reliable/representative transcripts for a gene.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to capture disruptions to promoters, enhancers, and other regulatory elements.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically provides population allele frequencies for structural variants to distinguish somatic hits from germline variation.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: medium
  Reason: Highly relevant for CNVs to assess if the gene is sensitive to changes in copy number (e.g., pHaplo).
✓ tsl [source: tsl, priority=recommended] confidence: medium
  Reason: Adds Transcript Support Level to help assess the reliability of the annotated transcripts.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to identify if the SVs overlap known variants/IDs in databases.
✓ clinvar [source: clinvar, priority=optional] confidence: medium
  Reason: Provides clinical significance for known variants that may overlap with the structural changes.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily designed for small variants (SNVs/indels) and is not applicable/standard for structural variant/CNV description in this context.
✗ most_severe [source: most_severe] confidence: high
  Reason: The user requested a "summary" but also needs to see impacts on regulatory/non-coding elements; `most_severe` would collapse these nuances.
✗ summary [source: summary] confidence: high
  Reason: User wants to capture both coding and regulatory elements; `summary` mode collapses the output too aggressively.
✗ sift [source: sift] confidence: high
  Reason: Missense predictors are not applicable to structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: Missense predictors are not applicable to structural variants/CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are optimized for SNVs/indels and are not applicable to structural variants.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --plugin DosageSensitivity --plugin gnomad_sv --regulatory --symbol --biotype --canonical --tsl --check_existing --clinvar
```
*Note: On the Ensembl Web Interface, ensure you select "Human" as the species, check the "Regulatory" box, and use the "Plugins" section to add DosageSensitivity and gnomAD SV.*
