## User Query
I have somatic SNVs and indels from a mouse tumor. I need to identify the functional impact of both coding and regulatory variants for a preliminary pathogenicity assessment.

## Recommendation
### 1. Detected Scenario
- **species**: mouse (indicated by "mouse tumor")
- **origin**: somatic (indicated by "somatic SNVs and indels")
- **variant_size_class**: small (indicated by "SNVs and indels")
- **region_focus**: coding, regulatory-noncoding (indicated by "both coding and regulatory variants")
- **analysis_goal**: clinical-interpretation (indicated by "preliminary pathogenicity assessment")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to drive consequence calculation using the Ensembl/GENCODE core annotation set.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make results more interpretable for functional assessment.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard nomenclature for coding and non-coding variants, necessary for reporting.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with regulatory regions (promoters, enhancers) as requested.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on whether the hit is in a protein-coding gene, lincRNA, etc.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most representative transcript for functional impact assessment.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), useful for linking results to protein-level changes.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, critical for assessing the functional impact of coding mutations.

  Reason: Essential for predicting the impact of indels/variants on splice sites in a non-human context.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides species-specific (mouse) missense pathogenicity prediction.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves known phenotype associations for genes, aiding pathogenicity assessment.

  Reason: CADD is a human-only resource.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin MaxEntScan --plugin Phenotypes --plugin Domains --symbol --hgvs --regulatory --biotype --canonical --protein --sift --numbers --check_existing
```
*Note: In the Ensembl Web Interface, ensure you select "Mouse" as the species and enable the "Regulatory" and "Plugin" checkboxes for MaxEntScan, Phenotypes, and Domains.*
