## User Query
I am processing human germline sequencing data from a large-scale population cohort and have identified several large structural changes, such as deletions and duplications of DNA segments. I want to focus my analysis on these changes when they occur in regulatory regions that control gene activity, rather than just looking at the protein-coding parts of the genome. For these types of variations, I need to ensure my annotation process includes information on how common these changes are within the general population so I can identify which ones are truly rare.

- **origin**: germline (explicitly stated "human germline sequencing data")

- **region_focus**: regulatory-noncoding (stated "focus my analysis on these changes when they occur in regulatory regions... rather than just looking at the protein-coding parts")
- **analysis_goal**: population-frequency (stated "ensure my annotation process includes information on how common these changes are")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the Ensembl/GENCODE core annotation is the standard and recommended driving set for consequence calculation in this scenario.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: The user specifically requested to focus on regulatory regions that control gene activity.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Since the user is analyzing structural variants (CNVs) like deletions and duplications, dosage sensitivity (pHaplo/pCNV) is critical for understanding the impact of gene copy number changes.

✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Helps assess the functional constraint of genes, which is useful when interpreting the impact of large-scale germline variations.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for assessing the consequence of the structural change.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for identifying the nature of the regulatory elements or non-coding features being hit (e.g., lincRNA, enhancer).

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: The user's primary goal is population frequency for structural variants; this custom dataset provides the specific allele frequencies for CNVs from gnomAD.

✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Required to enable the retrieval of existing variant IDs and clinical significance (ClinVar) which helps in population-scale rarity assessment.

✓ clinvar [source: clinvar, priority=optional] confidence: medium
  Reason: Useful to cross-reference if the identified structural changes have been previously reported as pathogenic in population studies.

✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature for coding variants is not applicable to the focus on non-coding regulatory structural variants.

✗ coding_only [source: coding_only] confidence: high
  Reason: The user explicitly stated they do NOT want to focus solely on protein-coding parts.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is designed for missense (single nucleotide) variants, which are not the focus of this structural variant analysis.

✗ most_severe [source: most_severe] confidence: high
  Reason: This flag restricts output and conflicts with several useful annotations; for structural/regulatory analysis, full consequence transparency is preferred.
