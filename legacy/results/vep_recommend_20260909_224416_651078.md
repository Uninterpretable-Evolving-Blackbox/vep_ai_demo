  Reason: Required to drive consequence calculation using Ensembl/GENCODE annotations.

  Reason: Makes results more human-readable by adding HGNC gene symbols.

  Reason: Essential for structural variants to provide gnomAD SV allele frequencies to distinguish rare from common events.

  Reason: Crucial for CNV analysis to identify if the affected gene is sensitive to copy number changes (e.g., pHaplo).
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance for co-located variants, aiding clinical interpretation.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Necessary to identify co-located known variants and enable ClinVar/gnomAD/rsID reporting.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps in clinical interpretation by linking genes to known phenotype associations.
✓ cadd [source: cadd, priority=recommended] confidence: medium
  Reason: Provides integrated deleteriousness scores for interpreting the impact of variants.
✗ hgvs [source: hgvs] confidence: high
  Reason: Conflicts with the goal of analyzing structural/CNV variants where HGVS nomenclature for short variants is not the primary focus and often conflicts with summary/most_severe settings.
✗ sift [source: sift] confidence: high
  Reason: Missense predictors like SIFT are designed for single nucleotide variants, not structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: Missense predictors like PolyPhen are designed for single nucleotide variants, not structural variants/CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this ensures you see the full per-transcript detail needed to understand how a CNV or SV disrupts specific coding models.
✗ summary [source: summary] confidence: high
  Reason: Disabling this ensures you get detailed annotations rather than a collapsed summary, which is necessary for clinical assessment.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --check_existing --clinvar --phenotypes --cadd --plugin DosageSensitivity --custom gnomad_sv,gnomad_sv.vcf.gz,exact
```
*Note: For the `--custom` flag, you must provide the path to a local gnomAD SV VCF file. On the Ensembl Web Interface, enable "Gene Symbol", "Transcript Biotype", "ClinVar", "Phenotypes", "CADD", and use the "Custom" upload option for gnomAD SV.*
