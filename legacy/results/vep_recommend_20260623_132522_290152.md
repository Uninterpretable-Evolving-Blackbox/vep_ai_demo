  Reason: You need all available transcripts because a single variant can affect splice sites differently depending on the transcript's exon-intron boundaries.

  Reason: Using MANE Select transcripts provides a standardized, clinically relevant reference for reporting pathogenic variants in human studies.

✓ **canonical** [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most representative transcript for each gene.

✓ **sift** [source: sift] confidence: high
  Reason: Useful for providing context on whether exonic variants that are also missense are likely to be deleterious.

✓ **polyphen** [source: polyphen] confidence: high
  Reason: Provides complementary protein-level functional impact predictions for exonic variants.

✓ **cadd** [source: cadd, priority=recommended] confidence: high
  Reason: An integrated metric that helps score the overall deleteriousness of both coding and non-coding variants.

✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Crucial for identifying if the splice-interrupting variant has already been reported with clinical significance.

✓ **check_existing** [source: check_existing, priority=critical] confidence: high
  Reason: Necessary to cross-reference the variant with known IDs (like rsIDs) and ClinVar entries.

✓ **gnomad_af** [source: gnomad_af, priority=critical] confidence: high
  Reason: Essential for filtering out common variants; most pathogenic splice-altering variants are rare in the population.

✓ **spliceai** [source: spliceai, priority=recommended] confidence: high
  Reason: **CRITICAL.** This is the primary tool for your request; it uses deep learning to predict the impact of variants on splicing (acceptor/donor sites, etc.).

✓ **maxentscan** [source: maxentscan, priority=optional] confidence: high
  Reason: Provides a sequence-based comparison of splice site strengths, acting as a complementary tool to SpliceAI.

✓ **hgvs** [source: hgvs, priority=critical] confidence: high
  Reason: Essential for providing standard nomenclature (HGVSc/HGVSp) needed for clinical reporting and communication.

✓ **gene_phenotype** [source: gene_phenotype, priority=recommended] confidence: high

### 3. Generated VEP Command
```bash
vep --input_file variants.vcf --output_file annotated_variants.txt --cache \
--transcript_set gencode_basic \
--mane_select --canonical \
--sift b --polyphen b --cadd \
--check_existing --clinvar \
--af_gnomade \
--plugin SpliceAI,snv='/path/to/spliceai_snv.vcf.gz',indel='/path/to/spliceai_indel.vcf.gz' \
--plugin MaxEntScan,/path/to/maxentscan_data \
--hgvs --symbol --gene_phenotype
```

**Note:** To use the web interface, you should manually select **SpliceAI** and **MaxEntScan** in the "Plugins" section and ensure **MANE Select** is checked under "Transcript Selection."
