### 2. Recommended Options
✓ **core_type** [source: core_type, priority=critical] confidence: high
  Reason: Uses the standard Ensembl/GENCODE annotation set required for consistent clinical reporting.

✓ **hgvs** [source: hgvs, priority=critical] confidence: high
  Reason: Provides standardized nomenclature (e.g., p.Arg506Gln) essential for clinical communication and variant identification.

✓ **mane** [source: mane, priority=critical] confidence: high
  Reason: Filters results to MANE Select transcripts, providing a single, high-quality, clinically relevant transcript to reduce ambiguity.

✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Directly flags variants previously reported with clinical significance in ClinVar, which is the primary goal of this analysis.

✓ **check_existing** [source: check_existing, priority=recommended] confidence: high
  Reason: Essential to link input variants to known rsIDs and existing clinical databases.

✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols (e.g., BRCA1) to make the output interpretable for clinicians.

✓ **tsl** [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help assess the reliability of the transcript being analyzed.

✓ **domains** [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is crucial for interpreting the functional impact of missense mutations.

✓ **appris** [source: appris, priority=recommended] confidence: high
  Reason: Identifies the most functionally important isoforms (APPRIS) to focus clinical interpretation efforts.

✓ **sift** [source: sift, priority=recommended] confidence: high
  Reason: Provides a standard prediction of whether an amino acid substitution affects protein function.

✓ **polyphen** [source: polyphen, priority=recommended] confidence: high
  Reason: Complements SIFT with structural/functional impact predictions for missense variants.

✓ **cadd** [source: cadd, priority=recommended] confidence: high
  Reason: Provides an integrated score of deleteriousness across many types of genomic variation.

✓ **spliceai** [source: spliceai, priority=recommended] confidence: high
  Reason: Critical for exome analysis, as it detects variants that may cause aberrant splicing even if they are not at canonical sites.

✓ **alphamissense** [source: alphamissense, priority=recommended] confidence: high
  Reason: Adds state-of-the-art pathogenicity predictions from Google DeepMind's AlphaMissense model.

✓ **phenotypes** [source: phenotypes, priority=recommended] confidence: high
  Reason: Links genes to known clinical phenotypes, helping to connect a variant's effect to the patient's symptoms.

✓ **biotype** [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on whether the transcript is protein-coding or non-coding (useful for filtering).

✓ **numbers** [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon and intron numbering, which is highly useful for manual inspection and validating variants in literature.

✓ **coding_only** [source: coding_only, priority=optional] confidence: medium
  Reason: Since the focus is specifically on the "exome" and "coding variants," this reduces output noise by removing non-coding consequences.

✗ **most_severe** [source: most_severe] confidence: high
  Reason: Disabled because it suppresses individual scores from SIFT, PolyPhen, and HGVS/DNA changes, which are all necessary for clinical evidence accumulation.

✗ **summary** [source: summary] confidence: high
  Reason: Disabled to ensure full transcript-level detail is available for review; a summary view hides the granular data needed for pathogenicity assessment.

✗ **pick** [source: pick] confidence: medium
  Reason: Avoided in favor of MANE and protein-level annotations; using --pick can sometimes hide relevant high-impact transcripts that are not "primary" but still clinically significant.

### 3. Generated VEP Command
```
vep --input_file input.vcf --output_file output.txt --cache --format vcf --everything \
--hgvs --mane --symbol --check_existing --tsl --domains --appris --sift --polyphen --cadd \
--plugin SpliceAI,src=/path/to/spliceai_model.tar.gz \
--plugin AlphaMissense,src=/path/to/alphamissense_data.tar.gz \
--plugin Phenotypes \
--biotype --numbers --coding_only
```
*Note: Web interface users should enable "MANE Select", "ClinVar", and the listed prediction plugins under the 'Plugins' and 'Consequence' settings.*
