## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation

- **species**: human (User specified "human somatic")
- **origin**: somatic (User specified "tumor biopsies")
- **variant_size_class**: structural-CNV (User specified "structural variants and copy number alterations")
- **region_focus**: coding (User specified "which protein-coding genes are being disrupted")
- **analysis_goal**: basic-consequence (User requested a "quick top-line call... without necessarily needing an exhaustive breakdown")

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to distinguish between protein-coding genes and other transcript types during disruption analysis.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Standard requirement to drive the consequence calculation using the Ensembl/GENCODE annotation set.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs/structural variants to determine if the gene is sensitive to changes in copy number (e.g., pHaplo).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Provides essential context for structural variants by comparing them against known gnomAD structural-variant allele frequencies.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which helps in identifying the specific location of the genomic disruption.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making the output readable for a "top-line" summary of disrupted genes.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize the most reliable transcripts being affected.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify the most functionally important isoforms (principal transcripts) being impacted by the CNV.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because it conflicts with the recommended `--symbol` and `--tsl` options.
✗ hgvs [source: hgvs] confidence: high
  Reason: User explicitly requested to avoid an exhaustive breakdown of small-scale nucleotide changes.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This is a resource for missense/small variants; not applicable for structural/CNV top-line analysis.
✗ regulatory [source: regulatory] confidence: high
  Reason: User specified a focus on protein-coding genes rather than regulatory elements.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, the user is looking for gene disruption/loss; enforcing coding_only can sometimes mask the full context of a structural event.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --tsl --appris --dosage_sensitivity --gnomad_sv <path_to_gnomad_sv.vcf> --numbers
```
*Note: The `--gnomad_sv` option requires a path to the gnomAD structural variant VCF file. On the Ensembl Web Interface, these options correspond to the "Gene Symbol", "Biotype", "Transcript Support Level", "APPRIS", "Dosage Sensitivity", "gnomAD SV", "Exon/Intron numbering", and "Core" settings.*
