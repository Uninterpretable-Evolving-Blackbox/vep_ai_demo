✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Standard Ensembl/GENCODE core annotation is the foundation for all consequence calculations.

  Reason: Essential for human-readable results by providing HGNC gene symbols.

  Reason: Necessary to distinguish between protein-coding genes, lincRNAs, and other features in the regulatory/non-coding focus.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with promoters, enhancers, and other regulatory elements.

  Reason: Essential for structural variant analysis to retrieve gnomAD SV allele frequencies for filtering.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs to identify if the disrupted gene is sensitive to dosage changes (e.g., pHaplo).
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Helps prioritize high-quality transcripts via Transcript Support Level.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to help localize the impact of the CNV/SV.

  Reason: HGVS nomenclature for single nucleotide changes is not applicable/useful for the primary description of structural variants/CNVs.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is for missense variants; not applicable for structural/CNV analysis.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor and does not apply to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor and does not apply to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is primarily designed for single nucleotide variants/indels, not CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While the goal is "primary" consequence, disabling this allows for a more complete view of all overlapping regulatory and coding features, which is safer for SV interpretation.
✗ summary [source: summary] confidence: high
  Reason: A summary output would strip away the specific regulatory and biotype details requested.
