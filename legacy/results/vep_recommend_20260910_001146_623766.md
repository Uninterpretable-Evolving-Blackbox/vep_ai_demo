### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --plugin DosageSensitivity --plugin Phenotypes --custom gnomad_sv,gnomad_sv.vcf.gz,exact --symbol --biotype --tsl --mane --check_existing --clinvar --dosage_sensitivity --phenotypes
```
*(Note: The `--custom` flag requires a path to a local gnomAD SV VCF file. In the web interface, select "gnomAD Structural Variants" from the custom datasets menu. The `--dosage_sensitivity` and `--phenotypes` flags require the corresponding plugins to be installed in your VEP directory.)*
