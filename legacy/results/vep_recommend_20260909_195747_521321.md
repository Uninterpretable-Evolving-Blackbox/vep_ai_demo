## User Query
I am analyzing somatic SNVs and indels from a mouse tumor WES to quickly identify any high-impact protein-coding variants.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor WES)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (protein-coding variants)
- **analysis_goal**: basic-consequence (quickly identify high-impact variants)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is necessary for identifying which genes are affected.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature for coding variants, which is essential for standardizing protein-level descriptions.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link results to protein-level consequences.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most likely functional transcript for each gene.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps confirm that the variants are hitting protein-coding transcripts.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds names of overlapping protein domains (e.g., Pfam), which is critical for assessing the "impact" of a coding variant.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to help localize the variant within the coding structure.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is human-only data and is NOT APPLICABLE for mouse.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is human-only and NOT APPLICABLE for mouse.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: gnomAD is human-only and NOT APPLICABLE for mouse.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only meta-resource and NOT APPLICABLE for mouse.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool and NOT APPLICABLE for mouse.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool and NOT APPLICABLE for mouse.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While you want "high-impact" variants, disabling this allows you to see the full per-transcript consequence detail, which is safer for somatic analysis where different transcripts might be affected.
✗ summary [source: summary] confidence: high
  Reason: Summary mode collapses information; for high-impact identification, you need the full detail of the consequence.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --protein --canonical --biotype --domains --numbers --core_type merged
```
*(Note: Web interface users should select "Gene Symbol", "HGVS", "Protein ID", "Canonical transcript", "Transcript biotype", "Protein domains", and "Exon/intron numbering" in the customization menu. Ensure the species is set to Mouse.)*
