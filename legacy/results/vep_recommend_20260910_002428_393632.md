### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses Ensembl/GENCODE core annotations which are the standard for primary consequence calculation.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to make results human-readable and easier to interpret.

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help assess the reliability of the annotated transcripts.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for distinguishing between protein-coding, non-coding, and regulatory features.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Enables overlap detection with regulatory regions (promoters, enhancers) as requested.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNV analysis to identify if the affected genes are sensitive to dosage changes (e.g., haploinsufficiency).

✓ loeuf [source: loeuF, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores to help assess the constraint of the gene being affected by the CNV.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which aids in quickly characterizing the structural impact.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically recommended for structural variant analysis to provide allele frequencies from gnomAD SV datasets.

✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for small variants (SNVs/indels); it is not applicable for the primary goal of CNV consequence identification here and conflicts with several recommended summary/symbol settings.

✗ most_severe [source: most_severe] confidence: high
  Reason: While useful for filtering, it conflicts with many useful descriptive flags like --symbol and --tsl; it is better to see full annotation for CNVs.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is designed for missense/single nucleotide variants, not structural variants/CNVs.

✗ spliceai [source: spliceai] confidence: high
  Reason: This tool predicts effects of small variants on splicing; it is not applicable for large-scale CNVs.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --tsl --biotype --regulatory --dosage_sensitivity --plugin LOEUF --numbers --custom <path_to_gnomad_sv.vcf>,type=exact,overlap_cutoff=exact
```
*Note: The `--custom` flag requires a path to a gnomAD SV VCF file. On the Ensembl Web Interface, these options correspond to selecting 'GENCODE' as the annotation set, checking 'Gene Symbol', 'TSL', 'Biotype', 'Regulatory regions', 'Dosage Sensitivity', 'LOEUF', 'Exon/Intron numbering', and uploading a custom SV file.*
