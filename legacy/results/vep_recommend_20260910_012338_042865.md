### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: The default Ensembl/GENCODE core annotation is appropriate for general annotation coverage across coding and non-coding regions when dealing with structural variants and population context.

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Since the analysis includes regulatory and coding focus, TSL helps to rank the quality/support of the transcript evidence used for consequence prediction.

✓ frequency [source: frequency, priority=recommended] confidence: high
  Reason: The primary analysis goal is population frequency context, necessitating the use of frequency filtering options.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Identifying the associated gene symbol is crucial for both coding and regulatory interpretation in a general diagnostic/population context.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: The region focus explicitly includes regulatory regions, so this plugin is essential for annotating overlaps with promoters/enhancers.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: For structural variants (CNVs), exon/intron numbering provides necessary local context for interpreting breakpoints relative to gene structure.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: This dataset is specifically designed to annotate structural variants (the core input type) with population-level frequency information for the human species.

✗ hgvs [source: hgvs] confidence: medium
  Reason: While useful, HGVS nomenclature is supplementary. The primary focus is on functional and population context, and including this adds output bulk without direct functional necessity for this specific mix of inputs (SV + regulatory).

✗ af_gnomade [source: af_gnomade] confidence: medium
  Reason: Although population frequency is needed, since we are dealing with large structural variants, `--gnomad_sv` is the specialized and more relevant population frequency tool. Using the general exome frequency may miss the relevant SV data.

✗ af_gnomadg [source: af_gnomadg] confidence: medium
  Reason: Similar to `af_gnomade`, `--gnomad_sv` is the specific tool for structural variant frequencies, making the general `--gnomad_sv` flag superior here.

✗ domains [source: domains] confidence: low
  Reason: Protein domains are most relevant for point mutations. Since the primary input is structural CNVs, this feature is less critical but can be included if protein disruption assessment is desired. *Keeping it disabled unless protein impact is explicitly required.*

✗ most_severe [source: most_severe] confidence: high
  Reason: Because we are analyzing structural variants (which can disrupt multiple features simultaneously), we need to see the consequence for *all* affected transcripts, not just the single "most severe" one.

✗ summary [source: summary] confidence: high
  Reason: Similar to `most_severe`, structural variants can affect multiple regulatory or coding consequences; suppressing all consequences into a summary line loses vital detail.

✓ loeuf [source: loeuf, priority=optional] confidence: medium
  Reason: While the core input is structural, if the CNVs contain any point mutation hotspots or are near highly polymorphic regions, LOEUF provides valuable population constraints on predicted loss-of-function impact.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Contextualizing the affected region by its transcript biotype (e.g., coding vs. lncRNA vs. regulatory) is crucial for interpretation.

✓ check_existing [source: check_existing] confidence: medium
  Reason: It is useful to know if the large SV overlaps with known, cataloged variants (like known structural variants or common SNPs) to aid in filtering.

✗ appris [source: appris] confidence: high
  Reason: APPRIS annotation is generally focused on functional isoforms of point mutations and is not the primary annotation for large-scale structural changes.

✗ dosage_sensitivity [source: dosage_sensitivity] confidence: high
  Reason: While CNVs suggest dosage changes, this plugin usually relates to small, localized dosage effects often seen in point mutation studies, and `--gnomad_sv` already covers the macro-level dosage context.
