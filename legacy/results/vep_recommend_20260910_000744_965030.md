### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to define the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, essential for human clinical interpretation of gene-disrupting CNVs.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps identify if CNVs affect protein-coding genes, lncRNAs, or other regulatory elements.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Essential to assess if structural changes overlap with promoters, enhancers, or CTCF binding sites.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically used to annotate structural variants with gnomAD SV allele frequencies to distinguish somatic drivers from common germline CNVs.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Allows identification of known variants co-located with the structural changes.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance for co-located variants, aiding in clinical interpretation.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNVs (duplications/deletions) to determine if the affected gene is sensitive to changes in copy number (e.g., pHaplo).
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Links affected genes to known phenotypes, assisting in the clinical interpretation of the structural change.
✓ cadd [source: cadd, priority=recommended] confidence: medium
  Reason: Can be used to provide a deleteriousness score for the structural event if it affects coding regions.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for short variants (SNVs/indels) and is not applicable/standard for structural-CNV classes.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide substitutions; not applicable to CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single nucleotide substitutions; not applicable to CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: For clinical CNV analysis, you need the full per-transcript/per-feature overlap detail, not a collapsed single most severe term.
✗ summary [source: summary] confidence: high
  Reason: Summary mode hides the detailed regulatory and gene-level overlap information required for this analysis.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin gnomad_sv,/path/to/gnomad_sv.vcf.gz --plugin DosageSensitivity --plugin Phenotypes --regulatory --symbol --biotype --check_existing --clinvar --cadd
```
*Note: On the Ensembl Web Interface, ensure "Regulatory" and "Dosage Sensitivity" are selected in the plugin/feature sections and use the "gnomAD SV" custom file upload if available.*
