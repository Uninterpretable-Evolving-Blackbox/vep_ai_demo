  Reason: Provides MANE Select/Plus Clinical flags to ensure the analysis focuses on the most clinically relevant transcripts.

  Reason: Provides exon/intron numbering which is vital for describing the impact of structural changes within a gene.

  Reason: Links the identified genes to known phenotypes, assisting in the clinical interpretation of the somatic finding.

  Reason: Provides a standardized deleteriousness score to assist in prioritizing variants.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin DosageSensitivity --plugin Mastermind --plugin Phenotypes --plugin CADD --plugin LOEUF --plugin gnomad_sv --custom <path_to_gnomad_sv.vcf.gz>,type=exact,overlap_cutoff=exact --check_existing --clinvar --pubmed --symbol --tsl --appris --mane --regulatory --biotype --numbers
```
*Note: For the web interface, ensure you enable "Regulatory Build" and select the relevant plugins from the "Plugins" section. The `--custom` flag requires a local path to the gnomAD SV VCF.*
