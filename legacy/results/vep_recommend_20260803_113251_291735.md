### 2. Recommended Options
✓ core_type [source: core_type, priority=critical] confidence: high
  Reason: Essential to define the transcript annotation set driving the consequence calculation.

✓ hgvs [source: hgvs, priority=critical] confidence: high
  Reason: Provides standardized nomenclature (HGVS) necessary for reporting and communicating variant effects.

✓ regulatory [source: regulatory, priority=critical] confidence: high
  Reason: Necessary to identify "changes that matter" in non-coding regions by looking for overlaps with promoters/enhancers.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols (e.g., Tp53) to the output, which is essential for biological interpretation of tumor drivers.

✓ check_existing [source: check_existing, priority=recommended] confidence: high
  Reason: Crucial for somatic analysis to see if the identified mutations are already cataloged in known variation databases.

✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps determine functional impact by showing if a mutation disrupts a protein domain (Pfam/PROSITE).

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Simplifies interpretation of somatic hits by flagging the primary transcript for each gene.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to differentiate if a mutation hits a protein-coding gene vs. a non-coding RNA (lncRNA/miRNA).

✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for potential splice-site disruptions in the variants.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is vital for mapping mutations to specific protein domains or structural motifs.

✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Useful for linking identified genes to known biological phenotypes in the mouse model.

✓ mirna [source: mirna, priority=recommended] confidence: high
  Reason: Provides context if a variant falls within a microRNA structure.

✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Can be used as an add-on to filter for protein-altering variants if the user wants to focus only on the exome.

✓ NMD [source: plugin NMD, priority=optional] confidence: medium
  Reason: Useful to predict if a somatic nonsense mutation will lead to mRNA degradation via nonsense-mediated decay.

✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because the user wants to know "which changes matter" across regulatory and coding regions; collapsing to only the single most severe consequence would hide important secondary effects (like regulatory changes).

✗ hgvs_conflicts [source: conflicts] confidence: high
  Reason: Note that --most_severe is incompatible with --hgvs, --symbol, and --domains.

✗ human_only_plugins [source: species_restriction] confidence: high
  Reason: All plugins/fields like ClinVar, CADD, dbNSFP, gnomAD, and SIFT/PolyPhen are disabled as they are explicitly restricted to human data and would not function for mouse.
