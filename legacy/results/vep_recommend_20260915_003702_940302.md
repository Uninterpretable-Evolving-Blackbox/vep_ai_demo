  Reason: This plugin is designed for missense single-nucleotide variants, not structural variants/CNVs.

  Reason: Provides gnomAD LOEUF scores, which are critical for assessing the constraint/frequency context of human genes.

  Reason: Adds HGNC gene symbols, making the results human-readable and easier to interpret.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps identify the primary transcript for a gene, which is standard practice in variant effect prediction.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and regulatory elements/non-coding RNAs.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --tsl --appris --canonical --biotype --regulatory --dosage_sensitivity --numbers --plugin LOEUF --check_existing --custom gnomad_sv,gnomad_sv.vcf.gz,exact
```
*Note: The `--custom` flag requires a local path to the gnomAD SV VCF file. On the Ensembl Web Interface, these would be selected via the "Gene/Transcript" and "Regulatory" checkboxes, and the "Plugins" section.*
