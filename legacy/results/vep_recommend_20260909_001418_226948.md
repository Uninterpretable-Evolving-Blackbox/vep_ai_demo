### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses Ensembl/GENCODE core annotations which are the standard for driving consequence calculation in human studies.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results human-readable and useful for clinical interpretation.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to confirm that the CNV overlaps with `protein_coding` transcripts as requested.

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help prioritize the most reliable transcript annotations.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is helpful for characterizing the boundaries of a coding CNV.

✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify the most functionally significant isoform (principal transcript) for the affected gene.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Specifically relevant for CNVs (deletions/duplications) to determine if the gene is sensitive to changes in copy number (e.g., pHaplo).

✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores to assess if the gene is constrained against loss-of-function, assisting in CNV interpretation.

✓ frequency [source: frequency, priority=recommended] confidence: high
  Reason: Enables frequency-based filtering to identify how common the variants are in the population.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: A custom dataset requirement to specifically retrieve allele frequencies for structural variants (CNVs) from gnomAD.

✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if the identified CNV matches existing known variant IDs in databases.

✓ clinvar [source: clinvar, priority=optional] confidence: medium
  Reason: Provides clinical significance for the overlap, helping to see if these specific CNVs have been previously reported.

✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for short variants (SNVs/Indels) and is not applicable/standard for CNVs in this context.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a meta-resource for missense/nonsynonymous single nucleotide variants, not structural variants.

✗ spliceai [source: spliceai] confidence: high
  Reason: SpliceAI is designed to predict splicing effects of small variants, not large-scale CNVs.

✗ most_severe [source: most_severe] confidence: high
  Reason: Using "most_severe" would conflict with several recommended informative flags like --symbol and --tsl.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --tsl --numbers --appris --dosage_sensitivity --plugin LOEUF --frequency --custom <path_to_gnomAD_SV.vcf>,type=exact,overlap_cutoff=exact --check_existing --plugin ClinVar --plugin NMD
```
*Note: The `--custom` flag requires a path to a local gnomAD SV VCF file. The `--plugin ClinVar` and `--plugin LOEUF` require the respective plugin files to be installed in your VEP plugin directory. This command is equivalent to selecting the recommended filters and plugins in the Ensembl VEP Web Interface.*
