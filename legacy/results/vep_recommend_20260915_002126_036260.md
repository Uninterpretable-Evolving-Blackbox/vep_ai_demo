### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to provide the base transcript/gene annotation set for consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols to make results human-readable for clinical reporting.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Necessary to distinguish if the CNV affects protein-coding genes, lincRNA, or other features.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to assess the impact on non-coding regulatory regions (promoters, enhancers) as requested.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: The primary tool for checking how common these structural variants are in healthy populations using gnomAD-SV frequencies.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for clinical interpretation of CNVs to determine if the affected genes are sensitive to copy number changes (pHaplo/pCNV).
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Allows the identification of known variants co-located with the structural changes.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to see if previously reported variants in these regions are linked to disease.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link the affected genes to known clinical phenotypes/diseases.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for short variants (SNVs/indels) and is not applicable for structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: Missense predictors like SIFT are for single nucleotide changes in coding sequences, not structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: Missense predictors like PolyPhen are for single nucleotide changes in coding sequences, not structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are optimized for SNVs and small indels, not structural variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: In clinical structural variant analysis, it is important to see all overlapping features (genes, enhancers, etc.) rather than a single collapsed consequence.
✗ summary [source: summary] confidence: high
  Reason: A summary view hides the detailed genomic context required for structural variant interpretation.

