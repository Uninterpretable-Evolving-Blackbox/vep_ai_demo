## User Query
I am currently reviewing exome sequencing results from a cohort of mice used in our recent developmental study. We have identified several single-letter changes and small additions or deletions throughout the genome. For my preliminary report, I just need to quickly identify which of these variations actually alter the protein sequence or create an early stop signal within the coding regions.

## Recommendation

- **species**: non-human (Mice/Mus musculus)
- **origin**: Not explicitly stated, but exome sequencing in a developmental study cohort typically implies germline or stable somatic variants; however, without a specific "somatic" or "germline" keyword, I will treat it as a general analysis.
- **variant_size_class**: small (indicated by "single-letter changes and small additions or deletions")
- **region_focus**: coding (indicated by "throughout the genome... identify which... actually alter the protein sequence or create an early stop signal within the coding regions")

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the biotype of the transcript (e.g., protein_coding), which is essential for identifying coding regions in a general genome scan.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most reliable transcript for consequence calculation, which is standard practice for a preliminary report.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the Ensembl core annotation to drive consequence calculations for this non-human species.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which helps characterize the impact of changes that alter the protein sequence.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature for the protein-altering changes requested.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering (e.g., 7/27) to help locate where in the coding sequence the changes occur.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP) to link nucleotide changes to their protein-level effects.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output for easy identification of affected genes.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Enables checking for known existing variants, which is useful for a quick preliminary report.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the user is focused on coding regions, they asked to identify *which* variations alter the sequence; disabling this allows the user to see non-coding variants that might be near coding regions, though it can be turned on to speed up analysis.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option conflicts with several recommended options like --hgvs, --symbol, and --protein.
✗ af_gnomad [source: af_gnomade] confidence: high
  Reason: NOT APPLICABLE as the species is non-human.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE as the species is non-human.
