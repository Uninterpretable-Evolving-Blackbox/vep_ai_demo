# VEP Recommendation

**Date:** 2026-09-09T22:38:07.763313

## User Query
I am working with whole exome sequencing data from a cohort of zebrafish tumor models where I have identified several somatic SNVs and small indels by comparing the tumor DNA to matched germline samples. My primary goal is to identify which of these mutations in the protein-coding regions are likely to be pathogenic, so I need a way to assess their potential impact on the amino acid sequence and overall protein function to help prioritize candidate driver mutations for further study.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Zebrafish/Danio rerio)
- **origin**: somatic (Tumor vs matched germline comparison)
- **variant_size_class**: small (SNVs and small indels)
- **region_focus**: coding (Protein-coding regions)
- **analysis_goal**: clinical-interpretation (Prioritizing candidate driver mutations based on impact)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set that drives the consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols (e.g., TP53) to the output, which is necessary for prioritizing candidate driver genes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, which is crucial for reporting and communicating specific amino acid changes.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides transcript biotype context to ensure focus on protein-coding transcripts.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript for each gene, aiding in the prioritization of the most biologically relevant isoform.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon and intron numbering, which is important for localizing the variant within the coding sequence.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: SIFT is available for species with variation data (like zebrafish) and helps predict if amino acid substitutions affect protein function.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Useful for assessing the impact of variants on splice sites, which can affect coding sequences.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations for genes, helping to link driver candidates to biological processes.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these somatic variants have been previously recorded in zebrafish variation databases.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Predicts if a premature stop codon will escape nonsense-mediated decay, a key aspect of assessing coding impact.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information (e.g., Pfam) to help assess if a mutation hits a functional site.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only resource and is not applicable to zebrafish.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource and is not applicable to zebrafish.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this to ensure full per-transcript detail is available for driver interpretation, as requested.
✗ summary [source: summary] confidence: high
  Reason: Disabling this to allow detailed per-transcript annotations rather than a collapsed view.

### 3. Generated VEP Command
```
vep --input_file tumor_somatic.vcf --output_file zebrafish_annotated.txt --cache --dir_cache /path/to/cache --symbol --hgvs --protein --biotype --canonical --numbers --sift --maxentscan --phenotypes --check_existing --nmd --domains
```
*Note: On the Ensembl Web Interface, ensure you select the correct zebrafish genome assembly and enable the checkboxes for Symbol, HGVS, Protein, Biotype, Canonical, Numbers, SIFT, MaxEntScan, Phenotypes, and Domains. Avoid selecting "Most Severe" or "Summary" to preserve detailed data.*
