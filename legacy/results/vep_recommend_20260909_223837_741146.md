## User Query
I have germline Mus musculus WES data; I need to identify protein-altering SNVs and indels in coding regions and assess their predicted functional pathogenicity.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (*Mus musculus* specified).
- **origin**: germline (specified).
- **variant_size_class**: small (SNVs and indels implied).
- **region_focus**: coding (specified).
- **analysis_goal**: clinical-interpretation (assessing functional pathogenicity).

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Selecting the Ensembl/GENCODE core annotation set is the standard approach for driving consequence calculation in non-human species.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Essential for clinical-grade interpretation to provide standardized HGVS nomenclature for the protein-altering changes.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps assess pathogenicity by showing if the variant overlaps known protein domains (Pfam, PROSITE, etc.).
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make the results interpretable for biological context.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, which is critical for prioritizing the most likely functional consequence in coding regions.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on the transcript type, ensuring the focus remains on protein-coding features.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based pathogenicity prediction for missense variants in species with available SIFT data (like Mouse).
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Essential for assessing the impact of indels or SNVs on splice sites, even when focusing on coding regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering (e.g., 7/27) to facilitate precise localization of the variant within the gene.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves overlapping phenotype associations, which is crucial for assessing the clinical/biological relevance of a finding.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Optional but helpful for assessing whether a premature stop codon will escape nonsense-mediated decay.
✓ uniprot [source: uniprot, priority=optional] confidence: medium
  Reason: Optional add-on to link variants to UniProt protein database accessions.
✓ go [source: go, priority=optional] confidence: medium
  Reason: Optional add-on to provide Gene Ontology terms for biological context.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because it conflicts with several recommended output flags like --hgvs, --symbol, and --sift.
✗ coding_only [source: coding_only] confidence: medium
  Reason: While the focus is coding, enabling this might hide important splice-site consequences (maxentscan) that are required for a complete pathogenicity assessment.
✗ af_gnomad [source: af_gnomade] confidence: high
  Reason: NOT APPLICABLE; gnomAD is a human-only database.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is a human-only database.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: NOT APPLICABLE; dbNSFP is a human-only meta-resource.

### 3. Generated VEP Command
```bash
vep --input_file mouse_wes.vcf --output_file mouse_wes_annotated.txt --cache --format vcf --vcf --hgvs --symbol --canonical --protein --biotype --sift b --maxentscan --numbers --phenotypes --plugin NMD --plugin UniProt --plugin GO
```
*(Note: In the web interface, ensure you select the Mus musculus cache. The `--sift b` flag specifies the scoring mode; 'b' is standard for bioinformatics pipelines.)*
