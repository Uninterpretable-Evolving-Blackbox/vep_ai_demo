### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the primary annotation set (Ensembl/GENCODE) to drive consequence calculations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, which is vital for clinical interpretation of gene-disrupting SVs.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps identify if the CNV overlaps protein-coding genes or other functional elements.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the primary transcript affected by the structural change.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Provides MANE Select/Plus Clinical flags to ensure clinical consistency with NCBI/RefSeq.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Identifies functionally important isoforms, which is critical when a CNV affects specific transcript variants.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Specifically targets the scenario of CNVs by providing pHaplo/pLI scores to assess gene dosage sensitivity.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Links the affected genes to known clinical phenotypes/diseases for pathogenicity assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Required to enable ClinVar and frequency lookups for co-located variants.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance (pathogenic/benign) for co-located variants to aid interpretation.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for the "population-frequency" goal; provides allele frequencies specifically for structural variants.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to help localize the boundaries of the CNV/SV.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature for short variants is not applicable/useful for structural-CNV variants.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Predictors in dbNSFP are designed for missense/SNVs, not structural variants.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts amino acid substitution impacts and is not applicable to CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts missense impact and is not applicable to CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is optimized for small variants (SNVs/indels) and is not appropriate for CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this allows for full per-transcript detail, which is necessary to see all genes/isoforms disrupted by a single SV.
✗ summary [source: summary] confidence: high
  Reason: A summary output collapses detail, which is counter-productive for clinical SV interpretation.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --everything --symbol --biotype --canonical --mane --appris --dosage_sensitivity --phenotypes --check_existing --clinvar --gnomad_sv --numbers
```
*Note: `--everything` is a shortcut; for precise control as recommended above, use specific flags. The `--gnomad_sv` flag requires the gnomAD SV custom dataset. In the web interface, ensure "Dosage Sensitivity" and "Phenotypes" plugins are selected.*
