✓ core_type [source: core_type, priority=critical] confidence: high
  Reason: Essential to use the standard Ensembl/GENCODE transcript set for consistent genomic annotation in clinical pipelines.

✓ hgvs [source: hgvs, priority=critical] confidence: high
  Reason: Required for standardized nomenclature (e.g., c. and p. notation) necessary for clinical reporting and communication with laboratories.

✓ mane [source: mane, priority=critical] confidence: high
  Reason: Essential for identifying transcripts that are matched between NCBI and Ensembl, ensuring clinical variants are reported on the same high-quality transcript.

✓ check_existing [source: check_existing, priority=recommended] confidence: high
  Reason: Enables retrieval of ClinVar clinical significance and rsIDs, which is critical for identifying previously reported pathogenic variants.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to the output, making results human-readable and easier for clinicians to interpret.

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level (TSL), helping distinguish well-supported transcripts from those with lower evidence.

✓ domains [source: domains, priority=recommended] confidence: medium
  Reason: Helps assess the functional impact of missense variants by identifying if they overlap known protein domains (e.g., Pfam).

✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Identifies the most functionally important isoforms (APPRIS) to help focus interpretation on biologically relevant transcripts.

✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based prediction of whether an amino acid substitution affects protein function.

✓ polyphen [source: polyphen, priority=recommended] confidence: high
  Reason: Predicts the impact of substitutions on protein structure and function using physical and evolutionary features.

✓ cadd [source: plugin CADD, priority=recommended] confidence: high
  Reason: Provides a consolidated metric (C-score) to integrate many different annotations into a single deleterious score.

✓ spliceai [source: plugin SpliceAI, priority=recommended] confidence: high
  Reason: Crucial for identifying potential impacts on splicing that might be missed by conventional methods, even in coding regions.

✓ alphamissense [source: plugin AlphaMissense, priority=recommended] confidence: high
  Reason: Utilizes DeepMind's latest structural models to provide highly accurate pathogenicity predictions for missense variants.

✓ eve [source: plugin EVE, priority=recommended] confidence: medium
  Reason: Provides evolutionary-based predictions that can complement traditional tools like SIFT and PolyPhen.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps quickly filter results to focus on protein-coding transcripts in an exome analysis.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering (e.g., 7/27), which is vital for localized variant descriptions in clinical reports.

✓ phenotypes [source: plugin Phenotypes, priority=recommended] confidence: medium
  Reason: Links variants to known disease associations or phenotypic features, directly supporting the "likely pathogenic" goal.

✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because clinical interpretation requires looking at all affected transcripts/consequences per variant, not just a collapsed summary.

✗ summary [source: summary] confidence: high
  Reason: Disabled to ensure the output contains full descriptive detail for every transcript rather than a single-line overview.
