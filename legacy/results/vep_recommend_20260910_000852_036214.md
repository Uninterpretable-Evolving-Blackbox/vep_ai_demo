# VEP Recommendation

**Date:** 2026-09-10T00:08:52.036563

## User Query
I am starting to set up the pipeline for our human tumor-only whole genome sequencing data from a large cancer cohort, but I am still a bit unsure about how to best capture all the relevant information. We have identified several structural variants and copy number alterations, and my goal is to get a quick top-line summary of their functional consequences. Specifically, I need to see how these changes affect protein-coding regions—ideally identifying impacts on the most reliable transcripts—but I also want to capture any potential disruptions to regulatory or non-coding elements. Additionally, it would be really helpful if the results provided context regarding population allele frequencies so I can distinguish these somatic hits from common germline variation.

## Recommendation
### 1. Detected Scenario
- **species**: human (explicitly stated "human tumor-only")
- **origin**: somatic (context of "tumor-only... cancer cohort" and "distinguish these somatic hits from common germline variation")
- **variant_size_class**: structural-CNV (explicitly stated "structural variants and copy number alterations")
- **region_focus**: coding, regulatory-noncoding (explicitly stated "affect protein-coding regions" and "disruptions to regulatory or non-coding elements")
- **analysis_goal**: basic-consequence, population-frequency (goal to "capture all relevant information" and "context regarding population allele frequencies")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core is the standard for high-quality consequence calculation for human data.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Helps identify the most reliable transcripts by providing Transcript Support Level (TSL) rankings.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols, which is essential for making results human-readable in a large cancer cohort.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps prioritize the most functionally important isoforms via APPRIS annotation.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to capture disruptions to regulatory/non-coding elements.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNV (Copy Number Variation) analysis to see if the altered dosage affects gene sensitivity.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores to help assess the functional constraint of the affected genes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Useful for distinguishing between protein-coding and various non-coding/regulatory elements.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is critical for locating the exact impact of a structural change.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically recommended for structural variants to provide population frequency context from gnomAD SV.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Enabled to allow the retrieval of ClinVar and other population frequency data.
✓ clinvar [source: clinvar, priority=optional] confidence: medium
  Reason: Provides clinical significance for known variants, aiding in the distinction between somatic drivers and benign variation.
✗ hgvs [source: hgvs] confidence: high
  Reason: Not recommended here because it conflicts with the `--most_severe` or summary-style output often preferred for "top-line" summaries, and is not the primary goal.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While you want a "top-line" view, disabling this allows you to see the full breadth of consequences across coding and regulatory regions as requested.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Not applicable as this is primarily for missense/single nucleotide variants, whereas the focus here is structural/CNV.
✗ spliceai [source: spliceai] confidence: high
  Reason: Not applicable for the primary goal of structural variant/CNV consequence prediction.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --everything --symbol --tsl --appris --regulatory --dosage_sensitivity --loeuf --biotype --numbers --plugin gnomad_sv,/path/to/gnomad_sv.vcf.gz --check_existing --clinvar
```
*Note: In the web interface, ensure you select the "Regulatory" build and provide the custom gnomAD SV file via the plugin interface.*
