### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for selecting the transcript/gene annotation set driving the consequence calculation.
✓ symbol [source: symbol, priority=no priority] confidence: high
  Reason: Adds gene symbols to the output, which is critical for orienting non-coding variants to their target genes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides the biotype of the regulatory feature (e.g., promoter, enhancer), which is vital for non-coding analysis.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically required to look for overlaps with regulatory regions like promoters and enhancers.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Necessary to identify if these somatic variants overlap with known variants in zebrafish databases.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard nomenclature for reporting variants.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most likely functional transcript for a given gene.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: A sequence-based tool that can help assess splice-site impacts if indels affect boundaries, applicable to all species.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link the variant to known phenotype associations for the genes it impacts.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only database and is not applicable to zebrafish.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only meta-resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with hgvs and symbol; in clinical interpretation, we need the full context of all overlapping consequences rather than just the single most severe term.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with hgvs and symbol; summary mode suppresses the detailed annotation needed for regulatory assessment.
