## User Query
I’m working through some human tumour sequencing data where we're specifically looking for large-scale changes in the DNA structure, like deletions or duplications. A lot of these structural changes are landing in the regions outside of the actual genes, so I need a way to quickly figure out if these stretches of missing or extra DNA might be affecting how genes are turned on or off. It would also be really helpful to see how common these types of variations are in the general healthy population so I can better judge whether a finding looks like a potential driver for the cancer or just a common variation.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set that drives consequence calculation.
✓ symbol [source: symbol, priority=no priority] confidence: high
  Reason: Adds gene symbols to make results more human-readable for clinical interpretation.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to identify if the structural variant overlaps protein-coding genes, lincRNA, or other features.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Necessary to identify overlaps with promoters, enhancers, and CTCF binding sites to assess non-coding effects.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically required to annotate structural variants with gnomAD SV allele frequencies to filter common variations.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Helps identify known variants co-located with the structural changes.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs to determine if the affected genes are sensitive to changes in copy number (pHaplo).
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to see if similar structural variants have known clinical significance.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for short variants/SNVs; structural variant nomenclature is typically handled differently.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide changes and is not applicable to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single nucleotide changes and is not applicable to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is designed for small variants (SNVs/indels) and is not applicable to structural variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: For CNVs, you need to see all overlapping features (genes and regulatory elements), not just a single "most severe" term.
✗ summary [source: summary] confidence: high
  Reason: Detailed context of which genes and regulatory elements are disrupted is required for clinical driver assessment.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --regulatory --gnomad_sv <path_to_gnomad_sv.vcf.gz> --check_existing --plugin DosageSensitivity --plugin ClinVar --core_type merged
```
*Note: The `--plugin ClinVar` and `--plugin DosageSensitivity` require the respective database files to be installed in your VEP plugin directory. On the Ensembl Web Interface, enable "Gene symbol", "Transcript biotype", "Regulatory regions", "gnomAD SV frequencies", and the "Dosage Sensitivity" and "ClinVar" plugins.*
