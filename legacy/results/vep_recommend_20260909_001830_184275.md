## User Query
I am processing human germline sequencing data from a large-scale population cohort and have identified several large structural changes, such as deletions and duplications of DNA segments. I want to focus my analysis on these changes when they occur in regulatory regions that control gene activity, rather than just looking at the protein-coding parts of the genome. For these types of variations, I need to ensure my annotation process includes information on how common these changes are within the general population so I can identify which ones are truly rare.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is recommended for standard human germline analysis.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: The user specifically requested to focus on changes in regulatory regions that control gene activity.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: For structural variants like deletions and duplications (CNVs) in germline data, knowing gene dosage sensitivity (e.g., pHaplo) is critical for assessing impact.

✓ frequency [source: frequency, priority=recommended] confidence: high
  Reason: The user needs to filter or identify variants based on how common they are in the general population.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for distinguishing between different types of regulatory features and non-coding elements.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically designed to annotate structural variants (SV) with allele frequencies from the gnomAD SV dataset, directly addressing the user's goal for CNV frequency.

✓ loeuf [source: loeuF, priority=recommended] confidence: medium
  Reason: While primarily used for LOF, providing constraint metrics helps in assessing the rarity and impact of germline variations in a population context.

✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily useful for coding variants; the user is focusing on large structural/regulatory changes.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a meta-resource for missense (coding) variants, which is not the focus of this regulatory/structural analysis.

✗ coding_only [source: coding_only] confidence: high
  Reason: The user explicitly stated they want to look at regulatory regions *rather than just* the protein-coding parts.

✗ dbscsnv [source: dbscsnv] confidence: high
  Reason: This tool is for splice-site prediction in coding/splicing regions, which is not the focus here.

✗ most_severe [source: most_severe] confidence: medium
  Reason: Using `--most_severe` would restrict the output, potentially hiding the important regulatory consequences the user is seeking.

✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Recommended to see if these structural variants have been previously identified/catalogued in other databases.
