### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to use the Ensembl/GENCODE core annotation set to drive consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making the results much more human-readable.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on whether the affected feature is a protein-coding gene, lincRNA, etc., which is critical for SV/CNV interpretation.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with promoters, enhancers, and other regulatory elements as requested.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs to identify if the affected genes are sensitive to changes in copy number (e.g., pHaplo scores).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for structural variants to provide population allele frequencies from gnomAD-SV to filter common variants.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize high-confidence transcripts during consequence assessment.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify the most functionally important isoforms, which is useful when CNVs disrupt specific coding regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, helping to localize the boundaries of the CNV relative to gene structures.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for short variants (SNVs/indels) and is not applicable for structural variants/CNVs.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is for missense variants (SNVs); it is not applicable to structural variants.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide changes and is not applicable to CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single nucleotide changes and is not applicable to CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are designed for small variants (SNVs/indels) and are not applicable to CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: For SVs, you generally want to see all overlapping features (coding and regulatory) rather than collapsing them into a single term.
✗ summary [source: summary] confidence: high
  Reason: A summary output would hide the detailed regulatory and coding information requested.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --regulatory --dosage_sensitivity --plugin gnomad_sv,/path/to/gnomad_sv.vcf.gz --tsl --appris --numbers
```
*Note: The `--plugin gnomad_sv` requires a path to the gnomAD SV VCF file. On the Ensembl Web Interface, these correspond to the "Gene Symbol", "Transcript Biotype", "Regulatory" (Ensembl Regulatory Build), "Dosage Sensitivity", "gnomAD SV", "TSL", "APPRIS", and "Exon/Intron Number" checkboxes.*
