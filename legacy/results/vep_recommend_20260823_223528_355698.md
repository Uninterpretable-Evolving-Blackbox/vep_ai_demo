### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --species homo_sapiens --symbol --tsl --appris --regulatory --dosage_sensitivity --cadd --mane --biotype --custom gnomad_sv,gnomad_sv.vcf,exact --clinvar --loeuf --phenotypes --numbers --mastermind --check_existing --pubmed --plugin NMD
```
*Note: The `--custom` flag requires a local path to the gnomAD SV VCF file. The `--clinvar` and `--dosage_sensitivity` flags require the respective plugins/data to be installed in your VEP cache/plugin directory. Web interface users should check the "Regulatory" and "Plugins" sections for these options.*
