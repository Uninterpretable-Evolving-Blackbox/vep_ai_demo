## User Query
I am reviewing human germline whole genome sequencing for a patient with suspected large-scale chromosomal changes. I need to quickly identify the impact on genes and regulatory regions, as well as how common these variants are in the general population.

- **species**: human (explicitly mentioned)
- **origin**: germline (explicitly mentioned)
- **variant_size_class**: structural-CNV (indicated by "large-scale chromosomal changes")
- **region_focus**: coding, regulatory-noncoding (indicated by "impact on genes and regulatory regions")
- **analysis_goal**: clinical-interpretation, population-frequency (indicated by "identify the impact" and "how common these variants are in the general population")

### 2. Recommended Options
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Provides isoform annotation to identify functionally important transcripts, which is critical for clinical interpretation of gene disruption.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for distinguishing between protein-coding genes and other features (e.g., lincRNA) impacted by chromosomal changes.
✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: Helps assess the deleteriousness of variants, supporting clinical interpretation.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Required to link variants to existing IDs (like rsIDs) and access clinical data like ClinVar.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Crucial for clinical interpretation to see if existing chromosomal changes or variants have known pathogenic significance.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Standard requirement to define the transcript set driving the consequence calculation.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for "large-scale chromosomal changes" as it annotates genes sensitive to copy number variations (CNVs).
✓ frequency [source: frequency, priority=recommended] confidence: high
  Reason: Enables frequency-based filtering to satisfy the goal of determining how common these variants are.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically provides allele frequencies for structural variants from gnomAD, matching the user's variant class.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Ensures results are cross-referenced with MANE Select/Plus transcripts for diagnostic precision.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is helpful for documenting the impact of structural changes.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Links genes and variants to known phenotypes, aiding clinical interpretation.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Necessary to satisfy the user's requirement to identify impacts on regulatory regions.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making the output human-readable for clinical reporting.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize the most reliable transcript annotations.
✗ hgvs [source: hgvs] confidence: high
  Reason: Conflicts with the ability to provide a streamlined summary/symbol-based clinical report in some workflows, though generally useful, it is often excluded in high-level CNV summaries.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with several recommended plugins and information fields (symbol, tsl, etc.) required for this clinical workflow.
✗ spliceai [source: spliceai] confidence: medium
  Reason: Primarily useful for small variants (SNVs/indels) affecting splice sites, less relevant for large-scale chromosomal changes.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin DosageSensitivity --plugin gnomad_sv --plugin Phenotypes --plugin CADD --appris --biotype --clinvar --dosage_sensitivity --frequency --gnomad_sv --mane --numbers --regulatory --symbol --tsl --check_existing
```
*Note: The `--plugin gnomad_sv` requires the specific gnomAD SV VCF file to be provided via the plugin argument. On the Ensembl VEP web interface, these correspond to the checkboxes for the selected plugins and parameters.*
