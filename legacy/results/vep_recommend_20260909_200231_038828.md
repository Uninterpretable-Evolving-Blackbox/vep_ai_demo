### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --everything --plugin phenotypes --plugin NMD --sift
```
*(Note: `--everything` is a shortcut in the web interface, but for command line, explicit flags for symbol, hgvs, protein, biotype, canonical, numbers, domains, and sift are used. The `--plugin` flags require local installation of the plugin files.)*
