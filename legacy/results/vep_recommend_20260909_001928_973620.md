I am reviewing human germline whole genome sequencing for a patient with suspected large-scale chromosomal changes. I need to quickly identify the impact on genes and regulatory regions, as well as how common these variants are in the general population.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for determining the primary transcript/gene annotation driving the consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Makes results human-readable by adding HGNC gene symbols.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Necessary to distinguish between protein-coding genes and other features like lincRNA in a WGS context.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to identify impacts on regulatory regions (promoters, enhancers, etc.).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for determining the population frequency of structural variants using gnomAD-SV data.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for clinical interpretation of CNVs to see if the affected genes are sensitive to dosage changes (e.g., pHaplo).
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Recommended to identify if these large-scale changes are already cataloged in known databases.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Required for clinical interpretation to see if the structural change has known pathogenicity.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link disrupted genes to known clinical phenotypes, aiding diagnostic interpretation.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for small variants; structural variant nomenclature varies and is not a primary requirement here.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Not applicable for structural/CNV variants; these tools are for missense/small variants.
✗ sift [source: sift] confidence: high
  Reason: Not applicable; SIFT is a missense pathogenicity predictor for single nucleotide changes.
✗ polyphen [source: polyphen] confidence: high
  Reason: Not applicable; PolyPhen is a missense pathogenicity predictor.
✗ cadd [source: cadd] confidence: high
  Reason: Not applicable; CADD is designed for single nucleotide and small indel variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: For clinical structural variant review, you need the full detail of all overlapping features, not a single collapsed consequence.
✗ summary [source: summary] confidence: high
  Reason: A summary collapses information, which is detrimental when trying to map a large CNV to multiple regulatory and coding elements.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --plugin DosageSensitivity --plugin gnomad_sv --check_existing --clinvar --phenotypes --regulatory --symbol --biotype --core_type merged
```
*Note: `--plugin gnomad_sv` requires the gnomAD SV VCF file path. On the Ensembl Web Interface, ensure "Regulatory" and "Dosage Sensitivity" are selected in the plugins/advanced section.*
