**Date:** 2026-09-13T19:28:41.996919

## User Query
I am analyzing somatic SNVs and indels from a mouse tumor WES to quickly identify any high-impact protein-coding variants.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor WES)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (protein-coding variants)
- **analysis_goal**: basic-consequence (identify high-impact variants)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for determining the transcript/gene annotation driving the consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds the gene symbol to the output, which is critical for identifying target genes in a tumor.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature for standardized reporting of the coding changes.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides the Ensembl protein identifier (ENSP) to link results to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Confirms the transcript type (e.g., protein_coding) to ensure focus on coding regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon/intron numbering, which is helpful for localizing the variant within the gene structure.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds overlapping protein domain information, which is vital for assessing "high-impact" functional changes.
✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Since the goal is to identify protein-coding variants, this restricts output to relevant consequences only.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled to avoid conflicts with hgvs, symbol, and protein; we need detailed per-transcript annotation to assess impact.
✗ summary [source: summary] confidence: high
  Reason: Disabled because a summary view collapses the detailed consequence data needed for impact assessment.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only resource and is NOT APPLICABLE to a mouse study.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource and is NOT APPLICABLE to a mouse study.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool and is NOT APPLICABLE to a mouse study.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool and is NOT APPLICABLE to a mouse study.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --canonical --protein --biotype --numbers --domains --coding_only
```
*Note: On the Ensembl VEP web interface, ensure you select "Mouse" as the species to prevent the tool from attempting to pull human-only datasets.*
