## User Query
Prioritize rare protein-altering variants in a patient with a suspected Mendelian disorder.

## Recommendation
### 1. Detected Use Case
**Category:** `rare_disease_germline`  
**Reason:** The user is investigating a patient with a suspected Mendelian (rare) disorder and focusing on identifying "protein-altering" variants, which requires deep transcript-level annotation, pathogenicity prediction (SIFT/PolyPhen), population frequency filtering (gnomAD), and clinical database cross-referencing (ClinVar).

### 2. Recommended Options
✓ **transcript_set** [source: transcript_set, priority=critical] confidence: high
  Reason: Using the default Ensembl/GENCODE annotation provides the most comprehensive set of transcripts for identifying all possible protein-altering effects.

✓ **mane_select** [source: mane_select, priority=critical] confidence: high
  Reason: Essential for reducing redundancy by focusing on the single transcript that is matched between NCBI and EBI, making variant interpretation much cleaner.

✓ **canonical** [source: canonical, priority=recommended] confidence: high
  Reason: A recommended flag to identify the primary transcript used in most clinical annotations.

✗ **pick** [source: pick] confidence: high
  Reason: Disabled because you should use MANE Select for filtering downstream; keeping all transcripts allows a more detailed review of all possible coding impacts.

✗ **per_gene** [source: per_gene] confidence: high
  Reason: Disabled because we need transcript-level detail (e.g., different effects on different splice sites) rather than just one result per gene.

✗ **most_severe** [source: most_severe] confidence: high
  Reason: Disabled because it is incompatible with the transcript-level annotations and scores (SIFT, PolyPhen, HGVS) needed to evaluate protein function.

✗ **summary** [source: summary] confidence: high
  Reason: Disabled because we need detailed per-transcript consequence data and scores, not a collapsed single-line summary.

✓ **sift** [source: sift b, priority=critical] confidence: high
  Reason: A critical tool for predicting whether an amino acid substitution affects protein function based on sequence homology.

✓ **polyphen** [source: polyphen b, priority=critical] confidence: high
  Reason: A critical predictor of the impact of substitutions on protein structure and function.

✓ **cadd** [source: cadd, priority=recommended] confidence: high
  Reason: Provides an integrated metric of deleteriousness across many different types of variants.

✓ **revel** [source: revel, priority=recommended] confidence: high
  Reason: An ensemble method that is highly effective at prioritizing protein-altering variants in rare disease studies.

✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Essential to check if the variant has already been reported with a known clinical significance.

✓ **check_existing** [source: check_existing, priority=critical] confidence: high
  Reason: Required to link variants to known identifiers like rsIDs and ClinVar significance.

✓ **gnomad_af** [source: gnomad_af, priority=critical] confidence: high
  Reason: Crucial for filtering out common variants that are unlikely to cause a rare Mendelian disorder.

✓ **hgvs** [source: hgvs, priority=critical] confidence: high
  Reason: Provides standard nomenclature (HGVSc/HGVSp) essential for clinical reporting and communication.

✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Enhances readability by providing the HGNC gene symbol (e.g., BRCA1).

✓ **domains** [source: domains, priority=recommended] confidence: high
  Reason: Helps prioritize variants that fall within functionally important protein domains/motifs.

✓ **gene_phenotype** [source: gene_phenotype, priority=recommended] confidence: high
  Reason: Provides context by linking the gene to known OMIM or Orphanet disease phenotypes relevant to the patient.

✗ **regulatory** [source: regulatory] confidence: medium
  Reason: Disabled because the primary focus is on protein-altering (coding) variants, not regulatory/non-coding elements.

✗ **spliceai** [source: spliceai] confidence: medium
  Reason: While useful for many rare disease cases, it is specifically focused on splicing; SIFT/PolyPhen are more direct for "protein-altering" prioritization.

### 3. Generated VEP Command
```bash
vep --input_file patient_variants.vcf --output_file annotated_variants.txt \
--cache --format vcf --force_overwrite \
--gencode_basic \
--mane_select \
--canonical \
--sift b \
--polyphen b \
--check_existing \
--symbol \
--hgvs \
--domains \
--gene_phenotype \
--plugin CADD,snv=/path/to/SNVs.tsv.gz,indels=/path/to/InDels.tsv.gz \
--plugin REVEL,file=/path/to/revel_scores.tsv.gz \
--af_gnomade
```
*Note: For the Web Interface, ensure "MANE Select", "Canonical", "SIFT", "PolyPhen", and "ClinVar" are checked in the configuration settings.*
