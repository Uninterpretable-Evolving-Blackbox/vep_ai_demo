# VEP Recommendation

**Date:** 2026-09-15T10:36:22.266623

## User Query
Mouse germline WGS, SNV and indel variants; rapid top-line functional annotation for protein-coding and regulatory regions.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Mouse)
- **origin**: germline (Mouse germline WGS)
- **variant_size_class**: small (SNV and indel variants)
- **region_focus**: coding, regulatory-noncoding (protein-coding and regulatory regions)
- **analysis_goal**: basic-consequence (rapid top-line functional annotation)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for providing the underlying Ensembl/GENCODE gene and transcript annotations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the results much more human/biological-readable.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on whether the hit is protein_coding, lincRNA, etc., which is vital for functional assessment.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature for the variants based on Ensembl identifiers.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, which is critical for prioritizing the most likely functional consequence.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) for coding variants to facilitate protein-level analysis.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to identify overlaps with regulatory regions (promoters, enhancers, etc.).
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information (e.g., Pfam) to provide functional context for coding variants.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon/intron numbering, essential for localizing the variant within the gene structure.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Recommended to check if these mouse variants are already cataloged in existing variation databases.
✓ sift [source: sift, priority=no priority] confidence: medium
  Reason: SIFT is available for species with SIFT data (including mouse) and provides rapid functional prediction for missense variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled to allow for full per-transcript detail; "top-line" annotation usually requires seeing all relevant consequences in a WGS context.
✗ summary [source: summary] confidence: high
  Reason: Disabled to ensure detailed functional annotations are provided rather than a collapsed view.
✗ polyphen [source: polyphen] confidence: high
  Reason: NOT APPLICABLE; PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is a human-only tool.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: NOT APPLICABLE; gnomAD is human-only.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar data is human-centric.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --biotype --canonical --protein --regulatory --domains --numbers --check_existing --sift
```
*Note: In the Ensembl VEP Web Interface, select "Mouse" as the species, enable "Gene symbol", "HGVS nomenclature", "Transcript biotype", "Canonical transcript", "Protein ID", "Regulatory regions", "Protein domains", "Exon/intron numbering", and "SIFT". Do not enable any human-specific plugins like CADD or PolyPhen.*
