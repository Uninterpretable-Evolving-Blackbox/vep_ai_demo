  Reason: Necessary to identify overlaps with promoters, enhancers, and other regulatory elements as requested.

  Reason: Highly relevant for CNVs to identify if the affected genes are sensitive to changes in copy number (e.g., pHaplo).

  Reason: Essential for structural variants to distinguish between common benign CNVs and potentially pathogenic ones using gnomAD-SV frequencies.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to help localize the exact impact of the CNV.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Helps prioritize transcripts based on their Transcript Support Level.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Assists in identifying functionally important isoforms in the context of structural disruptions.

  Reason: HGVS nomenclature is typically used for short variants (SNVs/Indels) and is not applicable to large-scale CNVs/structural variants.

  Reason: This plugin is for missense/short variant pathogenicity scores and is NOT APPLICABLE for structural variants.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts the effect of amino acid substitutions; it is NOT APPLICABLE for structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts the effect of amino acid substitutions; it is NOT APPLICABLE for structural variants/CNVs.
✗ cadd [source: cadd] confidence: high

✗ most_severe [source: most_severe] confidence: medium
  Reason: The user wants to identify consequences across both coding and regulatory regions; restricting to a single "most severe" term might hide the regulatory impact if a coding impact is detected.
