### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --everything --symbol --tsl --appris --mane --regulatory --dosage_sensitivity --clinvar --phenotypes --cadd --biotype --numbers --plugin gnomad_sv,/path/to/gnomad_sv.vcf.gz --plugin Mastermind --plugin LOEUF
```
*Note: The `--everything` flag is a shorthand often used in web interfaces, but in command line, it is better to be explicit. For the `--plugin gnomad_sv` option, you must provide the path to the local gnomAD SV VCF file. The `--plugin Mastermind` and `--plugin LOEUF` require the respective plugin data files to be installed in your VEP directory.*
