### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --hgvs --check_existing --regulatory --maxentscan --phenotypes --canonical --plugin Phenotypes,/path/to/phenotypes.tab
```
*Note: The `--plugin Phenotypes` requires a local database for zebrafish. On the Ensembl Web Interface, ensure 'Regulatory' and 'Phenotypes' are checked. Note that many human-centric tools (ClinVar, gnomAD, CADD) are excluded as they are not applicable to Danio rerio.*
