## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation

- **species**: human (explicitly stated "human somatic")
- **origin**: somatic (explicitly stated "tumor biopsies")
- **variant_size_class**: structural-CNV (explicitly stated "structural variants and copy number alterations")
- **region_focus**: coding (explicitly stated "protein-coding genes")
- **analysis_goal**: basic-consequence (indicated by "quick top-line call... without necessarily needing an exhaustive breakdown")

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps categorize the type of genes being disrupted (e.g., protein_coding) to provide context for the CNVs.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for the primary consequence calculation using Ensembl/GENCODE core annotations.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs as it identifies genes where changes in copy number (dosage) are known to cause disease.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variants to check if the observed CNVs/SVs are present in population databases.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is useful for a top-line understanding of where the disruption occurs.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides human-readable HGNC gene symbols, essential for a "quick top-line call" on disrupted genes.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize the most reliable transcripts affected by the alterations.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify the most functionally important isoforms being disrupted by the structural changes.
✗ hgvs [source: hgvs] confidence: high
  Reason: User specifically requested to avoid exhaustive breakdowns of small-scale nucleotide changes.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with several recommended options like symbol and tsl, and may hide useful overlapping information.
✗ regulatory [source: regulatory] confidence: high
  Reason: The user's focus is strictly on protein-coding regions, not regulatory or non-coding elements.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, this is a filter rather than an annotation; however, since the user is looking at CNVs, they want the consequence of the CNV on the coding gene, which VEP handles via standard annotation.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Primarily used for missense SNVs, which the user wants to bypass at this stage.
✗ spliceai [source: spliceai] confidence: high
  Reason: Primarily used for predicting splice-site impact of small variants, not large structural alterations.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --tsl --appris --dosage_sensitivity --gnomad_sv --numbers
```
*Note: The `--gnomad_sv` option requires the custom gnomAD SV VCF file to be provided via the `--custom` flag in a local environment.*
