## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation
### 1. Detected Scenario
- **species**: human (explicitly stated)
- **origin**: somatic (from "tumor biopsies")
- **variant_size_class**: structural-CNV (identified "structural variants and copy number alterations")
- **region_focus**: coding (goal is to see "which protein-coding genes are being disrupted")
- **analysis_goal**: basic-consequence (request for a "quick top-line call... without necessarily needing an exhaustive breakdown")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to use the Ensembl/GENCODE core annotation set to drive consequence calculations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols (e.g., TP53) to make the results human-readable for identifying disrupted genes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps confirm if the disrupted regions are protein_coding or other types of genomic features.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variants to annotate allele frequencies from the gnomAD SV database to filter out common variants.
✓ canonical [source: canonical, priority=recommended] confidence: medium
  Reason: Helps identify the primary transcript version of the disrupted genes for a "top-line" view.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: medium
  Reason: Highly relevant for CNVs (gains/losses) to identify if the disrupted gene is sensitive to dosage changes (e.g., haploinsufficiency).
✓ tsl [source: tsl, priority=recommended] confidence: medium
  Reason: Adds Transcript Support Level to help prioritize high-confidence transcripts in the disrupted regions.
✓ loeuf [source: loeuf, priority=recommended] confidence: medium
  Reason: Provides gnomAD LOEUF scores which help assess the evolutionary constraint of the genes being lost/gained.
✗ hgvs [source: hgvs] confidence: high
  Reason: Not required for the high-level gene disruption analysis requested; HGVS is more suited for single nucleotide changes.
✗ sift [source: sift] confidence: high
  Reason: Not applicable to structural variants/CNVs; these predictors are for missense single nucleotide variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: Not applicable to structural variants/CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: Not applicable to structural variants/CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: While the user wants a "top-line call," disabling this allows the user to see which genes are hit without collapsing all transcript details, which is safer for SV interpretation.
✗ summary [source: summary] confidence: high
  Reason: A summary output is too restrictive for understanding the nature of a structural disruption.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --canonical --tsl --loeuf --dosage_sensitivity --custom gnomad_sv,gnomAD_SV_VCF,exact,/path/to/gnomad_sv.vcf.gz
```
*Note: The `--custom` flag requires a path to a gnomAD SV VCF file. In the Ensembl Web Interface, these can be selected via the 'Custom' or 'Plugins' sections.*
