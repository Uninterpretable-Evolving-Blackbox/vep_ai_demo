### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to define the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols (e.g., BRCA1) which is vital for human clinical interpretation.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps identify if the CNV affects protein-coding genes, lincRNAs, etc., which is key for regulatory/non-coding focus.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to determine if the structural changes overlap with promoters, enhancers, or CTCF binding sites.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically needed to annotate structural variants with gnomAD SV allele frequencies to check how common they are in healthy populations.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs (duplications/deletions) to identify if the affected genes are sensitive to changes in copy number (e.g., pHaplo scores).
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if the CNV coordinates overlap with known short variants or previously reported IDs.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Critical for clinical interpretation to see if the affected genomic regions or variants have known clinical significance.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Provides gene-phenotype associations to help interpret the clinical impact of the CNV.
✓ canonical [source: canonical, priority=recommended] confidence: medium
  Reason: Helps prioritize the impact on the primary functional transcript.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for short variants (SNVs/indels) and is not the standard for structural variant reporting in this context.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single amino acid substitutions; it is not applicable to structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single amino acid substitutions; it is not applicable to structural variants/CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are designed for small variants (SNVs/indels) and do not apply to structural variations.
✗ most_severe [source: most_severe] confidence: high
  Reason: For structural variants, you need to see all overlapping features (genes, regulatory elements) rather than a single collapsed consequence.
✗ summary [source: summary] confidence: high
  Reason: Summary mode collapses data, which would hide the detailed gene/regulatory overlaps needed for CNV interpretation.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --regulatory --gnomad_sv <path_to_gnomad_sv.vcf.gz> --plugin DosageSensitivity --check_existing --clinvar --phenotypes --canonical
```
*Note: The `--plugin DosageSensitivity` and `--gnomad_sv` flags require their respective data files to be present. On the Ensembl Web Interface, enable "Gene Symbol", "Transcript Biotype", "Regulatory Build", "gnomAD SV", "Dosage Sensitivity", "ClinVar", "Phenotypes", and "Canonical transcript".*
