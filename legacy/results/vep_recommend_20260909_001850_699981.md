## User Query
I have somatic SNVs and indels from a mouse tumor. I need to identify the functional impact of both coding and regulatory variants for a preliminary pathogenicity assessment.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (specified as "mouse")
- **origin**: somatic (specified as "somatic SNVs and indels")
- **variant_size_class**: small (specified as "SNVs and indels")
- **region_focus**: coding, regulatory-noncoding (specified as "both coding and regulatory variants")
- **analysis_goal**: clinical-interpretation (specified as "preliminary pathogenicity assessment")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to define the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is critical for identifying relevant genes in a mouse model.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature for variants, which is necessary for standardized reporting and downstream functional validation.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and other features like lincRNA or miRNA, essential for interpreting regulatory vs. coding hits.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Enables detection of overlaps with regulatory regions (promoters, enhancers) as requested for the non-coding part of the analysis.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene in the mouse genome.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link coding variants to their protein-level consequences.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information (e.g., Pfam), which is crucial for assessing the functional impact of a mutation on a specific protein region.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Essential for assessing the impact of indels and SNVs on splice sites, even in non-human species.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based missense impact prediction available for species with SIFT data like mouse.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations for the genes hit, aiding the preliminary pathogenicity assessment.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is necessary to localize the variant within the gene structure.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to check if these somatic variants have been previously recorded in mouse variation databases.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because it conflicts with hgvs, symbol, and sift; for pathogenicity assessment, you need the full per-transcript detail rather than a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: Disabled because it conflicts with hgvs, symbol, and sift; detailed annotations are required for assessment.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is a human-specific clinical database.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: NOT APPLICABLE; gnomAD is a human-specific database.
✗ polyphen [source: polyphen] confidence: high
  Reason: NOT APPLICABLE; PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is a human-only resource.

### 3. Generated VEP Command
```
vep --input_file mouse_tumor.vcf --output_file mouse_annotation.txt --cache --format vcf --vcf --symbol --hgvs --biotype --regulatory --canonical --protein --domains --maxentscan --sift --phenotypes --numbers --check_existing --plugin Phenotypes [--dir_cache /path/to/cache]
```
*Note: In the web interface, ensure you select "Mouse" as the species and manually enable the regulatory and plugin options.*
