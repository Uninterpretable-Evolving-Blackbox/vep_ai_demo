### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for identifying the type of transcript (e.g., protein_coding) being affected.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most reliable transcript for interpreting the functional impact of the variant.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Allows the detection of known variants in the mouse genome to provide context for pathogenicity.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Necessary to define the primary annotation set driving the consequence calculation.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Crucial for clinical-interpretation to see if a variant hits a known functional protein domain.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized nomenclature for the protein-altering changes, which is vital for reporting and further analysis.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based prediction of splice site impact, which is relevant for indels in coding/splice regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is standard for describing variant positions in coding regions.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: If phenotype data is available for the mouse model, this helps link the variant to biological functions.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP), linking the variant to the specific protein product.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides a species-specific prediction of whether a missense substitution affects protein function.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds the gene symbol to make the results interpretable.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, disabling this prevents losing information about variants that might impact the edges of coding regions (like splice sites), though it can be an add-on.
