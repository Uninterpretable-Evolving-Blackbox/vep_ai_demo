## User Query
I am starting to set up the pipeline for our human tumor-only whole genome sequencing data from a large cancer cohort, but I am still a bit unsure about how to best capture all the relevant information. We have identified several structural variants and copy number alterations, and my goal is to get a quick top-line summary of their functional consequences. Specifically, I need to see how these changes affect protein-coding regions—ideally identifying impacts on the most reliable transcripts—but I also want to capture any potential disruptions to regulatory or non-coding elements. Additionally, it would be really helpful if the results provided context regarding population allele frequencies so I can distinguish these somatic hits from common germline variation.

  Reason: Essential to provide the underlying Ensembl/GENCODE gene and transcript annotations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to make results human-readable and useful for identifying affected genes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Necessary to identify if the SV/CNV disrupts coding genes, lincRNAs, or other regulatory elements.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps identify the impact on the most reliable/representative transcript for a gene.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to capture disruptions to promoters, enhancers, and other non-coding regulatory elements.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variants to provide gnomAD SV allele frequencies to filter out common germline CNVs.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs/structural variants to assess if the affected gene is sensitive to copy number changes (e.g., pHaplo).
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help prioritize the most well-supported transcripts.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to identify if the SV/CNV coordinates overlap with known variants in databases.
✓ most_severe [source: most_severe, priority=optional] confidence: medium
  Reason: Requested a "quick top-line summary"; this collapses multiple consequences into the single most severe term per variant.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for SNVs/indels; it is not applicable for structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide changes; not applicable to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor; not applicable to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are primarily designed for small variants (SNVs/indels); not applicable for CNVs.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a meta-resource for missense variants; not applicable for structural variants.
✗ pick [source: pick] confidence: high
  Reason: Conflict with `most_severe`; since the user wants a "top-line summary," `most_severe` is the preferred way to collapse results.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --canonical --regulatory --gnomad_sv <path_to_gnomad_sv.vcf.gz> --dosage_sensitivity --tsl --most_severe --check_existing
```
*Note: On the Ensembl Web Interface, select "Human" as species, enable "Gene Symbol", "Transcript Biotype", "Canonical Transcript", "Regulatory Build", "gnomAD SV frequencies", "Dosage Sensitivity", "Transcript Support Level", and set "Restrict results" to "Most severe".*
