# VEP Recommendation

**Date:** 2026-09-15T11:25:50.620076

## User Query
I have somatic SNVs and indels from a mouse tumor. I need to identify the functional impact of both coding and regulatory variants for a preliminary pathogenicity assessment.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (requested both)
- **analysis_goal**: clinical-interpretation (preliminary pathogenicity assessment)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to drive consequence calculation using the Ensembl/GENCODE core annotation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is necessary for identifying affected genes in a tumor.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature, essential for standardized reporting of somatic changes.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, helping to assess if a mutation hits a functional site.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with regulatory regions (promoters, enhancers) as requested.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides transcript context (e.g., protein_coding vs lincRNA) for both coding and regulatory regions.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most likely functional transcript for the mutation.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level changes.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based splice site scoring, which is useful for assessing indel/SNV impact on splicing.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides species-specific (non-human) missense impact prediction if data is available for the organism.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to precisely locate variants within gene structures.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Surfaces known phenotype/disease associations for the genes hit, aiding pathogenicity assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for checking if the somatic variants co-locate with known variants in the mouse genome.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only database and is not applicable to mouse studies.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only meta-resource.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this ensures you see all transcript consequences; in somatic studies, you need the full detail per transcript to identify driver potential.
✗ summary [source: summary] confidence: high
  Reason: Disabling this to avoid losing detailed annotation required for pathogenicity assessment.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --symbol --hgvs --domains --regulatory --biotype --canonical --protein --maxentscan --sift --numbers --phenotypes --check_existing
```
*(Note: On the Ensembl Web Interface, ensure you select the "Mouse" species and enable the corresponding checkboxes for Symbol, HGVS, Domains, Regulatory, Biotype, Canonical, Protein, MaxEntScan, SIFT, Numbers, and Phenotypes. Do not select any human-specific frequency or pathogenicity plugins.)*
