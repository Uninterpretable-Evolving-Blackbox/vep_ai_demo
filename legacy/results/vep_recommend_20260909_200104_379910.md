## User Query
Mouse germline WGS, SNV and indel variants; rapid top-line functional annotation for protein-coding and regulatory regions.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Mouse)
- **origin**: germline (Mouse germline WGS)
- **variant_size_class**: small (SNV and indel variants)
- **region_focus**: coding, regulatory-noncoding (protein-coding and regulatory regions)
- **analysis_goal**: basic-consequence (rapid top-line functional annotation)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Necessary to define the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output to make results more human/organism-readable.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to distinguish between protein-coding, miRNA, and other feature types.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature for the variants.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to fulfill the user's goal of annotating regulatory regions.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, useful for functional annotation of coding variants.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link results to protein-level data.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is vital for functional localization.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: Species is non-human; gnomAD is human only.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar data is human-only.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only meta-resource.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only prediction tool.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only predictor.
✗ most_severe [source: most_severe] confidence: medium
  Reason: User requested "top-line functional annotation"; disabling `most_severe` allows seeing the full range of consequences across transcripts, which is better for WGS analysis.
✗ summary [source: summary] confidence: medium
  Reason: Disabling `summary` ensures detailed annotations are provided rather than a collapsed view.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --hgvs --regulatory --canonical --domains --protein --numbers --core_type merged
```
*Note: Web interface equivalents include checking the boxes for Symbol, Biotype, HGVS, Regulatory, Canonical, Domains, Protein, and Numbers. Ensure the "Restrict results" dropdown is set to "All" rather than "Most severe" or "Summary" to maintain detail.*
