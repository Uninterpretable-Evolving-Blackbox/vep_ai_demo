### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to provide the base transcript/gene annotation set for consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results more human-readable for clinical review.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Identifies the type of feature hit (e.g., protein_coding, lincRNA), which is crucial for interpreting the impact of large structural changes.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to identify impacts on regulatory regions (promoters, enhancers, etc.).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for population frequency of structural variants; provides gnomAD SV allele frequencies to filter common variants.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Critical for CNVs/structural variants to determine if the affected gene is sensitive to changes in copy number (e.g., pHaplo).
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Helps identify if the structural change overlaps with known variants in databases.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance for co-located variants, aiding in clinical interpretation.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Links affected genes to known phenotypes, helping to connect chromosomal changes to the patient's presentation.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for small variants (SNPs/indels) and is not the standard for describing large-scale structural/CNV changes.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This meta-resource is for missense/small variants and is not applicable to structural-CNV.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single amino acid substitutions, not applicable to CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor and is not applicable to structural variations.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is designed for small variants and is not applicable to structural-CNV.
✗ most_severe [source: most_severe] confidence: high
  Reason: In clinical SV analysis, you need to see all overlapping features (genes and regulatory elements) rather than a single collapsed consequence.
✗ summary [source: summary] confidence: high
  Reason: A summary view would hide the detailed regulatory and gene-specific information required for this analysis.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin DosageSensitivity --plugin gnomad_sv --plugin Phenotypes --regulatory --symbol --biotype --check_existing --clinvar
```
*Note: The `--plugin gnomad_sv` requires the specific gnomAD SV VCF file to be provided via a path. On the Ensembl Web Interface, ensure "Regulatory" and "Dosage Sensitivity" are selected in the optional settings.*
