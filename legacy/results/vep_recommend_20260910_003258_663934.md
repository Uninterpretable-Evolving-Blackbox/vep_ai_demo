# VEP Recommendation

**Date:** 2026-09-10T00:32:58.664279

## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (indicated by "mouse model")
- **origin**: somatic (indicated by "tumor tissue" and "driving the tumor progression")
- **variant_size_class**: small (indicated by "single letter changes as well as small additions or removals")
- **region_focus**: coding, regulatory-noncoding (indicated by "impact on protein-coding sequences and any potential effects on the control regions")
- **analysis_goal**: clinical-interpretation (indicated by "tell which of these changes look like they might actually be driving the tumor progression")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Necessary to drive consequence calculation using the Ensembl/GENCODE core annotation set.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is essential for identifying candidate driver genes in a cancer model.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, which is critical for standardizing the description of the somatic changes identified.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, helping to interpret if a somatic change hits a functional site of a protein.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to detect overlaps with regulatory regions (promoters/enhancers) as requested for the control regions.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding and non-coding (regulatory) features.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP) to link variants to protein-level changes.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most likely functional transcript for each gene in the mouse model.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based splice site scoring, which is important for both coding and regulatory-adjacent variants.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides species-specific missense prediction for mouse to help identify potential driver mutations in proteins.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, essential for localizing variants in both coding and regulatory regions.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for checking if the identified somatic variants are present in known mouse variation databases.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: medium
  Reason: Helps link variants to known phenotype associations in mouse models to support driver interpretation.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only resource and is not applicable to a mouse model.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only database.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only meta-resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflict: Enabling this would disable hgvs, symbol, sift, and protein, which are all required for your clinical-style interpretation.
✗ summary [source: summary] confidence: high
  Reason: Conflict: Summary mode would collapse the detailed transcript and regulatory information you need to see.

### 3. Generated VEP Command
```
vep --input_file somatic_mouse_variants.vcf --output_file annotated_variants.txt --cache --format vcf --vcf --symbol --hgvs --domains --regulatory --biotype --protein --canonical --maxentscan --sift --numbers --check_existing --phenotypes
```
*Note: On the Ensembl Web Interface, ensure you select the "Mouse" species and check the boxes for Symbol, HGVS, Domains, Regulatory, Biotype, Protein, Canonical, MaxEntScan, SIFT, Numbers, and Phenotypes. Do not select "Most Severe" or "Summary".*
