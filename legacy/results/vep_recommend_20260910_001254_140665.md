### 3. Generated VEP Command
```
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --symbol --tsl --appris --biotype --regulatory --dosage_sensitivity --numbers --plugin LOEUF --plugin ClinPred --check_existing --custom gnomAD_SV,file,/path/to/gnomad_sv.vcf.gz,exact --custom clinvar,file,/path/to/clinvar.vcf.gz,exact
```
*Note: The `--custom` flags for gnomAD_SV and ClinVar require local paths to the respective VCF files. On the Ensembl Web Interface, these can be selected via the 'Custom datasets' and 'Check existing' dropdowns.*
