## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the Ensembl/GENCODE core annotation is the standard for driving consequence calculations in non-human species.

  Reason: Essential for clinical/functional interpretation to provide standardized nomenclature for the identified changes.

  Reason: Helps interpret the functional impact of coding changes by identifying if they overlap known protein domains.

  Reason: Adds gene symbols to the output, which is critical for biological interpretation of tumor drivers.

  Reason: Directly addresses the need to analyze effects on "control regions surrounding the genes" by looking for overlaps with promoters/enhancers.

  Reason: Helps prioritize the most biologically relevant transcript for each gene during interpretation.

  Reason: Provides the Ensembl protein ID (ENSP), linking the variants to protein-level changes.

  Reason: Distinguishes between protein-coding genes and other regulatory features (e.g., lincRNA).

  Reason: Provides sequence-based scoring for potential splice-site disruptions, which is vital for identifying functional variants.
