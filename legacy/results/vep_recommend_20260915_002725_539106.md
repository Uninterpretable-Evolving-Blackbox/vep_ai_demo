## User Query
I am analyzing somatic SNVs and indels from a mouse tumor WES to quickly identify any high-impact protein-coding variants.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor WES)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (protein-coding variants)
- **analysis_goal**: basic-consequence (identify high-impact variants)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Necessary to drive the consequence calculation using the Ensembl/GENCODE annotation set.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, essential for identifying which genes are affected.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature for coding variants, which is critical for describing protein-level changes.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), useful for linking results to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds transcript biotype to provide context for the coding regions.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript, helping to prioritize the most biologically relevant transcript for impact assessment.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon and intron numbering, which is vital for localizing the impact within the coding sequence.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds overlapping protein domain information (e.g., Pfam), which is critical for determining if a variant hits a functional site.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these somatic variants overlap with known variation in the mouse genome.
✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Since the goal is specifically "protein-coding variants," this restricts output to relevant consequences.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Predicts if a premature stop codon might escape nonsense-mediated decay, a key factor in "high-impact" assessment.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with hgvs and symbol; for somatic analysis, it is better to see full transcript detail to assess impact properly.
✗ summary [source: summary] confidence: high
  Reason: Collapses data into a single line, which prevents detailed assessment of protein-level impact.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is human-only.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is human-only.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is human-only.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is human-only.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is human-only.
✗ alpha_missense [source: alphamissense] confidence: high
  Reason: AlphaMissense is human-only.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --protein --biotype --canonical --numbers --domains --check_existing --coding_only --plugin NMD
```
