### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to define the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results more human-readable for functional assessment.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to distinguish between coding genes, lincRNAs, and other regulatory features.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Enables overlap detection with Ensembl's Regulatory Build (promoters, enhancers, etc.) as requested.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps identify the most biologically relevant transcript for each gene.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to assess the quality of the transcript annotation.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is helpful for localizing the impact of CNVs.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically designed for structural variants/CNVs to provide population-level allele frequencies.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNV analysis to identify if a gene is sensitive to copy number changes (e.g., haploinsufficiency).
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for short variants (SNVs/Indels) and is not applicable to CNVs.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This meta-resource is for missense variants; not applicable to structural variants.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts amino acid substitution effects; not applicable to structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts protein structure impact of missense mutations; not applicable to structural variants/CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are designed for single-nucleotide variants, not CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: Disabling this allows the user to see all overlapping consequences, which is important when a CNV spans multiple regulatory/coding features.
✗ summary [source: summary] confidence: high
  Reason: The user wants to identify functional consequences; a summary mode would collapse too much information.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --regulatory --canonical --tsl --numbers --plugin DosageSensitivity --custom gnomad_sv,gnomad_sv_file.vcf,type=exact --core_type ensembl
```
*Note: The `--custom` flag for `gnomad_sv` requires a local path to the gnomAD SV VCF file. In the Ensembl Web Interface, these correspond to the "Gene/Transcript" and "Regulatory" checkboxes and the "Dosage Sensitivity" and "gnomAD SV" plugins.*
