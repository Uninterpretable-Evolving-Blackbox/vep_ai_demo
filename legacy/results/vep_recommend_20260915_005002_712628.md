# VEP Recommendation

**Date:** 2026-09-15T00:50:02.712779

## User Query
I am currently reviewing exome sequencing results from a cohort of mice used in our recent developmental study. We have identified several single-letter changes and small additions or deletions throughout the genome. For my preliminary report, I just need to quickly identify which of these variations actually alter the protein sequence or create an early stop signal within the coding regions.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (implied by "identified several... changes" in a cohort study, though could be germline; however, no specific clinical/tumor context is provided, so defaults to standard annotation)
- **variant_size_class**: small (single-letter changes and small additions/deletions)
- **region_focus**: coding (explicitly requested "alter the protein sequence or create an early stop signal")
- **analysis_goal**: basic-consequence (requested a "quick" identification of protein-altering effects)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the Ensembl/GENCODE core annotation to drive consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the preliminary report readable.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature which is standard for reporting protein-altering changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish protein-coding genes from other transcript types.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link changes directly to protein-level effects.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most likely functional transcript for each gene.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, useful for locating the change within the coding sequence.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is critical for assessing the impact of protein-altering changes.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with recommended options like hgvs, symbol, and protein; you need the full detail to see the specific protein change.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with the need for detailed protein-level consequences and identifiers.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only resource and is not applicable to mice.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource and is not applicable to mice.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool and is not applicable to mice.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool and is not applicable to mice.
✗ coding_only [source: coding_only] confidence: medium
  Reason: While the user focuses on coding, keeping it OFF allows seeing if a variant hits a splice site that *affects* coding, though it can be turned ON to speed up processing if the VCF is massive.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --symbol --hgvs --biotype --protein --canonical --numbers --domains
```
*Note: In the Ensembl Web Interface, select "Mouse" as the species, and enable "Gene Symbol", "HGVS", "Transcript Biotype", "Protein ID", "Canonical", "Exon/Intron Numbering", and "Protein Domains".*
