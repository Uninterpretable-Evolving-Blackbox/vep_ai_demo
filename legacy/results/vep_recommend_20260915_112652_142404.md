## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

- **region_focus**: coding (explicitly stated as "protein-coding genes")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Provides the essential Ensembl/GENCODE gene annotation required for all consequence calculations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Crucial for a "top-line call" to identify the specific genes (e.g., TP53) being disrupted.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and other transcript types being hit by the CNVs.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for structural variants to determine if the CNV is a common population polymorphism or a potentially rare somatic event.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps simplify the "top-line" view by flagging the primary transcript for each disrupted gene.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs/structural variants to identify if the gene is sensitive to changes in copy number (e.g., haploinsufficiency).
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to gauge the reliability of the transcript annotation being hit.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is helpful for basic context of the disruption.
✗ hgvs [source: hgvs] confidence: high
  Reason: User requested a "top-line call" and specifically wants to avoid "exhaustive breakdown of every small-scale nucleotide change."
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide variants; not applicable to structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single nucleotide variants; not applicable to structural variants/CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a pathogenicity predictor for small-scale variants; not applicable to structural variants/CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While the user wants a "top-line" view, disabling this allows them to see the actual consequence (e.g., gene loss) rather than just a collapsed term.
✗ summary [source: summary] confidence: medium
  Reason: A summary output would be too reductive for interpreting structural disruptions.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --canonical --tsl --numbers --dosage_sensitivity --plugin gnomad_sv,/path/to/gnomad_sv.tar.gz
```
*(Note: In the Ensembl Web Interface, select "Symbol", "Biotype", "Canonical", "TSL", "Numbers", and use the "Dosage Sensitivity" and "gnomAD SV" plugins.)*
