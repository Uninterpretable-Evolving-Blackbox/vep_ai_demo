# VEP Recommendation

**Date:** 2026-07-21T11:18:25.923186

## User Query
I have a VCF of human germline variants from a rare disease trio and want to find the likely pathogenic coding variant

## Recommendation
### 1. Detected Use Case
**Category:** `rare_disease_germline`
**Reason:** The user is analyzing a human trio (proband and parents) to identify variants responsible for a rare Mendelian disorder. This necessitates focusing on coding-region pathogenicity, population frequency filtering to exclude common variants, and leveraging clinical databases like ClinVar and MANE Select.

### 2. Recommended Options

✓ **hgvs** [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature, which is essential for clinical reporting and variant identification.

✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Adds human-readable gene symbols (e.g., BRCA1), making the results interpretable for clinicians.

✓ **check_existing** [source: check_existing, priority=critical] confidence: high
  Reason: Essential to link input variants to known identifiers like rsIDs and facilitate ClinVar lookups.

✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Crucial for determining if the variant has been previously reported as pathogenic or benign in clinical databases.

✓ **mane** [source: mane, priority=critical] confidence: high
  Reason: Uses MANE Select transcripts to ensure analysis focuses on the most clinically relevant, standardized transcript.

✓ **sift** [source: sift, priority=critical] confidence: high
  Reason: Provides a standard prediction of whether an amino acid substitution affects protein function.

✓ **polyphen** [source: polyphen, priority=critical] confidence: high
  Reason: Complements SIFT by predicting the structural and functional impact on proteins.

✓ **cadd** [source: cadd, priority=recommended] confidence: high
  Reason: Provides an integrated score representing the overall deleteriousness of a variant.

✓ **af_gnomade** [source: af_gnomade, priority=critical] confidence: high
  Reason: Necessary to filter out common variants in the population that are unlikely to cause rare Mendelian disease.

✓ **af_gnomadg** [source: af_gnomadg, priority=critical] confidence: high
  Reason: Provides comprehensive allele frequency data from gnomAD genome-scale populations.

✓ **loeuF** [source: loeuf, priority=recommended] confidence: medium
  Reason: Helps assess if the gene is under evolutionary constraint (loss-of-function intolerance), which is relevant for rare disease genes.

✓ **biotype** [source: biotype, priority=recommended] confidence: high
  Reason: Allows filtering of results to focus specifically on protein-coding transcripts.

✓ **domains** [source: domains, priority=recommended] confidence: medium
  Reason: Identifies if a missense mutation occurs within a functionally significant protein domain (e.g., Pfam).

✓ **dbnsfp** [source: dbnsfp, priority=recommended] confidence: high
  Reason: Provides access to an aggregated meta-resource of many different pathogenicity prediction scores.

✓ **coding_only** [source: coding_only, priority=optional] confidence: high
  Reason: Reduces noise by restricting output to consequences within the protein-coding regions, matching the user's goal.

✗ **most_severe** [source: most_severe] confidence: high
  Reason: Must be disabled because it is incompatible with detailed annotations like SIFT, PolyPhen, and HGVS required for pathogenicity assessment.

✗ **summary** [source: summary] confidence: high
  Reason: Must be disabled to allow the output of all transcript-level details and predictions rather than a condensed overview.

✗ **regulatory** [source: regulatory] confidence: high
  Reason: Disabled because the analysis is specifically focused on coding variants, and regulatory features would increase runtime unnecessarily.

✗ **maxentscan** [source: maxentscan] confidence: medium
  Reason: Not required unless there is a specific hypothesis regarding splice-site disruption; standard clinical screening focuses on coding impact.

### 3. Generated VEP Command
```bash
vep --input_file trio_variants.vcf \
    --output_file clinical_analysis_results.txt \
    --cache \
    --format vcf \
    --hgvs \
    --symbol \
    --check_existing \
    --clinvar \
    --mane \
    --sift \
    --polyphen \
    --cadd \
    --af_gnomade \
    --af_gnomadg \
    --plugin LOEUF \
    --biotype \
    --domains \
    --plugin dbNSFP \
    --coding_only
```

**Note:** When using the Ensembl Web Interface, ensure you select "All" for transcripts or specifically use "MANE Select" if available. The `--plugin` flags (CADD, LOEUF, dbNSFP) require that the respective local cache/files are installed on your server environment.
