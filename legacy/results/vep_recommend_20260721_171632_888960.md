## Recommendation
### 1. Detected Use Case
**Category:** `rare_disease_germline`  
**Reason:** The query specifies "germline rare disease exome" and the goal is to identify "likely pathogenic coding variants." This requires a high-sensitivity workflow that prioritizes clinical significance (ClinVar), population frequency filtering (gnomAD), and protein-impact prediction (SIFT/PolyPhen/CADD) for protein-altering variants.

### 2. Recommended Options
✓ **mane** [source: mane, priority=critical] confidence: high
  Reason: MANE Select transcripts are the gold standard for clinical interpretation as they provide a single, consistent transcript between NCBI and Ensembl.

✓ **clinvar** [source: check_existing, priority=critical] confidence: high
  Reason: Essential to identify variants already documented in ClinVar with known pathogenic or benign significance.

✓ **check_existing** [source: check_existing, priority=annotated] confidence: high
  Reason: Necessary to link input variants to known rsIDs and other identifiers in clinical databases.

✓ **af_gnomade** [source: af_gnomade, priority=critical] confidence: high
  Reason: Crucial for filtering out common variants that are unlikely to cause rare Mendelian diseases.

✓ **sift** [source: sift, priority=critical] confidence: high
  Reason: A standard, essential tool for predicting the impact of amino acid substitutions on protein function.

✓ **polyphen** [source: polyphen, priority=critical] confidence: high
  confidence_score: high
  Reason: Complements SIFT by providing an additional prediction of protein structure and function impact.

✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Provides human-readable gene names (e.g., BRCA1), which is vital for clinical reporting and biological context.

✓ **hgvs** [source: hgvs, priority=recommended] confidence: high
  Reason: Adds standardized nomenclature required for clinical documentation and communication with molecular diagnostics labs.

✓ **coding_only** [source: coding_only, priority=not_applicable] confidence: high
  Reason: Directly addresses the user's focus on "coding variants," reducing noise from non-coding features.

✓ **cadd** [source: cadd, priority=recommended] confidence: high
  Reason: An aggregated score that helps prioritize variants with potentially deleterious effects across different genomic contexts.

✓ **spliceai** [source: spliceai, priority=recommended] confidence: medium
  Reason: Essential for detecting if a coding-region variant (even if synonymous or missense) might create/disrupt cryptic splice sites.

✓ **canonical** [source: canonical, priority=recommended] confidence: high
  Reason: Helps quickly identify the primary transcript used in standard annotation pipelines.

✓ **biotype** [source: biotype, priority=recommended] confidence: high
  Reason: Confirms that the annotated features are indeed protein-coding transcripts.

✗ **most_severe** [source: most_severe] confidence: high
  Reason: Disabled because we need to see all transcript-level evidence and impact scores (SIFT/PolyPhen) for full clinical assessment, which this flag would suppress.

✗ **summary** [source: summary] confidence: high
  Reason: Disabled because a summary view hides the detailed consequence data necessary to evaluate pathogenicity at the transcript level.

✗ **regulatory** [source: regulatory] confidence: high
  Reason: The analysis is focused on the exome/coding regions; including heavy regulatory annotations would increase runtime without providing relevant info for coding-centric disease discovery.

### 3. Generated VEP Command
```
vep --input_file input.vcf --output_file output.txt --cache --format vcf --everything --mane --clinvar --check_existing --af_gnomade --sift b --polyphen p --cadd --spliceai --coding_only --symbol --hgvs --canonical --biotype
```

**Note for Web Interface Users:**
To replicate this setup in the Ensembl VCF Web Tool:
1. Set **Transcript Set** to "Ensembl/GENCODE".
2. Enable **MANE Select**, **ClinVar**, and **gnomAD Exome (AF)**.
3. Under **Plugins**, enable **CADD**, **SpliceAI**, and **dbNSFP**.
4. In **Restrict Results**, ensure you have **not** selected "Most Severe" or "Summary".
