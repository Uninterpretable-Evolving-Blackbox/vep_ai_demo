## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the biotype of the transcript or regulatory feature, which is essential for distinguishing between coding and regulatory elements in your analysis.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most reliable transcript for each gene, which is crucial when interpreting the impact of potential driver mutations.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Allows you to see if these somatic variants have been previously recorded in other mouse datasets/databases.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Ensures the consequence calculation is driven by the primary Ensembl/GENCODE annotation set for the mouse genome.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, helping to assess if a coding mutation disrupts a known functional site, a key step in identifying driver mutations.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard nomenclature for your variants, facilitating communication of your findings and further downstream validation.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Scores splice sites, which is important for identifying small indels or SNVs that might affect transcript processing.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon and intron numbering, which is necessary for precise mapping of changes within the coding and regulatory regions.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations for the features hit, helping to link variants to biological functions or known mouse disease models.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically enables the search for overlaps with regulatory regions (promoters, enhancers), fulfilling the requirement to assess control regions.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Predicts whether missense amino acid substitutions affect protein function, which is a key metric for identifying potential drivers.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the results much more interpretable for biological analysis.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option is incompatible with several recommended options like --hgvs, --symbol, and --sift.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: NOT APPLICABLE; gnomAD is a human-only database.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is a human-only clinical database.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is a human-only tool.
