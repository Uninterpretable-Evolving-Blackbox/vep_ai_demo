## User Query
I have germline Mus musculus WES data; I need to identify protein-altering SNVs and indels in coding regions and assess their predicted functional pathogenicity.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (*Mus musculus* is specified)
- **origin**: germline (stated directly)
- **variant_size_class**: small (SNVs and indels mentioned)
- **region_focus**: coding (stated directly)
- **analysis_goal**: clinical-interpretation (assessing predicted functional pathogenicity)

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the transcript biotype (e.g., protein_coding), which is essential for identifying the nature of the genes being impacted.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript, helping to prioritize the most biologically relevant isoform for pathogenicity assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Essential for checking if these small variants are already known in existing mouse variation databases.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the Ensembl/GENCODE core annotation to drive consequence calculation, which is the standard for this species.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is crucial for interpreting the functional impact of amino acid changes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature, which is necessary for communicating protein-altering changes.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based modeling of splice sites, helping to predict if indels or SNVs disrupt splicing.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, aiding in the precise localization of the variants within the coding structure.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: medium
  Reason: Retrieves overlapping phenotype associations to support the clinical interpretation goal.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP), facilitating linkage to protein-level functional studies.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Predicts whether a missense substitution affects protein function based on sequence homology available for this species.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make the output human/biologically readable and easier to interpret.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option conflicts with several recommended options including --hgvs, --sift, and --symbol.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar data is human-only and not applicable to Mus musculus.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-centric meta-resource and not applicable for this species.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only prediction tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool.
✗ gnomad_sv [source: gnomad_sv] confidence: high
  Reason: gnomAD data is human-only.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --biotype --canonical --check_existing --core_type --domains --hgvs --maxentscan --numbers --plugin Phenotypes --protein --sift --symbol
```
