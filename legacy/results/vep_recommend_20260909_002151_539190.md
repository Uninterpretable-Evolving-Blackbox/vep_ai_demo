## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation
### 1. Detected Scenario
- **species**: human (User: "human somatic whole exome sequencing")
- **origin**: somatic (User: "tumor biopsies")
- **variant_size_class**: structural-CNV (User: "structural variants and copy number alterations")
- **region_focus**: coding (User: "which protein-coding genes are being disrupted")
- **analysis_goal**: basic-consequence (User: "quick top-line call... without necessarily needing an exhaustive breakdown")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard approach for driving consequence calculations in human studies.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for the user's goal of identifying which genes (e.g., BRCA1, TP53) are disrupted.

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help assess the quality/reliability of the transcripts being disrupted.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Allows the user to quickly filter for "protein_coding" genes, aligning with the goal of focusing on protein-coding disruptions.

✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify the most functionally important isoforms (principal transcripts) affected by the CNVs.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNV/structural variant analysis to determine if a gene is sensitive to changes in copy number (e.g., haploinsufficiency).

✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores to help contextualize the importance of the gene being lost or disrupted.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which assists in a "top-line" understanding of where in the gene the disruption occurs.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically recommended for structural-CNV size classes to check if these alterations are seen in population databases.

✗ hgvs [source: hgvs] confidence: high
  Reason: User explicitly requested to avoid exhaustive nucleotide-level details/nomenclature at this stage.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This is a resource for missense (SNV/Indel) functional prediction; not applicable/useful for large-scale CNVs.

✗ spliceai [source: spliceai] confidence: high
  Reason: Designed for predicting splice-site alterations from nucleotide changes; not applicable for structural-CNV.

✗ most_severe [source: most_severe] confidence: medium
  Reason: While the user wants a "top-line" call, enabling this can conflict with other useful descriptive flags like --symbol and --tsl. It is better to see the full transcript context for structural events.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --tsl --biotype --appris --dosage_sensitivity --loeuf --numbers --custom <gnomAD_SV_path>,type=exact,overlap_cutoff=exact
```
*Note: On the Ensembl Web Interface, select "Human" as the species, check the boxes for Symbol, TSL, Biotype, APPRIS, Dosage Sensitivity, LOEUF, and Numbers, and upload your gnomAD SV file in the Custom Datasets section.*
