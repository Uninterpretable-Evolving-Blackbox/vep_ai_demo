## User Query
Mouse germline WGS, SNV and indel variants; rapid top-line functional annotation for protein-coding and regulatory regions.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Mouse)
- **origin**: germline (WGS/germline)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (specified)
- **analysis_goal**: basic-consequence (rapid top-line functional annotation)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for defining the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is standard for top-line functional annotation.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context for the regulatory and coding features (e.g., protein_coding vs lincRNA).
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized nomenclature for the variants.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, helping prioritize consequences in a top-line analysis.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) for coding variants.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to annotate effects in the specified regulatory-noncoding regions.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information to help assess functional impact in coding regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, essential for localizing consequences.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Helpful for identifying if these mouse variants have been previously cataloged in Ensembl variation data.
✓ sift [source: sift, priority=no priority] confidence: medium
  Reason: Mouse SIFT data is available and provides a quick functional prediction for missense variants.

✗ summary [source: summary] confidence: high
  Reason: Disabled because a "top-line functional annotation" usually requires seeing the specific consequences rather than a collapsed string.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --hgvs --canonical --protein --regulatory --domains --numbers --check_existing --sift
```
*Note: On the Ensembl VEP web interface, ensure you select the correct mouse genome assembly and check the boxes for Symbol, Biotype, HGVS, Canonical, Protein, Regulatory, Domains, Numbers, and SIFT. Do not select any human-specific frequency or pathogenicity plugins.*
