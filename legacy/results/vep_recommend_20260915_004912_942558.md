I am looking at some human tumor sequencing results and I have noticed several large sections of DNA that seem to be either extra or missing. I am especially interested in the areas that don't actually make proteins but instead act as control switches for genes, as I want to see if these big changes might be affecting how those genes work and contributing to the cancer. How should I configure my run to get all that info about the regulatory impact and the population background?

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --dir_cache <path_to_cache> --plugin DosageSensitivity --plugin Phenotypes --custom gnomad_sv,gnomad_sv.vcf.gz,exact --regulatory --symbol --biotype
```
*Note: The `--custom` flag requires a path to a gnomAD SV VCF file. In the Ensembl web interface, ensure you select 'Regulatory Build' and 'gnomAD SV' from the available datasets.*
