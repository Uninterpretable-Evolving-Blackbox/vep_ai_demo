### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for providing the baseline transcript/gene annotation driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Necessary to make results human-readable by adding HGNC gene symbols.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and non-coding features (e.g., lincRNA) across the focus regions.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with promoters, enhancers, and CTCF binding sites in non-coding regions.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Critical for CNV analysis to identify if the affected genes are sensitive to copy number changes (e.g., pHaplo scores).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Necessary to filter out common structural variants using gnomAD-SV population frequencies.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is helpful for characterizing the boundaries of CNVs.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help prioritize high-confidence transcripts.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify principal isoforms, which is useful when evaluating the impact of a CNV on a specific transcript.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily designed for short variants (SNVs/indels) and is not applicable/standard for CNVs.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Contains missense variant annotations, which do not apply to structural variants.
✗ sift [source: sift] confidence: high
  Reason: Predicts effect of amino acid substitutions; not applicable to CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: Predicts effect of amino acid substitutions; not applicable to CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: Scoring is for single nucleotide variants; not applicable to CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: User wants to identify "primary functional consequences" across both coding and regulatory regions; collapsing to a single most severe term might hide the regulatory impact of a CNV.
✗ summary [source: summary] confidence: medium
  Reason: A summary-only output would lose the detailed regulatory and dosage sensitivity information required.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --core_type merged --symbol --biotype --regulatory --dosage_sensitivity --gnomad_sv <path_to_gnomad_sv.vcf> --numbers --tsl --appris
```
*Note: The `--gnomad_sv` flag requires a custom VCF input for the gnomAD SV dataset. On the Ensembl Web Interface, these options correspond to checking the boxes for Gene Symbol, Biotype, Regulatory, Dosage Sensitivity, gnomAD SV, Numbering, TSL, and APPRIS.*
