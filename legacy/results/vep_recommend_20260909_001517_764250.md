# VEP Recommendation

**Date:** 2026-09-09T00:15:17.765019

## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse model)
- **origin**: somatic (tumor tissue)
- **variant_size_class**: small (single letter changes and small additions/removals)
- **region_focus**: coding, regulatory-noncoding (protein-coding sequences and control regions)
- **analysis_goal**: clinical-interpretation (identifying driving changes for tumor progression)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to choose the transcript/gene annotation set driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make results more interpretable for identifying potential drivers.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature, essential for reporting and cross-referencing coding changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and non-coding regulatory features.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Necessary to identify overlaps with regulatory regions (promoters, enhancers) to address the user's interest in control regions.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which helps assess the functional impact of coding variants on drivers.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for functional interpretation.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides protein identifiers (ENSP) to link variant effects to protein-level changes.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based prediction of amino acid substitution impact, which is available for species with SIFT data (like mouse).
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, crucial for localizing small indels and coding changes.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides splice site scoring, which is important for identifying functional impacts of small indels.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link genes to biological processes or known phenotypes, aiding in the identification of tumor drivers.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only database; it cannot be used for a mouse model.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with recommended options like --hgvs, --symbol, and --sift. For somatic driver identification, per-transcript detail is preferred over a single collapsed line.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with recommended detailed annotations; summary mode would hide the specific regulatory and protein details required.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --biotype --regulatory --domains --canonical --protein --sift --numbers --maxentscan --plugin Phenotypes --dir_cache /path/to/cache
```
*Note: In the web interface, ensure you select the Mouse genome assembly and enable the "Regulatory" and "Plugin" checkboxes for Phenotypes and MaxEntScan.*
