## User Query
I want to test for a rare disease

## Recommendation
To provide you with the most accurate configuration, I have assumed your goal is **clinical variant interpretation** of germline data (e.g., Whole Exome or Whole Genome Sequencing) to identify causative mutations in a patient with a suspected Mendelian disorder.

### 1. Detected Use Case
**Category:** `rare_disease_germline`
**Reason:** You are looking for rare, potentially pathogenic variants that follow Mendelian inheritance patterns. This requires high-density annotation including population frequencies (to filter common variants), pathogenicity predictors (to assess impact), and clinical databases (to check for known disease associations).

### 2. Recommended Options

**Identifiers & Annotation Context**
✓ **core_type** [source: core_type, priority=critical] confidence: high
  Reason: Essential to define the primary annotation set used for all consequence calculations.
✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols (e.g., *BRCA1*) to make results human-readable and easy to interpret.
✓ **hgvs** [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature for reporting variants in clinical documents.
✓ **protein** [source: protein, priority=optional] confidence: medium
  Reason: Adds Ensembl protein IDs (ENSP) to link genomic changes to their amino acid consequences.
✓ **transcript_version** [source: transcript_version, priority=recommended] confidence: high
  Reason: Ensures precise tracking of transcripts by including version numbers.
✓ **mane** [source: mane, priority=critical] confidence: high
  Reason: Uses MANE Select transcripts to ensure your interpretation is consistent with NCBI/clinical standards.
✓ **canonical** [source: canonical, priority=recommended] confidence: high
  Reason: Distinguishes the primary transcript for a gene, which is vital for prioritizing variants.
✓ **biotype** [source: biotype, priority=recommended] confidence: medium
  Reason: Helps distinguish between protein-coding genes and non-coding features like lincRNAs.

**Clinical & Population Evidence**
✓ **check_existing** [source: check_existing, priority=critical] confidence: high
  Reason: Crucial for linking input variants to known identifiers like rsIDs (dbSNP).
✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Provides vital clinical significance (e.g., Pathogenic, Benign) from the ClinVar database.
✓ **af_gnomade** [source: af_gnomade, priority=critical] confidence: high
  Reason: Essential for filtering out common polymorphisms; variants found frequently in gnomAD are unlikely to cause rare Mendelian diseases.
✓ **af_gnomadg** [source: af_gnomadg, priority=critical] confidence: medium
  Reason: Provides additional frequency data from gnomAD genome sequences to supplement exome data.
✓ **pubmed** [source: pubmed, priority=recommended] confidence: medium
  Reason: Links discovered variants to existing scientific literature for deeper biological context.

**Pathogenicity Prediction (Human-only)**
✓ **sift** [source: sift, priority=critical] confidence: high
  Reason: A standard tool for predicting the impact of missense mutations on protein function.
✓ **polyphen** [source: polyphen, priority=critical] confidence: high
  Reason: Predicts the structural and functional impact of amino acid substitutions.
✓ **cadd** [source: cadd, priority=recommended] confidence: medium
  Reason: Provides a single integrated score (C-score) for the deleteriousness of variants.
✓ **spliceai** [source: spliceai, priority=recommended] confidence: medium
  Reason: Essential for detecting variants that may disrupt splicing even if they appear to be intronic or synonymous.
✓ **nmd** [source: nmd, priority=recommended] confidence: medium
  Reason: Determines if a nonsense mutation will escape Nonsense-Mediated Decay (NMD), which is critical for evaluating Loss-of-Function (LoF) impact.

**Filtering & Restriction**
✗ **most_severe** [source: most_severe] confidence: high
  Reason: Must be disabled because clinical review requires observing all transcript consequences, especially to identify if a variant affects a specific splice site or UTR.
✗ **summary** [source: summary] confidence: high
  Reason: Must be disabled as the "summary" mode loses the detailed per-transcript information required for diagnostic evidence.

### 3. Generated VEP Command

```bash
vep --input_file input.vcf \
    --output_file output.txt \
    --cache \
    --format vcf \
    --everything \
    --symbol \
    --hgvs \
    --mane \
    --canonical \
    --biotype \
    --transcript_version \
    --check_existing \
    --clinvar \
    --af_gnomade \
    --af_gnomadg \
    --sift b \
    --polyphen p \
    --cadd \
    --spliceai \
    --plugin NMD \
    --plugin ClinPred \
    --plugin AlphaMissense \
    --plugin REVEL \
    --protein \
    --pubmed
```

**Note on Web Interface:** If using the Ensembl VEP Web Interface, you cannot run all plugins (like SpliceAI or CADD) simultaneously due to computational limits. For a "Rare Disease" setup, manually check **"HGVS"**, **"ClinVar"**, **"gnomAD"**, and **"Transcript Support Level"**, and use the "Custom" plugin field for specialized tools.
