# VEP Recommendation

**Date:** 2026-09-09T22:37:53.177986

## User Query
I am working with whole exome sequencing data from a cohort of zebrafish tumor models where I have identified several somatic SNVs and small indels by comparing the tumor DNA to matched germline samples. My primary goal is to identify which of these mutations in the protein-coding regions are likely to be pathogenic, so I need a way to assess their potential impact on the amino acid sequence and overall protein function to help prioritize candidate driver mutations for further study.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Zebrafish)
- **origin**: somatic (identified by comparing tumor to matched germline)
- **variant_size_class**: small (SNVs and small indels)
- **region_focus**: coding (protein-coding regions)
- **analysis_goal**: clinical-interpretation (identifying pathogenic driver mutations)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the Ensembl/GENCODE core annotation is the standard approach for providing accurate transcript consequences.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: This option is for human-only gnomAD exome populations.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Essential for clinical-style interpretation to provide standardized nomenclature for the identified mutations.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps assess protein function by identifying if a mutation overlaps with known functional domains (Pfam, etc.).
✗ frequency [source: frequency] confidence: high
  Reason: This is a human-only frequency filtering option.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This is a human-only meta-resource.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides gene symbols to make the identification of driver genes intuitive.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize mutations occurring in the most biologically relevant (canonical) transcripts.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides protein identifiers (ENSP) which are necessary for linking amino acid changes to protein-level consequences.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Confirms the transcript type (e.g., protein_coding) to ensure focus remains on coding regions.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Predicts the impact of missense substitutions on protein function for species with available SIFT data.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Crucial for assessing the potential impact of small indels or SNVs on splice sites.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is vital for reporting the exact location of the somatic mutation.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Assists in clinical-style interpretation by linking genes to known phenotype associations.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Useful for coding-region focus to predict if a mutation leads to nonsense-mediated decay.
✓ uniprot [source: uniprot, priority=optional] confidence: medium
  Reason: Provides protein-level links to UniProt, aiding in the functional study of candidate drivers.
✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Since the goal is specifically protein-coding regions, this reduces noise from non-coding consequences.
✗ most_severe [source: most_severe] confidence: high
  Reason: Enabled to provide detailed consequence data per transcript; using `--most_severe` would conflict with recommended options like `--hgvs`, `--symbol`, and `--sift`.

### 3. Generated VEP Command
```
vep --input_file somatic_variants.vcf --output_file zebrafish_analysis.txt --cache --species zebrafish --hgvs --domains --symbol --canonical --protein --biotype --sift --maxentscan --numbers --phenotypes --nmd --uniprot --coding_only
```
*Note: In the Ensembl Web Interface, ensure the "Species" is set to Zebrafish and select the corresponding plugins/options listed above. The `--coding_only` flag is highly recommended to filter out non-coding noise in your exome data.*
