## User Query
I am currently reviewing exome sequencing results from a cohort of mice used in our recent developmental study. We have identified several single-letter changes and small additions or deletions throughout the genome. For my preliminary report, I just need to quickly identify which of these variations actually alter the protein sequence or create an early stop signal within the coding regions.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (user specifies "mice")
- **origin**: somatic (implied by "recent developmental study" findings, though the focus is on the consequence rather than the inheritance)
- **variant_size_class**: small (user specifies "single-letter changes and small additions or deletions")
- **region_focus**: coding (user specifies "throughout the genome" but wants to focus on "altering protein sequence or creating early stop signals")
- **analysis_goal**: basic-consequence (user wants to "quickly identify which of these variations actually alter the protein sequence")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the Ensembl/GENCODE core annotation is the standard for determining transcript consequences in non-human species.

✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature for the identified coding changes, which is essential for reporting protein-altering variants.

✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps identify if the protein-altering changes fall within critical functional domains (e.g., Pfam), aiding in developmental study interpretation.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the preliminary report readable for biologists.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize consequences by identifying the most representative transcript for each gene.

✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides Ensembl protein identifiers (ENSP), which is crucial when the goal is to analyze protein-sequence alterations.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Confirms the transcript type (e.g., protein_coding), ensuring the focus remains on valid coding targets.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon and intron numbering, which is necessary for locating the exact position of the variation within the gene structure.

✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled to avoid conflicts with recommended options like `--hgvs`, `--symbol`, and `--protein`. Keeping all consequences allows for a more detailed view of the coding impact.

✗ coding_only [source: coding_only] confidence: medium
  Reason: While the user is interested in coding regions, the user also mentioned "throughout the genome". It is safer to provide all consequences and filter later, or let the user see the context.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: NOT APPLICABLE; this resource is human-only.

✗ af_gnomad [source: af_gnomade] confidence: high
  Reason: NOT APPLICABLE; gnomAD is human-only.

✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: An optional add-on that helps identify if "early stop signals" (nonsense mutations) are likely to lead to nonsense-mediated decay, a key part of the user's request.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --canonical --protein --biotype --domains --numbers --plugin NMD
```
*Note: The `--plugin NMD` requires the NMD plugin files to be installed in your VEP plugin directory. On the Ensembl Web Interface, these correspond to the "Gene" and "Protein" sections in the 'Output' settings.*
