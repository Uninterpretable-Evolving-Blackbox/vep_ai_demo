### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to establish the Ensembl/GENCODE transcript set for consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to make results more human-interpretable.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Necessary to distinguish between protein-coding genes and other features like lincRNA or enhancers.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to annotate impacts on regulatory regions (promoters, enhancers, etc.) as requested.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Critical for CNV/structural variant analysis to identify genes sensitive to copy number changes (e.g., pHaplo).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Provides allele frequencies specifically for structural variants from the gnomAD SV dataset.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcripts for coding consequences.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to assess the quality/evidence of the transcripts being hit.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is useful for localizing structural disruptions.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Needed to link variants to known IDs and enable other frequency/clinical plugins.
✓ clinvar [source: clinvar, priority=optional] confidence: medium
  Reason: Provides clinical significance for any known variants co-located with the SVs.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for small variants (SNVs/indels) and is not applicable/standard for structural variants in this context.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a resource for missense single nucleotide variants; not applicable to structural/CNV analysis.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single-base substitutions; not applicable to CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single-base substitutions; not applicable to CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are primarily designed for SNVs and small indels; not applicable to SV/CNV analysis.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this ensures full per-transcript/per-feature detail is kept, which is vital for interpreting complex structural overlaps.
✗ summary [source: summary] confidence: high
  Reason: Disabling this ensures detailed annotations are provided rather than a collapsed summary.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --regulatory --dosage_sensitivity --gnomad_sv --canonical --tsl --numbers --check_existing --clinvar
```
*Note: For the `--gnomad_sv` plugin, you will need to provide the path to the gnomAD SV VCF file using `--custom`. The `--dosage_sensitivity` plugin requires the Collins rCNV 2022 catalogue data.*
