## User Query
I am analyzing somatic SNVs and indels from a zebrafish tumor sample. I want to assess the potential pathogenicity of these non-coding variants by evaluating their impact on regulatory elements or transcription factor binding sites.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Zebrafish/Danio rerio)
- **origin**: somatic (tumor sample)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: regulatory-noncoding (evaluating regulatory elements and TF binding sites)
- **analysis_goal**: clinical-interpretation (assessing potential pathogenicity)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the Ensembl/GENCODE core annotation to drive consequence calculations, which is standard for non-human species.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, which is essential for clinical reporting and standardization of variant identifiers.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Directly addresses the user's need to evaluate impact on regulatory regions (promoters, enhancers, etc.) for a species with a regulatory build.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps characterize the genomic context (e.g., lincRNA, miRNA) of the non-coding regions being analyzed.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Useful for clinical interpretation to prioritize consequences occurring in the canonical transcript.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link variants to known phenotype associations, which is critical for clinical interpretation of pathogenicity.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for splice site impact, which is important for assessing the effect of indels/SNVs even in non-coding contexts that might affect splicing.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because it conflicts with several recommended options like `hgvs` and `symbol`.

  Reason: NOT APPLICABLE; this is a human-only resource.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is a human-centric database.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is a human-only tool.

  Reason: NOT APPLICABLE; SpliceAI is a human-only tool.
✗ check_existing [source: check_existing] confidence: medium

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --hgvs --regulatory --biotype --canonical --phenotypes --maxentscan
```
*Note: In the Ensembl Web Interface, ensure you select 'Danio rerio' as the species and enable the 'Regulatory' and 'Phenotypes' plugins/options in the advanced settings.*
