### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to use the Ensembl/GENCODE core transcript set to drive consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results much more human-interpretable for clinical reporting.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to distinguish if the SV disrupts protein-coding genes versus non-coding features.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Required to enable the retrieval of ClinVar and gnomAD-SV data by checking co-located variants.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance (e.g., pathogenic) for known co-located variants, critical for clinical assessment.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Annotates structural variants with gnomAD-SV allele frequencies to filter common benign variants.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs; provides pHaplo/pLI scores to assess gene dosage sensitivity.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link affected genes to known clinical phenotypes for diagnostic relevance.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize high-confidence transcripts.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Identifies MANE Select/Plus transcripts, ensuring clinical reporting uses standardized, high-confidence transcripts.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically for small variants (SNVs/Indels); not applicable for large-scale SV/CNV descriptions.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This resource aggregates missense-specific scores (like SIFT/PolyPhen); not applicable for structural variants.
✗ sift [source: sift] confidence: high
  Reason: Predicts amino acid substitution impacts; not applicable for CNVs/structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: Predicts protein structure impact of single amino acid changes; not applicable for SVs.
✗ cadd [source: cadd] confidence: high
  Reason: Provides scores for single nucleotide/small indel deleteriousness; not applicable for structural variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: Clinical SV interpretation requires seeing all overlapping features (multiple genes/transcripts) rather than a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: Summary mode hides the detailed transcript/gene-level impact information required for clinical assessment.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache \
--format vcf --vcf \
--symbol --biotype --tsl --mane \
--check_existing --clinvar --phenotypes \
--plugin DosageSensitivity \
--plugin gnomad_sv --custom <path_to_gnomad_sv.vcf.gz>,type=exact,overlap_cutoff=80
```
*Note: For the web interface, ensure "dosage_sensitivity" and "gnomad_sv" (via custom file upload) are selected. Most clinical-grade SV pipelines also require the MANE and ClinVar plugins/datasets to be active.*
