## User Query
I’m working through some human tumour sequencing data where we're specifically looking for large-scale changes in the DNA structure, like deletions or duplications. A lot of these structural changes are landing in the regions outside of the actual genes, so I need a way to quickly figure out if these stretches of missing or extra DNA might be affecting how genes are turned on or off.
