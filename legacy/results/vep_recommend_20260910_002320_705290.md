### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to choose the Ensembl/GENCODE core transcript set for consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results more human-interpretable for clinical reports.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on whether the disrupted feature is a protein-coding gene or other feature.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for structural variants to provide gnomAD structural-variant allele frequencies to filter common variants.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance (pathogenic/benign) for co-located variants to assist in clinical interpretation.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Required to enable the retrieval of ClinVar and gnomAD-SV data via co-location.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNVs to identify if the affected genes are dosage-sensitive (e.g., haploinsufficient).
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps clinical interpretation by linking affected genes to known phenotypes.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for small variants (SNVs/Indels); not applicable/useful for CNV/SV representation in this context.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: DBNSFP aggregates missense variant predictors; not applicable to structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for small variants; not applicable to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for small variants; not applicable to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are designed for single nucleotide and small indel deleteriousness; not applicable to CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this ensures the user sees all overlapping gene/transcript consequences for the SV, which is vital for structural analysis.
✗ summary [source: summary] confidence: high
  Reason: Disabling this ensures full per-transcript detail is preserved rather than collapsed.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --gnomad_sv <path_to_gnomad_sv.vcf> --clinvar --check_existing --plugin DosageSensitivity --plugin Phenotypes --core_type merged
```
*Note: In the Ensembl Web Interface, ensure you select "Human" as the species and add the "DosageSensitivity" and "Phenotypes" plugins manually. The `gnomad_sv` option requires a custom VCF file path to be provided.*
