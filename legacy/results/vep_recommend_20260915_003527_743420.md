### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --canonical --mane --dosage_sensitivity --gnomad_sv --check_existing --clinvar --phenotypes --numbers --plugin CADD --plugin Phenotypes
```
*Note: `--gnomad_sv` requires the gnomAD SV VCF to be provided via `--custom`. The `--dosage_sensitivity` and `--plugin CADD` require their respective plugin data files. In the web interface, ensure "Structural Variant" support and "Dosage Sensitivity" plugins are selected.*
