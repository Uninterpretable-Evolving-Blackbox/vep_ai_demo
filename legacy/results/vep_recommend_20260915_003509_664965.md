### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard and recommended approach for human coding analysis.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is marked NOT APPLICABLE for this scenario to avoid conflicts with clinical summary tools.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize high-confidence transcripts during clinical interpretation.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is for missense variants; structural variants/CNVs do not benefit from these specific single-nucleotide metrics.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Essential for population frequency analysis to determine if the gene is constrained by loss-of-function.
✓ mastermind [source: mastermind, priority=recommended] confidence: high
  Reason: Directly supports clinical interpretation by linking variants to existing medical literature.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols, making the output human-readable for clinical reports.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps prioritize functionally important isoforms, which is critical for coding-region clinical assessment.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Specifically recommended for CNV analysis as it annotates gene dosage sensitivity (pHaplo).
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Essential for clinical pathogenicity assessment to identify known pathogenic variants.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Provides MANE Select/Plus flags to ensure the analysis focuses on the gold-standard transcript for clinical reporting.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Assists in clinical interpretation by linking genes/variants to known phenotypes.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps filter for the primary transcript to simplify the interpretation of coding impacts.
✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: Provides a combined deleteriousness score to assist in pathogenicity assessment.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Confirms the transcript type (e.g., protein_coding), ensuring the focus remains on coding regions.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically designed to annotate structural variants with gnomAD SV allele frequencies, fulfilling the population frequency goal.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is vital for describing the location of a CNV or structural variant in a clinical report.
✗ pick [source: pick] confidence: high
  Reason: Not selected as the user needs full context for clinical assessment of multiple overlapping transcripts/consequences.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Required as a dependency to enable ClinVar and frequency lookups.
✓ go [source: go, priority=optional] confidence: medium
  Reason: Optional add-on to provide biological context via Gene Ontology terms.
