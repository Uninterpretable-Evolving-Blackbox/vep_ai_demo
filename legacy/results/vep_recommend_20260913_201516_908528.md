# VEP Recommendation

**Date:** 2026-09-13T20:15:16.908886

## User Query
I have somatic SNVs and indels from a mouse tumor. I need to identify the functional impact of both coding and regulatory variants for a preliminary pathogenicity assessment.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (explicitly requested both)
- **analysis_goal**: clinical-interpretation (preliminary pathogenicity assessment)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set that drives consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is critical for interpreting the functional impact on specific genes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, necessary for standardizing the reporting of the somatic variants.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to assess the functional impact of variants in regulatory regions (promoters, enhancers, etc.).
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds transcript/regulatory feature biotype, helping to distinguish between protein-coding and non-coding elements.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is vital for assessing the impact of coding variants on protein function.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript, helping to prioritize the most biologically relevant consequence for clinical assessment.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), useful for linking variants to protein-level functional changes.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based splice site scoring, which is necessary for assessing the impact of indels/SNVs near splice junctions.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Since mouse has SIFT data available, this provides a sequence-based prediction of missense impact.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Helps identify if these somatic variants have been previously reported in mouse variation databases.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: medium
  Reason: Retrieves phenotype associations for genes, assisting in the pathogenicity assessment of the identified mutations.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon and intron numbering, essential for localizing the variant relative to gene structures.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only database; it is not applicable to mouse.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with hgvs, symbol, domains, and sift; for pathogenicity assessment, we need the full per-transcript detail rather than a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with detailed annotation options; a summary would hide the specific functional details required for assessment.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --regulatory --biotype --domains --canonical --protein --maxentscan --sift --check_existing --phenotypes --numbers
```
*(Note: The `--phenotypes` plugin requires a corresponding phenotype database for the species. Use the VEP web interface to select these checkboxes for an interactive run.)*
