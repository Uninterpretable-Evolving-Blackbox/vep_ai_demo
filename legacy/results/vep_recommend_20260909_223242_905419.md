## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse model)
- **origin**: somatic (tumor tissue)
- **variant_size_class**: small (single letter changes and small additions/removals)
- **region_focus**: coding, regulatory-noncoding (impact on protein-coding and control regions)
- **analysis_goal**: clinical-interpretation (identifying drivers of tumor progression)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to drive consequence calculation using the standard Ensembl/GENCODE annotation set.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is crucial for identifying candidate driver genes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard nomenclature for the variants, necessary for reporting and downstream analysis.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Enables overlap with regulatory regions (promoters, enhancers, etc.) to satisfy the requirement for analyzing control regions.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides transcript/feature context (e.g., protein_coding vs non-coding) which is necessary for interpreting regulatory impacts.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level consequences.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most likely functional transcript for each gene.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, helping to interpret if a somatic change hits a functional site.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Essential for scoring splice-site effects, which is important for both coding and regulatory-adjacent changes.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based prediction of missense impact; available for species with SIFT data like mouse.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Recommended to identify if these somatic changes co-locate with known variants in the mouse genome.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations for features, helping to link identified changes to biological processes.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Predicts if premature stops escape nonsense-mediated decay, helping to assess the severity of somatic mutations.
✓ uniprot [source: uniprot, priority=optional] confidence: medium
  Reason: Provides UniProt accessions to aid in functional investigation of protein-altering changes.

✗ summary [source: summary] confidence: high
  Reason: Disabled as it collapses results into a single line, preventing the detailed regulatory and coding analysis requested.

### 3. Generated VEP Command
```
vep --input_file tumor_variants.vcf --output_file tumor_annotation.txt --cache --format vcf --vcf --symbol --hgvs --regulatory --biotype --protein --canonical --domains --max_entscan --sift --check_existing --phenotypes --nmd --uniprot
```
*Note: In the web interface, ensure you select the Mouse genome and manually check the boxes for Symbol, HGVS, Regulatory, Biotype, Protein, Canonical, Domains, MaxEntScan, SIFT, Check Existing, Phenotypes, NMD, and UniProt. Do not select "Most Severe" or "Summary".*
