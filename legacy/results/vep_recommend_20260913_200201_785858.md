  Reason: The primary tool for assessing the population frequency of structural variants specifically.

  Reason: Helps in clinical interpretation by linking affected genes to known disease or phenotype associations.

  Reason: Not applicable for structural variants; these are amino acid substitution predictors.

✗ summary [source: summary] confidence: high
  Reason: A summary output hides the detailed transcript-level and gene-level consequences needed for pathogenicity assessment.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --plugin DosageSensitivity --plugin Phenotypes --custom gnomad_sv,path/to/gnomad_sv.vcf.gz,exact --check_existing --clinvar --symbol --biotype --mane --tsl --dosage_sensitivity --phenotypes
```
*Note: The `--custom` flag requires a path to a gnomAD SV VCF file. On the Ensembl Web Interface, enable: Symbol, Biotype, MANE, TSL, Dosage Sensitivity, ClinVar, Phenotypes, and use the Custom/gnomAD_SV option.*
