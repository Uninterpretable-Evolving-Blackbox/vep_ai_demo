### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --force_overwrite --symbol --biotype --tsl --appris --mane --dosage_sensitivity --gnomad_sv <path_to_gnomad_sv.vcf> --check_existing --clinvar --phenotypes --frequency
```
*(Note: The `--gnomad_sv` flag requires a custom VCF file path to the gnomAD SV dataset. On the Ensembl Web Interface, these correspond to selecting the respective checkboxes in the "Plugins" and "Frequency" sections.)*
