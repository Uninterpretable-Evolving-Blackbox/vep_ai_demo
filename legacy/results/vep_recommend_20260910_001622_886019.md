## User Query
I have somatic SNVs and indels from a mouse tumor. I need to identify the functional impact of both coding and regulatory variants for a preliminary pathogenicity assessment.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (coding and regulatory variants)
- **analysis_goal**: clinical-interpretation (pathogenicity assessment)

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for distinguishing between protein-coding, miRNA, and other transcript types to assess functional context.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most representative transcript for each gene, which is critical for pathogenicity assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these somatic mutations overlap with known variants in the mouse genome.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Necessary to define the primary annotation set driving the consequence calculations.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is vital for assessing the impact of coding mutations on protein function.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized nomenclature for the variants, aiding in the formal reporting of clinical findings.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for splice sites, which is crucial for assessing the impact of small indels and SNVs on splicing.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is essential for describing the exact location of variants in clinical reports.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Links variants to known phenotype associations in the mouse, supporting pathogenicity assessment.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Enables the identification of overlaps with regulatory regions (promoters, enhancers), fulfilling the requirement to check regulatory variants.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based prediction of whether missense substitutions affect protein function in species where data is available (mouse).
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the results interpretable for clinical/biological assessment.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option conflicts with several recommended options like --hgvs, --symbol, and --sift.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is a human-only tool.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar data is human-only.
✗ gnomad [source: af_gnomadg] confidence: high
  Reason: NOT APPLICABLE; gnomAD is a human-only database.
✗ polyphen [source: polyphen] confidence: high
  Reason: NOT APPLICABLE; PolyPhen is a human-only tool.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --biotype --canonical --check_existing --core_type --domains --hgvs --maxentscan --numbers --phenotypes --regulatory --sift --symbol
```
