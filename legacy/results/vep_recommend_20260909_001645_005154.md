## User Query
I am analyzing small DNA changes from a zebrafish tumor and need to quickly identify if any variants in the non-coding regions are disrupting gene regulation or could be considered pathogenic.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Zebrafish/Danio rerio)
- **origin**: somatic (Tumor)
- **variant_size_class**: small (DNA changes/SNVs)
- **region_focus**: regulatory-noncoding (Disrupting gene regulation)
- **analysis_goal**: clinical-interpretation (Identifying pathogenic potential)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the Ensembl/GENCODE core annotation is the standard starting point for non-human species to drive consequence calculation.

✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized HGVS nomenclature which is essential for clinical interpretation and reporting, even in non-human models.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to identify if variants are disrupting gene regulation by looking for overlaps with regulatory builds.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for non-coding analysis to distinguish between different types of non-coding features (e.g., lincRNA, miRNA).

✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Helps identify potential splicing disruptions which can occur in non-coding/intronic regions that impact downstream gene regulation.

✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Crucial for clinical-style interpretation to see if the affected genomic features are associated with known phenotypes in zebrafish.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize variants by identifying if they hit the canonical transcript of a gene.

✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: Human-only; not applicable to zebrafish.

✗ clinvar [source: clinvar] confidence: high
  Reason: Clinical significance data in ClinVar is human-centric and not applicable for zebrafish somatic analysis.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This meta-resource is specifically for human missense variants and is NOT APPLICABLE for non-human regulatory analysis.

✗ cadd [source: cadd] confidence: high
  Reason: Human-only tool for pathogenicity prediction.

✗ most_severe [source: most_severe] confidence: medium
  Reason: Disabled because it conflicts with `--hgvs`, which is required for formal clinical reporting.

### 3. Generated VEP Command
```
vep --input_file zebrafish_tumor_variants.vcf --output_file zebrafish_analysis.txt --cache --format vcf --vcf --hgvs --regulatory --biotype --maxentscan --phenotypes --canonical
```
*Note: For the web interface, ensure you select the zebrafish species and check the boxes for HGVS, Regulatory, Biotype, MaxEntScan, Phenotypes, and Canonical.*
