## User Query
I am analyzing small DNA changes from a zebrafish tumor and need to quickly identify if any variants in the non-coding regions are disrupting gene regulation or could be considered pathogenic.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Zebrafish is a non-human model organism)
- **origin**: somatic (derived from a "tumor")
- **variant_size_class**: small (specified as "small DNA changes")
- **region_focus**: regulatory-noncoding (specified as "non-coding regions are disrupting gene regulation")
- **analysis_goal**: clinical-interpretation (aiming to identify if variants are "pathogenic")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Choosing the Ensembl/GENCODE core annotation set is the standard for driving consequence calculations across all species.

✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature, which is essential for formal clinical interpretation and reporting of variants.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Directly addresses the goal of identifying if variants disrupt gene regulation by overlapping with promoters, enhancers, and other regulatory elements.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between different types of non-coding elements (e.g., lincRNA, miRNA) which is critical when focusing on regulatory regions.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, providing a stable reference point for interpreting the functional impact of a variant.

✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Supports clinical interpretation by retrieving overlapping phenotype associations for the genes or features hit by the variants.

✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for splice site strength, which is relevant for understanding potential regulatory/splicing disruptions.

✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: Human-only frequency data; not applicable to zebrafish.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Human-only meta-resource; not applicable to zebrafish.

✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar data is specific to human clinical significance; not applicable to zebrafish.

✗ most_severe [source: most_severe] confidence: medium
  Reason: While useful, this option conflicts with several recommended reporting flags like `--hgvs` and `--symbol`. It is better to see the full context of consequences in a regulatory/non-coding study.

✗ coding_only [source: coding_only] confidence: high
  Reason: Explicitly requested analysis is for non-coding/regulatory regions; this would hide the variants of interest.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --hgvs --regulatory --biotype --canonical --phenotypes --maxentscan
```
*Note: In the Ensembl Web Interface, ensure the species is set to Danio rerio (zebrafish) and select the "Regulatory" and "Phenotypes" checkboxes. The `--maxentscan` plugin may require a local installation of the MaxEntScan tool if running via command line.*
