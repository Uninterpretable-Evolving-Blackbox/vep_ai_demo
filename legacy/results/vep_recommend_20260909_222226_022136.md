### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the Ensembl/GENCODE core annotation set is the standard for driving consequence calculations in non-human species.

✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature based on Ensembl identifiers, which is essential for describing the exact change in the protein-coding sequence.

✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information (e.g., Pfam), which helps identify if a high-impact variant hits a functional domain.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, facilitating quick identification of the genes involved in the tumor.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript, which is critical for prioritizing the most biologically relevant consequence in a coding analysis.

✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides Ensembl protein identifiers (ENSP), essential for linking variants to protein-level changes.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides the transcript biotype to ensure the variants are indeed falling in protein-coding regions.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon and intron numbering, which is helpful for characterizing the location of the variant within the gene.

✗ most_severe [source: most_severe] confidence: high
  Reason: While the user wants "high-impact" variants, enabling `--most_severe` would conflict with `--hgvs` and `--symbol`, preventing the output of detailed descriptive information. It is better to see all consequences and filter manually or via script.

✗ coding_only [source: coding_only] confidence: medium
  Reason: Although the focus is coding, keeping it disabled allows for seeing if a variant has secondary effects (e.g., near splice sites), though it can be added if the user wants to strictly limit the output.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This tool is human-only and not applicable to a mouse analysis.

✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar data is human-specific and not applicable to mouse tumor analysis.

✗ af_gnomad [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only database; allele frequencies for mouse are not provided via this flag.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --hgvs --symbol --domains --canonical --protein --biotype --numbers
```
