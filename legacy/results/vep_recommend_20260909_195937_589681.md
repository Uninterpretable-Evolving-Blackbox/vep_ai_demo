## User Query
I am currently processing a set of somatic mutations identified from mouse tumor sequencing to identify potential driver candidates in this model. We have a collection of SNVs and small indels derived from both WES and some supplemental WGS data, and I need to perform an initial, high-level annotation pass. The goal is to quickly categorize these variants based on their functional impact, specifically distinguishing between those falling within protein-coding sequences and those residing in regulatory or non-coding regions, so I can prioritize which mutations are worth more rigorous downstream analysis.

- **variant_size_class**: small (user specified "SNVs and small indels")
- **region_focus**: coding, regulatory-noncoding (user wants to distinguish "protein-coding sequences" from "regulatory or non-coding regions")
- **analysis_goal**: basic-consequence (user requested "initial, high-level annotation pass" to "quickly categorize")

### 3. Generated VEP Command
```
vep --input_file mouse_somatic.vcf --output_file mouse_annotation.txt --cache --format vcf --everything --symbol --biotype --hgvs --regulatory --canonical --protein --domains --numbers --check_existing
```
*Note: While `--everything` is a shortcut, for precise control in a pipeline, the specific flags enabled above are preferred. On the Ensembl Web Interface, ensure "Mouse" is selected as the species and check the boxes for Symbol, Biotype, HGVS, Regulatory, Canonical, Protein, Domains, and Numbers.*
