# VEP Recommendation

**Date:** 2026-06-23T09:33:34.765461

## User Query
Prioritize rare protein-altering variants in a patient with a suspected Mendelian disorder.

## Recommendation
### 1. Detected Use Case
**rare_disease_germline**: The user is investigating a patient with a suspected Mendelian disorder, requiring an emphasis on pathogenicity prediction (SIFT, PolyPhen, CADD), clinical significance (ClinVar), and population frequency filtering (gnomAD) to identify rare, deleterious protein-altering variants.

### 2. Recommended Options
✓ **transcript_set** [source: --gencode_basic] confidence: high
  Reason: Using a comprehensive/standard transcript set is essential for accurate coding annotation in germline studies.

✓ **mane_select** [source: --mane_select, priority=critical] confidence: high
  Reason: For human GRCh3AG, MANE Select provides a single gold-standard transcript per gene, significantly reducing complexity and noise in disease prioritization.

✓ **canonical** [source: --canonical, priority=recommended] confidence: high
  Reason: Identifies the primary transcript for each gene, which is useful when reviewing known pathogenic variants.

✗ **pick** [source: --pick] confidence: medium
  Reason: While MANE Select provides a representative transcript, keeping multiple transcripts (if not using MANE) allows for checking all possible protein-altering impacts.

✗ **per_gene** [source: --per_gene] confidence: high
  Reason: We need detailed, per-transcript information to evaluate splice sites and specific amino acid changes.

✗ **most_severe** [source: --most_severe] confidence: high
  Reason: This option is incompatible with functional predictors (SIFT/PolyPhen) and HGVS nomenclature required for clinical interpretation.

✗ **summary** [source: --summary] confidence: high
  Reason: Summary mode suppresses the detailed transcript-level data needed to evaluate protein-altering consequences.

✓ **sift** [source: --sift, priority=critical] confidence: high
  Reason: A standard and critical tool for predicting the impact of amino acid substitutions.

✓ **polyphen** [source: --polyphen, priority=critical] confidence: high
  Reason: Essential clinical predictor for assessing the structural/functional impact of missense variants in humans.

✓ **cadd** [source: --plugin CADD, priority=recommended] confidence: high
  Reason: Provides an integrated score of deleteriousness, which is highly effective for prioritizing rare variants.

✓ **alphamissense** [source: --plugin AlphaMissense, priority=recommended] confidence: medium
  Reason: Highly accurate AI-based prediction for missense pathogenicity in human GRCh38.

✓ **revel** [source: --plugin REVEL, priority=optional] confidence: medium
  Reason: An ensemble method that provides an additional layer of evidence for the pathogenicity of rare missense variants.

✓ **clinvar** [source: --check_existing, priority=critical] confidence: high
  Reason: Directly identifies if a variant has been previously reported as pathogenic or benign in ClinVar.

✓ **check_existing** [source: --check_existing, priority=critical] confidence: high
  Reason: Necessary to link input variants to known rsIDs and clinical metadata.

✓ **gnomad_af** [source: --af_gnomade, priority=critical] confidence: high
  Reason: Critical for filtering out common polymorphisms; Mendelian disease variants should be rare in gnomAD.

✗ **af_1kg** [source: --af_1kg] confidence: medium
  Reason: gnomAD provides more comprehensive and modern allele frequency data for human populations than 1000 Genomes.

✗ **gnomad_sv** [source: --custom] confidence: high
  Reason: The focus is on protein-altering SNVs/Indels, not large structural variants.

✗ **clinvar_sv** [source: --custom] confidence: high
  Reason: The focus is on protein-altering nucleotide variants, not structural variations.

✗ **regulatory** [source: --regulatory] confidence: high
  Reason: The analysis is specifically focused on protein-altering (exonic) variants rather than non-coding regulatory elements.

✓ **hgvs** [source: --hgvs, priority=critical] confidence: high
  Reason: Standardized nomenclature is mandatory for clinical reporting and downstream interpretation.

✓ **symbol** [source: --symbol, priority=recommended] confidence: high
  Reason: Makes the VCF output much more human-readable by providing gene symbols (e.g., BRCA1) instead of Ensembl IDs.

✗ **protein** [source: --protein] confidence: medium
  Reason: HGVS nomenclature and Gene Symbols are sufficient for standard clinical prioritization; ENSP is often redundant here.

✓ **domains** [source: --domains, priority=recommended] confidence: high
  Reason: Provides functional context by showing if a variant falls within a known protein domain (e.g., Kinase domain).

✓ **spliceai** [source: --plugin SpliceAI, priority=recommended] confidence: medium
  Reason: Useful for detecting "silent" or intronic variants that may actually cause protein-altering effects via cryptic splice site activation.

✗ **maxentscan** [source: --plugin MaxEntScan] confidence: medium
  Reason: SpliceAI is generally more powerful; MaxEntScan is not strictly required unless specifically investigating canonical splice sites.

✓ **gene_phenotype** [source: --gene_phenotype, priority=recommended] confidence: high
  Reason: Essential for linking candidate genes to the patient's clinical phenotype (OMIM/Orphanet).

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache \
--gencode_basic --mane_select --canonical \
--sift b --polyphen b --plugin CADD,snv=/path/to/SNVs.tsv.gz,indels=/path/to/InDels.tsv.gz \
--plugin AlphaMissense,file=/path/to/AlphaMissense_hg38.tsv.gz \
--plugin REVEL,file=/path/to/revel_scores.tsv.gz \
--check_existing --af_gnomade --plugin SpliceAI,snv=/path/to/spliceai_snvs.vcf.gz,indel=/path/to/spliceai_indels.vcf.gz \
--hgvs --symbol --domains --gene_phenotype
```

**Note for Web Interface:** To replicate this, enable "MANE Select", "Canonical", "SIFT", "PolyPhen", "CADD", "AlphaMissense", "REVEL", "ClinVar", "gnomAD allele frequency", "HGVS", "Gene Symbol", "Domains", and "Gene Phenotype" in the Ensembl VEP settings.
