## User Query
I’m working through some human tumour sequencing data where we're specifically looking for large-scale changes in the DNA structure, like deletions or duplications. A lot of these structural changes are landing in the regions outside of the actual genes, so I need a way to quickly figure out if these stretches of missing or extra DNA might be affecting how genes are turned on or off. It would also be really helpful to see how common these types of variations are in the general healthy population so I can better judge whether a finding looks like a potential driver for the cancer or just a common variation.

  Reason: Helps distinguish if the CNV affects protein-coding genes or non-coding features like lincRNA.

  Reason: Necessary to link the structural variants to known variants/IDs.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Directly addresses the goal of seeing if variations affect how genes are "turned on or off" by overlapping regulatory regions.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically provides allele frequencies for structural variants from gnomAD to distinguish drivers from common population variation.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance for co-located variants to aid in driver interpretation.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Provides biological context/associations for the genes being disrupted.
✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: While primarily for SNVs, it provides a general deleteriousness score that can support the interpretation of the genomic region.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for small variants (SNVs/indels) and is not applicable/useful for large-scale CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for amino acid substitutions; it does not apply to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for amino acid substitutions; it does not apply to structural variants.
✗ most_severe [source: most_severe] confidence: high

✗ summary [source: summary] confidence: high
  Reason: A summary view would collapse the regulatory and biotype details needed for this specific analysis.

### 3. Generated VEP Command
```

```
*Note: The `--gnomad_sv` option requires a local tabix-indexed VCF file. On the Ensembl Web Interface, these options correspond to enabling "Gene Symbol", "Transcript Biotype", "Regulatory", "Check existing variants", "gnomAD SV", "ClinVar", "Phenotypes", and "CADD".*
