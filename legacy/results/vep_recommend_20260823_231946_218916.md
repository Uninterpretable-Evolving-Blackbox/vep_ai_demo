### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set (Ensembl/GENCODE) that drives consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols (e.g., TP5    53) to the output, making results much more human/species-readable.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard HGVS nomenclature based on Ensembl identifiers, crucial for reporting coding changes.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript, helping to prioritize the most biologically relevant transcript for each gene.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP) to link variants to protein-level consequences.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on the transcript type (e.g., protein_coding), which is vital for coding region analysis.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information (Pfam, etc.), which is highly useful for assessing the impact of coding variants.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon and intron numbering, providing necessary structural context for the variants.
✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Since the focus is specifically on coding regions, this restricts the output to relevant consequences only.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for identifying if these somatic SNVs overlap with known variants in the mouse genome.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-specific database and is not applicable to mouse data.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool for predicting protein impact.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only integrative annotation resource.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only database.
✗ revel [source: revel] confidence: high
  Reason: REVEL is a human-only ensemble predictor.
✗ alphamissense [source: alphamissense] confidence: high
  Reason: AlphaMissense is a human-only pathogenicity prediction tool.
✗ most_severe [source: most_severe] confidence: medium
  Reason: Disabling this allows for the full range of transcript-level consequences to be seen, which is important for somatic driver identification.
✗ summary [source: summary] confidence: medium
  Reason: Disabling summary mode ensures detailed annotation per transcript is available rather than a collapsed view.
