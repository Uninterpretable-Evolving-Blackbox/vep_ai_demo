### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --everything --symbol --hgvs --biotype --regulatory --domains --canonical --protein --maxentscan --numbers --sift --phenotypes --check_existing --uniprot --plugin Phenotypes,/path/to/phenotypes.tab
```
*Note: The `--everything` flag is a shortcut, but for precision in a non-human pipeline, it is better to explicitly list the flags above. The `--plugin Phenotypes` requires a local path to the phenotype database if running via command line.*
