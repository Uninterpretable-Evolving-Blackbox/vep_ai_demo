## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Necessary to drive the consequence calculation using Ensembl/GENCODE core annotations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for providing human-readable HGNC gene symbols (e.g., TP53) to identify disrupted genes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps characterize the nature of the disrupted genomic features (e.g., protein_coding vs lincRNA).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Critical for structural variant analysis to provide gnomAD structural-variant allele frequencies to filter common variants.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs/structural variants to identify if the gene disruption affects dosage-sensitive regions (pHaplo).
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to help localize the disruption within the gene structure.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for small-scale nucleotide changes; not the priority for large-scale CNV top-line calls.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is for missense variants; it is NOT APPLICABLE for structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts effects of amino acid substitutions; it is NOT APPLICABLE for structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts effects of amino acid substitutions; it is NOT APPLICABLE for structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is designed for single nucleotide/small indel pathogenicity; it is NOT APPLICABLE for structural variants.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While the user wants a "top-line" call, disabling `most_severe` allows the user to see the specific transcripts involved in the disruption rather than a single collapsed term.
✗ summary [source: summary] confidence: medium
  Reason: The user needs to know *which* genes are disrupted; `summary` provides too little detail for structural interpretation.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --core_type --symbol --biotype --gnomad_sv --dosage_sensitivity --numbers --plugin DosageSensitivity,/path/to/plugin/
```
*Note: The `--gnomad_sv` option requires a custom VCF file from gnomAD SV. The `--dosage_sensitivity` option requires the ClinGen/Collins rCNV plugin. On the Ensembl web interface, select "Symbol", "Biotype", "Transcript numbering", and use the "Dosage Sensitivity" and "gnomAD SV" plugins/custom datasets.*
