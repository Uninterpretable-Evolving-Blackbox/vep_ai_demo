# VEP Recommendation

**Date:** 2026-09-10T00:17:31.837597

## User Query
I am working with whole exome sequencing data from a cohort of zebrafish tumor models where I have identified several somatic SNVs and small indels by comparing the tumor DNA to matched germline samples. My primary goal is to identify which of these mutations in the protein-coding regions are likely to be pathogenic, so I need a way to assess their potential impact on the amino acid sequence and overall protein function to help prioritize candidate driver mutations for further study.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (zebrafish)
- **origin**: somatic (tumor DNA vs. matched germline)
- **variant_size_class**: small (SNVs and small indels)
- **region_focus**: coding (protein-coding regions)
- **analysis_goal**: clinical-interpretation (identifying pathogenic driver mutations)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to drive the consequence calculation using the Ensembl/GENCODE annotation set.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make results more interpretable for prioritizing driver genes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Essential for providing standard nomenclature of the coding changes for downstream validation.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides transcript context (e.g., protein_coding) to ensure focus remains on coding regions.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds overlapping protein domain information (Pfam, etc.), crucial for assessing if a mutation hits a functional site.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to precisely locate the variant within the coding sequence.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Zebrafish has SIFT data available to predict the impact of amino acid substitutions on protein function.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Useful for small indels near splice sites to assess potential splicing disruption in the coding context.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations for genes to help link mutations to the observed tumor phenotype.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these somatic variants have been previously reported in zebrafish databases.
✓ coding_only [source: coding_only, priority=optional] confidence: medium
  Reason: Can be used to restrict output to coding consequences to reduce noise, as per the region_focus.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Helps predict if premature stop codons will lead to nonsense-mediated decay.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool and is not applicable to zebrafish.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only resource.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar data is human-only.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is a human-only database.
✗ most_severe [source: most_severe] confidence: high
  Reason: Should be disabled to allow full transcript-level detail required for somatic driver interpretation.
✗ summary [source: summary] confidence: high
  Reason: Should be disabled to retain detailed annotations rather than a collapsed view.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --everything --symbol --hgvs --protein --biotype --canonical --domains --numbers --sift --maxentscan --phenotypes --check_existing --coding_only --plugin NMD
```
*Note: In the web interface, ensure you select the zebrafish species and manually deselect any human-specific plugins like PolyPhen or CADD.*
