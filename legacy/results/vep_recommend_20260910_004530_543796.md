### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard for high-quality consequence calculation in humans.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is NOT APPLICABLE for structural variants/CNVs in this context and conflicts with summary/most_severe settings.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Transcript Support Level (TSL) helps rank the quality of the transcripts being hit by the CNV.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: LOEUF scores provide crucial context regarding the intolerance of a gene to loss-of-function variants, which is highly relevant for CNV analysis.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adding HGNC gene symbols is essential for making the output human-readable and biologically interpretable.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to meet the user's requirement to analyze regulatory-noncoding regions.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly recommended for CNV analysis as it provides gene-level dosage sensitivity scores (e.g., pHaplo) from the Collins rCNV catalogue.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish if the CNV hits a protein-coding gene, a lincRNA, or a regulatory element.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for structural variant analysis to compare input CNVs against known population structural variant frequencies in gnomAD.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is helpful for understanding the genomic context of the variant.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While the user wants "primary" consequences, enabling `--most_severe` can conflict with several useful annotation flags (like `--symbol` or `--tsl`) in some VEP versions; it is better to see the full context for CNVs.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: NOT APPLICABLE as dbNSFP is optimized for single nucleotide missense variants, not structural/CNV analysis.
✗ spliceai [source: spliceai] confidence: high
  Reason: NOT APPLICABLE as this is a tool for predicting splice-site alterations from SNVs/indels, not large-scale CNVs.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --assembly GRCh38 --symbol --tsl --biotype --regulatory --dosage_sensitivity --loeuf --numbers --custom <gnomAD_SV_VCF>,type=exact,overlap_cutoff=exact
```
*Note: The `--custom` flag requires the path to a gnomAD SV VCF file. On the Ensembl Web Interface, ensure "Regulatory" and "Dosage Sensitivity" are checked under the plugin/annotation sections.*
