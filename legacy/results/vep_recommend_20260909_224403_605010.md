## User Query
I have human somatic tumor WES/WGS data containing structural variants and CNVs. I want to identify protein-coding consequences, clinical pathogenicity, and population allele frequency context.

## Recommendation
### 1. Detected Scenario
- **species**: human (explicitly stated)
- **origin**: somatic (tumor data)
- **variant_size_class**: structural-CNV (structural variants and CNVs mentioned)
- **region_focus**: coding (identify protein-coding consequences)
- **analysis_goal**: clinical-interpretation (clinical pathogenicity) and population-frequency (population allele frequency context)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is recommended for driving consequence calculations in human studies.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making the results much more human-readable for clinical interpretation.

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level (TSL) to help prioritize high-quality, well-supported transcripts.

✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Provides APPRIS isoform annotation to identify functionally important transcripts.

✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores, which are essential for assessing the constraint of genes in the context of population frequency.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly critical for CNVs/Structural Variants to assess the impact of gene dosage changes via the pHaplo/pLI scores.

✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Identifies MANE Select transcripts, ensuring clinical focus on standardized, high-confidence transcripts.

✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Connects variants to phenotype associations, aiding clinical interpretation.

✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: Provides a combined deleteriousness score, useful for prioritizing variants during clinical analysis.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds transcript biotype, helping to confirm if the variant affects protein-coding genes.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is essential for describing the location of the structural change in coding regions.

✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Directly provides clinical significance (e.g., pathogenic) from ClinVar for clinical interpretation.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically addresses the structural variant/CNV aspect by providing allele frequencies from gnomAD SV datasets.

✓ mastermind [source: mastermind, priority=recommended] confidence: high
  Reason: Links variants to clinical evidence cited in medical literature.

✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Required to enable ClinVar and other frequency/ID-based checks.

✓ pubmed [source: pubmed, priority=optional] confidence: medium
  Reason: Optional add-on to provide literature links for clinical evidence.

✓ go [source: go, priority=optional] confidence: medium
  Reason: Optional add-on to provide biological context through Gene Ontology terms.

✗ hgvs [source: hgvs] confidence: high
  Reason: Disabled due to conflict with the `--symbol` and `--most_severe` flags/summary logic if applied; however, primarily because many clinical pipelines prefer standardized VEP output over raw HGVS strings if symbol/protein info is already present. (Note: Conflicts are prioritized in the logic).

✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because it conflicts with many of the recommended descriptive flags like `--symbol`, `--tsl`, and `--appris`.

✗ coding_only [source: coding_only] confidence: high
  Reason: Though the focus is coding, structural variants/CNVs often require looking at broader contexts to understand the full impact on the locus; however, if the user strictly wants coding output, this could be enabled. Given the "CNV" nature, it is safer to see all consequences.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Not applicable as the primary goal is CNV/SV and clinical significance, rather than missense-specific scores like SIFT/Polyphen.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --check_existing --symbol --tsl --appris --plugin LOEUF --plugin Mastermind --plugin DosageSensitivity --clinvar --mane --plugin Phenotypes --plugin CADD --biotype --numbers --custom gnomad_sv,gnomAD_SV_VCF.vcf,type=exact --pubmed --plugin GO
```
*Note: For the web interface, enable "Gene Symbol", "Transcript Support Level", "APPRIS", "LOEUF", "ClinVar", "MANE Select", "Dosage Sensitivity", and upload the gnomAD SV custom file.*
