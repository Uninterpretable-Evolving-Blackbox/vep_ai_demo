# VEP Recommendation

**Date:** 2026-09-09T22:36:40.855062

## User Query
I have somatic SNVs and indels from a mouse tumor. I need to identify the functional impact of both coding and regulatory variants for a preliminary pathogenicity assessment.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (functional impact of both)
- **analysis_goal**: clinical-interpretation (pathogenicity assessment)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to drive consequence calculation using the Ensembl/GENCODE core annotation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is critical for interpreting functional impact in a clinical/pathogenicity context.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature, essential for standardized reporting of coding and non-coding variants.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with regulatory regions (promoters, enhancers, etc.) as requested.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides context on the type of feature hit (e.g., protein_coding vs lincRNA), helping assess functional relevance.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is vital for assessing the impact of coding variants on protein function.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for pathogenicity assessment.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), linking coding variants to protein-level changes.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Since the species is mouse and SIFT data is available for species with variation data, it provides a sequence-based prediction of missense impact.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for splice sites, necessary for assessing the impact of indels/SNVs near boundaries.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations to aid in the assessment of functional/pathogenic relevance.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these somatic variants overlap with known mouse variation data.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is essential for localizing the variant within the gene structure.
✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Helps assess if a premature termination codon is likely to trigger nonsense-mediated decay.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is human-only data and is NOT APPLICABLE to a mouse scenario.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: gnomAD is human-only and is NOT APPLICABLE.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is human-only and is NOT APPLICABLE.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is human-only and is NOT APPLICABLE.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with recommended options like hgvs, symbol, and sift. For pathogenicity assessment, you need full per-transcript detail rather than a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with the need for detailed functional annotations.

### 3. Generated VEP Command
```
vep --input_file somatic_mouse.vcf --output_file somatic_mouse_annotated.txt --cache --format vcf --vcf --symbol --hgvs --regulatory --biotype --domains --canonical --protein --sift --maxentscan --phenotypes --check_existing --numbers --plugin NMD
```
*Note: Web interface users should select the corresponding checkboxes for Symbol, HGVS, Regulatory, Biotype, Domains, Canonical, Protein, SIFT, MaxEntScan, Phenotypes, and NMD.*
