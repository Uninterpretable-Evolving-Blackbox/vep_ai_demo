### 2. Recommended Options
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Provides APPRIS isoform annotation to identify functionally important transcripts, which is vital for clinical interpretation of coding changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the transcript biotype, helping to confirm if the variant affects protein-coding genes.
✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: Integrates CADD scores to help predict the deleteriousness of variants, aiding clinical pathogenicity assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Required to enable ClinVar and population frequency lookups by checking for co-located known variants.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance (e.g., pathogenic/benign) which is central to the user's clinical assessment goal.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the standard Ensembl/GENCODE annotation set to drive consequence calculations.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Essential for CNVs/structural variants to assess how gene dosage sensitivity (e.g., pHaplo) impacts pathogenicity.
✓ frequency [source: frequency, priority=recommended] confidence: high
  Reason: Enables frequency-based filtering and context, necessary for the user's population frequency goal.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically provides allele frequencies for structural variants from gnomAD, which is the primary variant class in this scenario.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Flags MANE transcripts, providing high-confidence, standardized transcript identifiers for clinical diagnostic certainty.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon/intron numbering, which is helpful for describing the exact location of structural disruptions.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to make the output human-readable for clinical reports.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help prioritize the most well-supported transcripts.
✗ af_gnomade [source: af_gnomade] confidence: high
  Reason: Specifically for exome populations; since this is WGS/CNV focused, standard frequency/gnomad_sv is more appropriate.
✗ hgvs [source: hgvs] confidence: high
  Reason: Conflicts with the goal of providing a streamlined consequence-based output and is often used for small variants rather than CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with several recommended functional and transcript-level flags (symbol, tsl, etc.).
✗ spliceai [source: spliceai] confidence: high
  Reason: Primarily designed for small-scale splice-site variants rather than large-scale structural variants/CNVs.
