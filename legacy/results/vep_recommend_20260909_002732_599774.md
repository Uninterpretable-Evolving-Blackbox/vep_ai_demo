### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard for high-quality consequence calculation.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is generally used for small variants (SNVs/Indels); it is not applicable for structural-CNV analysis in this context.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Transcript Support Level (TSL) helps rank the quality of the transcripts being annotated, which is essential for reliable consequence assessment.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: LOEUF scores provide critical context regarding the constraint of a gene to loss-of-function variants, aiding in interpreting CNV impact.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adding HGNC gene symbols makes the output human-readable and facilitates quick biological interpretation.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: The user specifically requested analysis of regulatory regions; this enables overlap with promoters, enhancers, and CTCF sites.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly critical for CNV/structural variant analysis to identify genes sensitive to changes in copy number (e.g., pHaplo).
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for distinguishing between protein-coding, non-coding, and regulatory feature types.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is necessary for describing the location of the structural disruption.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for CNV analysis to compare input structural variants against known population-level structural variation frequencies in gnomAD.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a resource for missense (SNV) functional predictions and is not applicable to structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT is designed for amino acid substitutions in single nucleotide variants, not for structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is designed for amino acid substitutions in single nucleotide variants, not for structural variants.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --assembly GRCh38 \
--symbol --tsl --biotype --numbers --regulatory --plugin DosageSensitivity \
--plugin LOEUF --custom gnomad_sv,gnomad_sv.vcf.gz,exact
```
*Note: The `--custom` flag for `gnomad_sv` requires a path to a local gnomAD SV VCF file. On the Ensembl Web Interface, these would be selected via the "Plugins" and "Custom Data" sections.*
