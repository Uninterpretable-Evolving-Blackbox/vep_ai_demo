### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps categorize the type of gene/transcript being affected (e.g., protein_coding), which is essential for a top-line summary of gene disruption.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps the user identify if the disruption hits the primary transcript used for most functional annotations.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for defining the base annotation set (Ensembl/GENCODE) used to calculate consequences.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNV analysis to determine if the loss or gain of a gene is known to cause disease due to dosage sensitivity.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Provides context for structural variants by comparing them to known structural variation frequencies in gnomAD.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which helps in understanding the scale of the disruption within a gene.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides HGNC gene symbols, making the "top-line" output human-readable and useful for quick identification.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help judge the reliability of the annotated transcripts.
✗ most_severe [source: most_severe] confidence: high
  Reason: While the user wants a "top-line" call, --most_severe often conflicts with other useful descriptive flags and can over-simplify the output in a way that obscures the specific nature of the CNV disruption.
✗ hgvs [source: hgvs] confidence: high
  Reason: The user specifically requested to avoid an exhaustive breakdown of small-scale nucleotide changes.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is for missense SNVs; it is NOT APPLICABLE for structural-CNV analysis.
✗ regulatory [source: regulatory] confidence: high
  Reason: The user specifically focused the analysis on protein-coding genes.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, for CNVs, it is often better to see the full context of the structural change rather than strictly filtering for coding-only consequences.
✗ lofeu [source: lofeu] confidence: high
  Reason: LOEUF is primarily used for assessing the impact of loss-of-function SNVs/indels, not typically for large-scale CNV structural analysis.
