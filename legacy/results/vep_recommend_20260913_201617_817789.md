## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation
### 1. Detected Scenario
- **species**: human (stated "human somatic")
- **origin**: somatic (stated "tumor biopsies")
- **variant_size_class**: structural-CNV (stated "structural variants and copy number alterations")
- **region_focus**: coding (stated "protein-coding genes")
- **analysis_goal**: basic-consequence (stated "quick top-line call on which... genes are being disrupted")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to provide the base transcript/gene annotation driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Necessary to identify the gene names (e.g., BRCA1) being disrupted, which is your primary goal.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps confirm if the disrupted regions are protein_coding or other features.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variants to check if the CNV is a common population variant or potentially somatic/rare.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs/structural variants to identify if the gene is sensitive to changes in copy number (e.g., pHaplo).
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron context for the disruption.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help gauge the quality of the annotated transcripts.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for small-scale nucleotide changes (SNVs/Indels), which you explicitly want to skip.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This plugin is for missense variants; it is not applicable to structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts effects of amino acid substitutions; not applicable to large-scale structural changes.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts effects of amino acid substitutions; not applicable to large-scale structural changes.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is designed for small-scale variants; not applicable to CNVs/SVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: You want to see which genes are disrupted; collapsing to a "most severe" consequence might hide the specific nature of the genomic disruption.
✗ summary [source: summary] confidence: medium
  Reason: While you want a "top-line" call, the summary mode often removes the very gene/biotype details you need to identify the disrupted genes.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --gnomad_sv --dosage_sensitivity --numbers --tsl --core_type merged
```
*Note: The `--gnomad_sv` option requires a custom VCF file for the gnomAD SV dataset. On the Ensembl Web Interface, these correspond to the 'Gene Symbol', 'Transcript Biotype', 'gnomAD SV', 'Dosage Sensitivity', 'Exon/Intron Numbering', and 'TSL' checkboxes.*
