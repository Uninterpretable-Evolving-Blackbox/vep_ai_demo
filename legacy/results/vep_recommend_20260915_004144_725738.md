## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (coding and regulatory variants)
- **analysis_goal**: clinical-interpretation (preliminary pathogenicity assessment)

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps categorize the functional nature of the affected transcripts or regulatory features (e.g., protein_coding, lincRNA).
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to prioritize effects on the primary, most well-supported transcript for a gene.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for somatic studies to see if the variant has been previously cataloged in other databases.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Defines the fundamental annotation set (Ensembl/GENCODE) driving the consequence calculation.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information, which is critical for assessing the functional impact of coding mutations.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard nomenclature (e.g., p.Arg50Gly) which is required for formal pathogenicity reporting.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: A sequence-based tool to predict splice-site alterations, vital for assessing the impact of indels and SNVs in coding/splicing regions.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering context, which is essential for describing the variant's location.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: medium
  Reason: Links variants to known phenotype associations for the genes involved, aiding pathogenicity assessment.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Directly addresses the user's need to analyze regulatory and non-coding elements.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Predicts the impact of missense substitutions based on sequence homology, which is supported for this species.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the clinical interpretation of gene-level effects much easier.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: NOT APPLICABLE; gnomAD is human-only.
✗ cadd [source: cadd] confidence: high
  Reason: NOT APPLICABLE; CADD is human-only.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar data is human-only.
✗ polyphen [source: polyphen] confidence: high
  Reason: NOT APPLICABLE; PolyPhen is human-only.
✗ most_severe [source: most_severe] confidence: high
  Reason: Enabling this would conflict with several recommended options like --hgvs, --symbol, and --sift.

### 3. Generated VEP Command
