## User Query
I have human somatic tumor WES/WGS data containing structural variants and CNVs. I want to identify protein-coding consequences, clinical pathogenicity, and population allele frequency context.

## Recommendation

- **species**: human (explicitly stated)
- **origin**: somatic (tumor data mentioned)
- **variant_size_class**: structural-CNV (explicitly stated)
- **region_focus**: coding (aiming for "protein-coding consequences")
- **analysis_goal**: clinical-interpretation, population-frequency (aiming for "clinical pathogenicity" and "population allele frequency context")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard for determining consequences in human coding regions.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to map variants to HGNC gene symbols (e.g., TP53).

✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Provides Transcript Support Level to help prioritize high-confidence transcripts for clinical reporting.

✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify functionally important isoforms, which is critical when assessing the impact of CNVs on specific protein products.

✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Provides MANE Select/Plus flags to ensure clinical interpretation is aligned with standardized NCBI/Ensembl transcripts.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly critical for CNV analysis; identifies genes where copy number changes are known to cause disease (pHaplo/pCNV).

✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores to assess the constraint of genes, helping distinguish driver somatic events from background variation.

✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: Provides a combined deleteriousness score to assist in predicting the impact of variants.

✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Directly supports the clinical-interpretation goal by linking variants to known phenotypic associations.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Confirms the functional class of the affected transcript (e.g., protein_coding).

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which is vital for describing the exact location of a structural variant's breakpoint.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for the population-frequency goal specifically for structural variants, using the gnomAD SV database.

✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Directly addresses the clinical-interpretation goal by providing known clinical significance.

✓ mastermind [source: mastermind, priority=recommended] confidence: high
  Reason: Adds clinical evidence from medical literature, supporting the pathogenicity assessment.

✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Required as a dependency to pull ClinVar and other frequency-based/literature-based data.

✓ pubmed [source: pubmed, priority=optional] confidence: medium
  Reason: Provides supporting literature for clinical interpretation.

✓ go [source: go, priority=optional] confidence: medium
  Reason: Adds biological context via Gene Ontology, which can aid in interpreting the functional impact of a CNV.

✗ hgvs [source: hgvs] confidence: high
  Reason: Disabled due to conflicts with --most_severe and --summary; additionally, HGVS nomenclature for complex SVs is often less informative in standard VEP output than manual description.

✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled because it conflicts with several recommended functional and clinical annotation flags (symbol, tsl, mane, etc.).

✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, structural variants/CNVs often have breakpoints in non-coding regions that affect coding genes (e.g., promoter deletions); restricting to coding-only might miss the mechanism of action.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Primarily used for missense single nucleotide variants; less relevant for the primary focus of CNV/Structural variants.

✗ spliceai [source: spliceai] confidence: high
  Reason: Targeted at single nucleotide variants affecting splicing; less applicable to large-scale CNVs.

### 3. Generated VEP Command
```
vep --input_file somatic_variants.vcf --output_file somatic_annotated.txt --cache --plugin DosageSensitivity --plugin LOEUF --plugin Mastermind --plugin Phenotypes --plugin CADD --plugin gnomad_sv --custom gnomad_sv.vcf,type=exact,overlap_cutoff=exact --check_existing --clinvar --pubmed --symbol --tsl --appris --mane --biotype --numbers --go
```
*Note: When using the web interface, ensure you select the appropriate plugins for Dosage Sensitivity and gnomAD SV via the custom/plugin upload sections.*
