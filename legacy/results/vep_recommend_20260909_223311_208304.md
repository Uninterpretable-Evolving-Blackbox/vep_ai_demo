### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --dir_cache <path_to_cache> --plugin DosageSensitivity --plugin LOEUF --custom <path_to_gnomAD_SV.vcf>,type=exact,overlap_cutoff=80 --symbol --tsl --biotype --regulatory --frequency --numbers
```

*Note: The `--custom` flag for gnomAD_SV requires a path to the local gnomAD SV VCF file. On the Ensembl Web Interface, ensure "Regulatory" and "Dosage Sensitivity" plugins are selected.*
