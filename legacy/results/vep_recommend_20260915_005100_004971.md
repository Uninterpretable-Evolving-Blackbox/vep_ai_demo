### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Provides the essential Ensembl/GENCODE transcript/gene annotation set required for all consequence calculations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to make results human-readable and easier for clinical reporting.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Identifies the type of gene/transcript affected (e.g., protein_coding), helping to confirm coding consequences.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs to identify if the affected genes are sensitive to dosage changes (e.g., pHaplo scores).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Provides gnomAD structural-variant allele frequencies to distinguish somatic events from common germline CNVs.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to identify if the affected genomic region/gene has known pathogenic associations.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Necessary to link the input variants to known clinical or population databases.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps with clinical interpretation by linking genes to known disease or phenotype associations.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is useful for localizing the impact of the structural event.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize high-confidence transcripts during clinical review.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Helps identify functionally important isoforms, which is critical when interpreting structural impacts on coding regions.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Uses MANE Select/Plus Clinical flags to ensure clinical interpretation is based on the standardized, high-confidence transcript.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript to streamline the prioritization of consequences.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is typically used for small variants (SNVs/indels); it is not applicable for structural/CNV analysis.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, structural variants often have flanking effects or regulatory implications that should not be strictly masked.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a resource for missense SNVs; it is NOT APPLICABLE for structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for SNVs; it is NOT APPLICABLE for structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for SNVs; it is NOT APPLICABLE for structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are primarily designed for single nucleotide variants; not applicable for CNVs.
✗ most_severe [source: most_severe] confidence: high
  Reason: For clinical CNV analysis, you need the full transcript-level detail of which genes are hit, not a single collapsed consequence.
✗ summary [source: summary] confidence: high
  Reason: A summary view hides the detailed transcript/gene information required for clinical validation of CNVs.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --everything --plugin DosageSensitivity --plugin gnomad_sv --plugin Phenotypes --symbol --biotype --mane --canonical --appris --tsl --numbers --clinvar --check_existing
```
*Note: The `--everything` flag is a shorthand used in some versions, but for clarity, the specific plugins and flags above are recommended. In the web interface, ensure "Dosage Sensitivity", "gnomAD SV", and "Phenotypes" are checked under the Plugins section.*
