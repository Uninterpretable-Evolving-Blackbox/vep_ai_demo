### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to choose the transcript/gene annotation set that drives consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results far more human-readable for clinical reports.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides transcript biotype context (e.g., protein_coding) to help identify coding consequences.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Critical for structural variants to provide gnomAD structural-variant allele frequencies to filter common variants.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Provides per-gene dosage sensitivity scores (e.g., pHaplo) which are vital for interpreting the impact of CNVs/structural variants.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to report known pathogenic/benign clinical significance.
✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Required to enable the lookup of co-located known variants, which is a dependency for ClinVar and frequency data.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps clinical interpretation by retrieving phenotype associations for the affected genes.
✓ cadd [source: cadd, priority=recommended] confidence: high
  Reason: Provides an integrated deleteriousness score useful for prioritizing variants.
✓ mane [source: mane, priority=recommended] confidence: high
  Reason: Adds MANE Select/Plus Clinical flags to ensure alignment with standard clinical transcript sets.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help assess the reliability of the annotated transcripts.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for short variants; while useful, it is not the focus for structural/CNV analysis in this scenario.
✗ coding_only [source: coding_only] confidence: high
  Reason: Although the focus is coding, disabling this entirely might miss structural variants that have regulatory or boundary consequences.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this ensures you get full per-transcript detail, which is necessary for evaluating how a CNV/SV impacts different isoforms.
✗ summary [source: summary] confidence: high
  Reason: Disabling this is necessary to avoid losing detailed consequence and clinical annotation data.
✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide variants and is not applicable to structural variants/CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor and not applicable to structural variants/CNVs.
✗ spliceai [source: spliceai] confidence: high
  Reason: SpliceAI is designed for small indels/SNVs at splice sites and is not applicable to large-scale structural variants.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --everything --symbol --biotype --gnomad_sv <path_to_gnomad_sv.vcf> --plugin DosageSensitivity --plugin Phenotypes --plugin CADD --mane --tsl --check_existing --clinvar
```
*Note: On the Ensembl Web Interface, ensure you select "Human" as species, enable "Gene Symbol", "Transcript Biotype", "MANE Select", "ClinVar", and add the "Dosage Sensitivity" and "Phenotypes" plugins. For SVs, you must provide a custom gnomAD SV file via the "Custom" upload option.*
