- **region_focus**: coding (explicitly mentioned)
- **analysis_goal**: clinical-interpretation (requested assessment of functional pathogenicity)

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the transcript biotype (e.g., protein_coding), which is essential for verifying the coding nature of the hits.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, helping prioritize the most biologically relevant transcript for functional assessment.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for identifying if these germline variants have been previously recorded in databases.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the Ensembl core annotation set to drive consequence calculations, which is the standard for this species.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Provides names of overlapping protein domains (Pfam, etc.), which is crucial for assessing functional pathogenicity in coding regions.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature, which is standard for reporting protein-altering changes.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based modeling of splice sites to assess if indels/SNVs disrupt splicing, relevant for pathogenicity.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is necessary for precise clinical reporting of coding variants.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves phenotype associations for genes to provide biological context for the variant's potential impact.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), essential for linking nucleotide changes to protein-level effects.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides species-specific SIFT scores to predict the impact of amino acid substitutions on protein function.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make the output human/animal-researcher readable.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option conflicts with several recommended flags like --hgvs, --symbol, and --sift.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar data is human-only and not applicable to *Mus musculus*.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-centric meta-resource and not applicable here.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are human-only.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --protein --biotype --canonical --domains --numbers --sift --maxentscan --phenotypes --check_existing
```
