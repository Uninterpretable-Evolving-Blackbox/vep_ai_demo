## User Query
I am analyzing somatic SNVs and indels from a mouse tumor WES to quickly identify any high-impact protein-coding variants.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor WES)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (protein-coding variants)
- **analysis_goal**: basic-consequence (identify high-impact variants)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential for choosing the transcript/gene annotation set that drives consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, which is vital for identifying which genes are affected by somatic mutations.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature for coding variants, which is necessary for communicating variant effects.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for consequence assessment.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), useful for linking mutations to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides the transcript biotype to confirm the variant is indeed falling within a protein-coding context.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds overlapping protein domains (e.g., Pfam), helping to identify if a mutation hits a functional site.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon/intron numbering, providing necessary context for the location of the variant within the gene.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with recommended options like --symbol, --hgvs, and --protein. For somatic analysis, keeping per-transcript detail is better for driver interpretation.
✗ summary [source: summary] confidence: high
  Reason: Conflicts with recommended options. A summary output collapses detail that is needed to assess the impact of specific somatic mutations.
✗ clinvar [source: clinvar] confidence: high
  Reason: ClinVar is a human-only resource.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: gnomAD is a human-only resource.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a human-only resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a human-only tool.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --canonical --protein --biotype --domains --numbers
```
*Note: Web interface users should select "Gene Symbol", "HGVS nomenclature", "Canonical transcript", "Protein ID", "Transcript biotype", "Protein domains", and "Exon/intron numbering" in the optional settings.*
