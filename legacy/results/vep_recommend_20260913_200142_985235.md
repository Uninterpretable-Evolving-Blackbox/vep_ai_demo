### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to define the underlying transcript/gene annotation set for consequence calculation.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols to make the results human-readable and useful for interpretation.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps confirm if the CNV overlaps with protein-coding biotypes as requested.

✓ check_existing [source: check_existing, priority=optional] confidence: high
  Reason: Necessary to identify co-located known variants and provides the basis for ClinVar lookup.

✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically annotates structural variants with gnomAD SV allele frequencies to assess population prevalence.

✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs (deletions/duplications) to determine if the affected gene is sensitive to dosage changes (e.g., haploinsufficiency).

✓ clinvar [source: clinvar, priority=optional] confidence: high
  Reason: Useful for clinical context to see if the region/gene is associated with known pathogenic CNVs.

✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily used for single nucleotide variants/small indels and is not the focus for structural variant interpretation in this scenario.

✗ sift [source: sift] confidence: high
  Reason: SIFT is a missense predictor for single nucleotide substitutions; it is not applicable to structural variants (CNVs).

✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is a missense predictor for single nucleotide substitutions; it is not applicable to structural variants (CNVs).

✗ cadd [source: cadd] confidence: high
  Reason: CADD is designed for small variants (SNVs/indels) and does not provide relevant scoring for large-scale CNVs.

✗ most_severe [source: most_severe] confidence: high
  Reason: Disabling this ensures you see the full overlapping context of the CNV rather than just a single collapsed consequence.

✗ summary [source: summary] confidence: high
  Reason: You need detailed annotation of which genes/transcripts are affected, not a condensed summary.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --symbol --biotype --check_existing --clinvar --gnomad_sv --dosage_sensitivity --plugin DosageSensitivity,/path/to/plugin/
```
*Note: The `--gnomad_sv` option requires the gnomAD SV dataset to be present. In the Ensembl Web Interface, these correspond to selecting the "Symbol", "Biotype", "ClinVar", and "gnomAD SV" checkboxes.*
