## User Query
I am reviewing human germline whole genome sequencing for a patient with suspected large-scale chromosomal changes. I need to quickly identify the impact on genes and regulatory regions, as well as how common these variants are in the general population.

- **species**: human (stated "human")
- **origin**: germline (stated "germline whole genome sequencing")
- **variant_size_class**: structural-CNV (stated "large-scale chromosomal changes")
- **region_focus**: coding, regulatory-noncoding (stated "impact on genes and regulatory regions")
- **analysis_goal**: clinical-interpretation, population-frequency (stated "identify the impact... as well as how common these variants are")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Required to drive consequence calculation using Ensembl/GENCODE annotations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for clinical interpretation to map variants to HGNC gene symbols.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish if the CNV affects protein-coding genes, lincRNA, or other functional elements.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Necessary to assess the impact on promoters, enhancers, and other regulatory regions as requested.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically used to annotate structural variants with gnomAD SV allele frequencies to assess population prevalence.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNV analysis to determine if the affected genes are sensitive to changes in copy number (e.g., pHaplo scores).
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Recommended to identify if the structural variant is already catalogued in known databases.
✓ clinvar [source: clinvar, priority=recommended] confidence: high
  Reason: Provides clinical significance for the variant, aiding in the interpretation of whether the change is pathogenic.
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link the affected genes to known clinical phenotypes for the patient's suspected disorder.
✓ canonical [source: canonical, priority=recommended] confidence: medium
  Reason: Helps prioritize the most clinically relevant transcript for the affected gene.
✓ mane [source: mane, priority=recommended] confidence: medium
  Reason: Provides the MANE Select/Plus Clinical transcripts, ensuring consistency with clinical standards.
✓ tsl [source: tsl, priority=recommended] confidence: medium
  Reason: Provides Transcript Support Level to help assess the quality of the transcript being affected.
✓ numbers [source: numbers, priority=recommended] confidence: medium
  Reason: Provides exon/intron numbering which can be useful for characterizing the boundaries of the change.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature for small variants is not applicable to large-scale structural variants/CNVs.
✗ sift [source: sift] confidence: high
  Reason: Missense predictors like SIFT are designed for single nucleotide substitutions, not structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: Missense predictors like PolyPhen are not applicable to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are primarily optimized for small variants and are not suitable for CNV/structural analysis.
✗ most_severe [source: most_severe] confidence: high
  Reason: In clinical structural variant analysis, you need the full context of all affected genes/regions, not just a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: Detailed annotation is required for clinical review; a summary lacks the necessary depth for structural variants.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --core_type merged --symbol --biotype --regulatory --plugin gnomad_sv,/path/to/gnomad_sv.vcf.gz --plugin DosageSensitivity --check_existing --plugin ClinVar --plugin Phenotypes --canonical --mane --tsl --numbers
```
*Note: The `--plugin gnomad_sv` requires a local path to the gnomAD SV VCF. On the Ensembl Web Interface, these correspond to the 'Regulatory Build', 'gnomAD SV', and various clinical/phenotype plugins.*
