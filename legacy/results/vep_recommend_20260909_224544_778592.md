## User Query
I am analyzing human germline structural variants and CNVs from a WGS cohort and want to quickly identify the primary functional consequences across both protein-coding and regulatory regions.

## Recommendation
### 1. Detected Scenario
- **species**: human (explicitly stated)
- **origin**: germline (explicitly stated)
- **variant_size_class**: structural-CNV (explicitly stated)
- **region_focus**: coding, regulatory-noncoding (explicitly stated)
- **analysis_goal**: basic-consequence (goal is to identify primary functional consequences)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is standard for driving consequence calculation in human germline analysis.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results more human-readable for functional assessment.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides the transcript or regulatory feature type (e.g., protein_coding, enhancer), which is essential for distinguishing coding vs. regulatory hits.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Enables overlap with Ensembl's Regulatory Build to identify consequences in promoters, enhancers, and CTCF sites.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Specifically useful for CNVs/structural variants to identify if the affected genes are sensitive to dosage changes (e.g., pHaplo).
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Essential for structural variant analysis to provide population allele frequencies from gnomAD-SV, helping to filter common variants.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which helps localize the boundaries of the structural variants.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize higher-quality transcripts during consequence assessment.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Adds APPRIS isoform annotation to identify functionally important transcripts.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Adds gnomAD LOEUF scores to assess the evolutionary constraint of the genes being disrupted by CNVs.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for short variants (SNPs/indels) and is NOT APPLICABLE for structural-CNV class.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a resource for missense variant scores; it is NOT APPLICABLE for structural variants.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts the impact of amino acid substitutions; it is NOT APPLICABLE for structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts impact of amino acid substitutions; it is NOT APPLICABLE for structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD scores are designed for single nucleotide and small indel variants; it is NOT APPLICABLE for structural variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: The user wants to identify functional consequences across coding and regulatory regions; disabling `most_severe` allows for a full view of all overlapping consequences rather than a single collapsed term.
✗ summary [source: summary] confidence: high
  Reason: A summary output would hide the detailed regulatory and coding details requested for functional consequence identification.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --regulatory --dosage_sensitivity --custom gnomad_sv,gnomAD_SV_VCF,exact --numbers --tsl --appris --plugin LOEUF --core_type ensembl
```
*Note: The `--custom` flag requires the path to the gnomAD SV VCF file. In the web interface, enable "Gene Symbol", "Transcript Biotype", "Regulatory Build", "Dosage Sensitivity", "gnomAD SV", "Exon/Intron numbering", "TSL", "APPRIS", and "LOEUF".*
