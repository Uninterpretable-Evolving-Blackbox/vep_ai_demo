### 3. Generated VEP Command
```
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --symbol --tsl --regulatory --dosage_sensitivity --clinvar --mane --phenotypes --cadd --biotype --numbers --gnomad_sv /path/to/gnomad_sv.vcf.gz --check_existing --pubmed
```
*Note: On the Ensembl Web Interface, ensure you select "Human" as the species and check the boxes for "Regulatory regions", "Clinical significance", and "Transcript support level". For gnomAD SV, you may need to use the command line version as it requires a custom dataset upload/path.*
