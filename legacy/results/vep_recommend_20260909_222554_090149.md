### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential to confirm the transcript type (e.g., protein_coding) for the variants identified.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize variants by identifying if they hit the canonical transcript for a gene.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Ensures the use of the standard Ensembl/GENCODE annotation set to drive consequence calculation.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Useful for identifying if a variant overlaps known protein domains, helping assess functional impact.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standard nomenclature for the coding changes, which is crucial for reporting protein-altering variants.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon and intron numbering, which is vital for locating the variant within the coding structure.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP), allowing for direct linking to protein-level consequences.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds the gene symbol to the output, making the results readable and easy to interpret.
