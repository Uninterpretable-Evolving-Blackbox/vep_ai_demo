### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is recommended for driving consequence calculation in non-human species.

✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature based on Ensembl identifiers, which is essential for standardizing variant reporting in clinical contexts.

✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Directly addresses the goal of evaluating impact on regulatory regions (promoters, enhancers, etc.) for a species with a regulatory build.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize consequences by identifying the canonical transcript for each gene, useful for clinical interpretation.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the biotype of the feature, which is critical when focusing on non-coding/regulatory regions to distinguish between types of elements.

✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Provides sequence-based scoring for splice sites, which is useful for assessing the impact of indels/SNVs near exon-intron boundaries.

✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Retrieves overlapping phenotype associations, aiding the clinical interpretation of the variant's potential impact.

  Reason: NOT APPLICABLE; ClinVar is a human-specific clinical database.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: NOT APPLICABLE; this meta-resource aggregates human-specific functional annotations.

  Reason: Disabled to avoid conflict with the recommended `--hgvs` and `--biotype` flags, which provide more granular detail necessary for non-coding analysis.

✓ check_existing [source: check_existing] confidence: medium
  Reason: Optional but recommended to check if these somatic variants overlap with known variants in zebrafish datasets if available.

✓ go [source: go] confidence: low
