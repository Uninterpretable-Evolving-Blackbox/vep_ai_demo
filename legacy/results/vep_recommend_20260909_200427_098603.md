### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin DosageSensitivity --plugin Phenotypes --plugin CADD --custom gnomad_sv,gnomad_sv.vcf.gz,exact --check_existing --clinvar --symbol --biotype
```
*Note: The `--custom` flag requires a path to a gnomAD SV VCF file. For the web interface, ensure you select the "Dosage Sensitivity", "Phenotypes", "CADD", and "gnomAD SV" plugins/options.*
