## User Query
I have germline Mus musculus WES data; I need to identify protein-altering SNVs and indels in coding regions and assess their predicted functional pathogenicity.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (*Mus musculus*)
- **origin**: germline (explicitly stated)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (explicitly stated)
- **analysis_goal**: clinical-interpretation (identifying protein-altering variants and assessing pathogenicity)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to drive consequence calculation using the Ensembl/GENCODE annotation set.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make results more interpretable for identifying affected genes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides standardized HGVS nomenclature for coding variants, which is critical for clinical reporting.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link variants to protein-level changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps confirm the functional context of the transcripts being annotated.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, aiding in the prioritization of the most likely functional consequence.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds overlapping protein domain information (e.g., Pfam), which is vital for assessing the functional impact of protein-altering variants.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides species-specific SIFT scores for predicting the effect of amino acid substitutions in non-human species like mouse.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Essential for assessing the impact of indels and SNVs on splice sites, even within coding-focused studies.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering to precisely localize the variant within the coding structure.

  Reason: Retrieves phenotype associations for genes, helping to link variants to potential biological outcomes.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --plugin MaxEntScan --plugin Phenotypes --symbol --hgvs --protein --biotype --canonical --domains --sift --numbers --coding_only --check_existing
```
*Note: For the web interface, ensure you select the Mus musculus cache and enable the plugins listed above. Avoid any "Human-only" checkboxes in the settings.*
