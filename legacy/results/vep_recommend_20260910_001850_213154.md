## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation
### 1. Detected Scenario
- **species**: human (explicitly stated)
- **origin**: somatic (from tumor biopsies)
- **variant_size_class**: structural-CNV (identifying structural variants and copy number alterations)
- **region_focus**: coding (goal is to see which protein-coding genes are disrupted)
- **analysis_goal**: basic-consequence (wants a "quick top-line call" rather than exhaustive nucleotide-level detail)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Provides the essential Ensembl/GENCODE annotation required for all consequence calculations.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for a "top-line call" to quickly identify the affected genes by their HGNC symbols.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Allows the user to distinguish between protein-coding genes and other features disrupted by the CNVs.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variants to determine if the observed CNV is a common population variant or potentially relevant.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs/structural variants to assess if the gene loss/gain is likely to be pathogenic based on dosage sensitivity (e.g., pHaplo).
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these structural changes overlap with known variants in databases.
✗ hgvs [source: hgvs] confidence: high
  Reason: The user specifically requested to avoid exhaustive breakdown of small-scale nucleotide changes.
✗ sift [source: sift] confidence: high
  Reason: SIFT is for missense (single nucleotide) variants and is not applicable/useful for large structural/CNV changes.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is for missense variants and is not applicable to structural variations.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a per-base deleteriousness score and is not suitable for interpreting large-scale CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While the user wants a "top-line call," disabling this ensures they see the specific gene-level impact rather than a single collapsed term.
✗ summary [source: summary] confidence: medium
  Reason: A summary provides very little detail; the user needs to know *which* genes are hit, which is better served by symbol/biotype.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --gnomad_sv <path_to_gnomad_sv.vcf.gz> --plugin DosageSensitivity --check_existing
```
*Note: On the Ensembl VEP Web Interface, ensure you select "Human" as the species and check the boxes for Symbol, Biotype, and the gnomAD SV plugin if available. The DosageSensitivity option is typically accessed via the "Plugins" section.*
