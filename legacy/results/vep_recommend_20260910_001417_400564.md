**Date:** 2026-09-10T00:14:17.400899

## User Query
Mouse germline WGS, SNV and indel variants; rapid top-line functional annotation for protein-coding and regulatory regions.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (Mouse)
- **origin**: germline (WGS/germline variants)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding, regulatory-noncoding (explicitly requested)
- **analysis_goal**: basic-consequence (top-line functional annotation)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Provides the Ensembl/GENCODE core annotation driving consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output for easier functional identification.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds transcript/regulatory feature biotypes (e.g., protein_coding) to provide context.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Adds HGVS nomenclature for standardized variant reporting.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP) to link results to protein-level consequences.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Flags the canonical transcript to help prioritize the most biologically relevant consequence.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to identify overlaps with regulatory regions (promoters, enhancers) as requested.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds protein domain information (Pfam, etc.) to assess the impact of coding variants.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon/intron numbering to help localize the variant within the gene structure.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for checking if the mouse variants are already cataloged in Ensembl variation data.
✗ most_severe [source: most_severe] confidence: high
  Reason: Disabled to ensure detailed per-transcript information is available for both coding and regulatory hits.
✗ summary [source: summary] confidence: high
  Reason: Disabled to allow for full annotation rather than a collapsed summary.
✗ clinvar [source: clinvar] confidence: high
  Reason: Not applicable; ClinVar is a human-only database.
✗ af_gnomadg [source: af_gnomadg] confidence: high
  Reason: Not applicable; gnomAD is a human-only resource.
✗ polyphen [source: polyphen] confidence: high
  Reason: Not applicable; PolyPhen is a human-only tool.
✗ cadd [source: cadd] confidence: high
  Reason: Not applicable; CADD is a human-only resource.
✗ sift [source: sift] confidence: low
  Reason: While SIFT exists for some species, for a "rapid top-line" request in a non-human species, we prioritize core annotations over species-specific plugin dependencies unless requested.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --hgvs --protein --canonical --regulatory --domains --numbers --check_existing
```
*Note: On the Ensembl VEP web interface, select "Mouse" as the species and enable the corresponding checkboxes for Symbol, Biotype, HGVS, Protein, Canonical, Regulatory, Domains, Numbers, and Check existing.*
