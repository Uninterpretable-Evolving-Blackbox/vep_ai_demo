# VEP Recommendation

**Date:** 2026-09-15T00:19:06.305149

## User Query
I am analyzing somatic SNVs and indels from a mouse tumor WES to quickly identify any high-impact protein-coding variants.

## Recommendation
### 1. Detected Scenario
- **species**: non-human (mouse)
- **origin**: somatic (tumor WES)
- **variant_size_class**: small (SNVs and indels)
- **region_focus**: coding (protein-coding variants)
- **analysis_goal**: basic-consequence (quickly identify high-impact variants)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is recommended for driving consequence calculations in non-human species.

✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, which is essential for standardizing variant reporting in protein-coding analyses.

✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps identify if a variant hits a known functional protein domain, aiding in the assessment of "high-impact" variants.

✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to the output, making the results interpretable for biological analysis.

✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, which is critical for prioritizing the most biologically relevant consequence in coding regions.

✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds Ensembl protein identifiers (ENSP), allowing for direct linking to protein-level consequences.

✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Provides transcript biotypes, helping to confirm the variant is indeed hitting a protein-coding feature.

✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is standard for describing the position of variants within a gene.

✗ most_severe [source: most_severe] confidence: high
  Reason: While useful for "quick" identification, enabling this creates conflicts with `--hgvs`, `--symbol`, and `--protein`. It is better to see all consequences and filter manually or via post-processing to ensure full context.

✗ coding_only [source: coding_only] confidence: medium
  Reason: Although the focus is coding, keeping this disabled (default) is safer to ensure you don't miss variants that might have adjacent regulatory or splice impacts that lead to coding changes.

✗ frequency [source: frequency] confidence: high
  Reason: This is a human-only option for pre-filtering; not applicable for mouse.

✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: This is a human-only meta-resource; not applicable for mouse.

✗ clinvar [source: clinvar] confidence: high
  Reason: This is a human-only clinical database; not applicable for mouse.

✓ nmd [source: nmd, priority=optional] confidence: medium
  Reason: Since the goal is to identify high-impact variants, knowing if a premature stop codon escapes nonsense-mediated decay (NMD) is very helpful for assessing functional impact.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --hgvs --domains --canonical --protein --biotype --numbers --plugin NMD
```
*Note: On the Ensembl Web Interface, ensure "Gene Symbol", "HGVS", "Protein ID", and "Transcript Canonical" are checked. The `--plugin NMD` may require selecting it from the plugin menu.*
