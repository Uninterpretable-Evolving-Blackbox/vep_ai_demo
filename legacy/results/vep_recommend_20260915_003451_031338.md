## User Query
I am reviewing human germline exome results and need to see how common any identified large-scale DNA deletions or duplications are in the general population, specifically within protein-coding areas.

## Recommendation
### 1. Detected Scenario
- **species**: human ("human germline exome results")
- **origin**: germline ("germline exome results")
- **variant_size_class**: structural-CNV ("large-scale DNA deletions or duplications")
- **region_focus**: coding ("specifically within protein-coding areas")
- **analysis_goal**: population-frequency ("how common... in the general population")

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the transcript biotype (e.g., protein_coding), which is essential for characterizing coding regions.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript, helping prioritize the most relevant transcript for the CNV impact.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the Ensembl/GENCODE core annotation set to drive consequence calculation for human data.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Specifically annotates variants with per-gene dosage sensitivity scores (e.g., pHaplo), which is critical for interpreting CNVs.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Provides allele frequencies for structural variants from gnomAD, directly addressing the goal of determining how common these deletions/duplications are.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making the output human-readable and useful for clinical/research context.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is helpful for locating the exact position of the CNV within the gene.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level (TSL) to help assess the reliability of the transcripts being hit by the CNVs.
✓ loeuf [source: loeuf, priority=recommended] confidence: high
  Reason: Provides gnomAD LOEUF scores, which helps in assessing the constraint of the gene being affected by the CNV.
✓ appris [source: appris, priority=recommended] confidence: high
  Reason: Adds APPRIS isoform annotation to help identify functionally important transcripts in the coding region.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Enables the ability to check for co-located known variants, which is required for certain frequency plugins.
✓ frequency [source: frequency, priority=optional] confidence: medium
  Reason: Allows for frequency-based filtering/reporting to satisfy the population-frequency goal.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for small variants (SNVs/indels) and is not applicable to large-scale structural CNVs in this context.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, disabling this allows the user to see if a CNV has overlapping boundaries in non-coding regions, providing better context.
✗ most_severe [source: most_severe] confidence: high
  Reason: Conflicts with other useful descriptive flags like symbol and tsl.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: dbNSFP is a resource for missense SNVs; it is not applicable for structural CNVs.
✗ sift [source: sift] confidence: high
  Reason: SIFT is used for predicting the impact of amino acid substitutions (SNVs), not CNVs.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen is used for amino acid substitutions (SNVs), not CNVs.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --tsl --canonical --biotype --numbers --appris --dosage_sensitivity --gnomad_sv --loeuf --check_existing --frequency
```
*Note: On the Ensembl Web Interface, ensure you select the "dosage_sensitivity" plugin and "gnomAD SV" custom dataset from the plugin/custom section.*
