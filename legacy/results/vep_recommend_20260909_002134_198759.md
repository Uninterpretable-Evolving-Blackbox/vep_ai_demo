## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

## Recommendation
### 1. Detected Scenario
- **species**: human (explicitly stated "human")
- **origin**: somatic (explicitly stated "tumor biopsies")
- **variant_size_class**: structural-CNV (user mentions "structural variants and copy number alterations")
- **region_focus**: coding (user mentions "protein-coding genes")
- **analysis_goal**: basic-consequence (user asks for a "quick top-line call" on gene disruption rather than exhaustive nucleotide-level detail)

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Standard Ensembl/GENCODE core annotation is the required baseline for consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Essential for the user's goal of identifying which specific genes are being disrupted.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish between protein-coding genes and other genomic features being hit by CNVs.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Necessary to provide allele frequencies for structural variants to help filter out common population CNVs.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs as it provides scores (like pHaplo) indicating how sensitive a gene is to changes in copy number.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering which assists in describing the scale of the gene disruption.
✓ appris [source: appris, priority=recommended] confidence: medium
  Reason: Helps identify the most functionally important isoforms (principal isoforms) in the context of gene loss/gain.
✓ tsl [source: tsl, priority=recommended] confidence: medium
  Reason: Adds Transcript Support Level to help assess the quality of the gene models being disrupted.
✗ hgvs [source: hgvs] confidence: high
  Reason: User requested a top-line call on genes, not an exhaustive breakdown of small-scale nucleotide changes.
✗ sift [source: sift] confidence: high
  Reason: Missense predictors like SIFT are for single nucleotide variants (SNVs) and are not applicable to large structural/CNV changes.
✗ polyphen [source: polyphen] confidence: high
  Reason: Missense predictors like PolyPhen are not applicable to structural variants/CNVs.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is designed for small-scale variants and is not applicable to CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While the user wants a "top-line call," enabling `most_severe` conflicts with many useful annotations; it is better to provide the gene context.
✗ summary [source: summary] confidence: medium
  Reason: A summary mode might collapse too much information; the user needs to know *which* genes are hit.

### 3. Generated VEP Command
```bash
vep --input_file input.vcf --output_file output.txt --cache --format vcf --vcf --symbol --biotype --numbers --dosage_sensitivity --gnomad_sv /path/to/gnomad_sv.vcf.gz --appris --tsl
```
*Note: In the Ensembl Web Interface, ensure you select "Human" as the species and enable the "Dosage Sensitivity" plugin and "gnomAD SV" custom dataset.*
