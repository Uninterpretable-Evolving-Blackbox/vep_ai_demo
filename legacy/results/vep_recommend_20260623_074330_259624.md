# VEP Recommendation

**Date:** 2026-06-23T07:43:30.260070

## User Query
Prioritize rare protein-altering variants in a patient with a suspected Mendelian disorder.

## Recommendation
### 1. Detected Use Case
**Category:** `rare_disease_germline`
**Reason:** The user's goal is to identify causal variants in a clinical context (suspected Mendelian disorder). This requires focusing on the rarity of the variant (using population frequencies), the functional impact on protein structure/function (using pathogenicity predictors), and linking the variant to known disease phenotypes.

### 2. Recommended Options
✓ **transcript_set** [source: transcript_set, priority=critical] confidence: high
  Reason: Using a comprehensive or basic GENCODE set is essential for accurate annotation of coding regions in human clinical genetics.

✓ **mane_select** [source: mane_select, priority=critical] confidence: high
  Reason: Using MANE Select transcripts provides a single, standardized transcript per gene that is consistent between NCBI and EBI, which is the current gold standard for clinical reporting.

✓ **canonical** [source: canonical, priority=recommended] confidence: high
  Reason: Identifying canonical transcripts helps prioritize the most biologically relevant transcript for each gene.

✗ **pick** [source: pick] confidence: medium
  Reason: While `--pick` simplifies output, it is better to keep all transcripts initially so that if a variant hits a non-MANE transcript that is still highly damaging, it isn't hidden by the ranking system.

✗ **per_gene** [source: per_gene] confidence: high
  Reason: We need transcript-level details (like HGVS nomenclature) to evaluate the specific effect on the protein, rather than just the most severe effect for the gene.

✗ **most_severe** [source: most_severe] confidence: high
  Reason: This option is incompatible with the detailed pathogenicity predictors (SIFT, PolyPhen) and HGVS notation required for this analysis.

✗ **summary** [source: summary] confidence: high
  Reason: Summary mode collapses transcript-specific information, making it impossible to see the specific amino acid changes or transcript-specific impacts.

✓ **sift** [source: sift, priority=critical] confidence: high
  Reason: A standard tool for predicting whether a missense substitution affects protein function.

✓ **polyphen** [source: polyphen, priority=critical] confidence: high
  Reason: Provides essential structural/functional impact predictions for human amino acid substitutions.

✓ **cadd** [source: cadd, priority=recommended] confidence: high
  Reason: Provides an integrated score of deleteriousness, which is highly useful for ranking variants across different types of functional impacts.

✓ **alphamissense** [source: alphamissense, priority=recommended] confidence: high
  Reason: Uses advanced AI/Deep Learning to provide highly accurate classifications for missense pathogenicity.

✓ **revel** [source: revel, priority=optional] confidence: medium
  Reason: As an ensemble method, it provides a robust secondary layer of evidence for the pathogenicity of missense variants.

✓ **clinvar** [source: clinvar, priority=critical] confidence: high
  Reason: Essential to check if the variant is already documented in ClinVar as pathogenic or benign in other patients.

✓ **check_existing** [source: check_existing, priority=critical] confidence: high
  Reason: Necessary to retrieve existing IDs (like rsIDs) and link the variant to known clinical databases.

✓ **gnomad_af** [source: gnomad_af, priority=critical] confidence: high
  Reason: Crucial for filtering out common polymorphisms; Mendelian disease variants must be rare in the population.

✗ **af_1kg** [source: af_1kg] confidence: high
  Reason: gnomAD provides much more comprehensive and modern population frequency data for human populations than 1000 Genomes.

✗ **gnomad_sv** [source: gnomad_sv] confidence: medium
  Reason: The focus is on "protein-altering" (typically SNVs/Indels) rather than large structural variants.

✗ **clinvar_sv** [source: clinvar_sv] confidence: medium
  Reason: Not required unless specifically investigating large-scale structural rearrangements.

✗ **regulatory** [source: regulatory] confidence: high
  Reason: The user specified protein-altering variants; searching regulatory regions increases runtime without adding specific value to coding-centric analysis.

✓ **hgvs** [source: hgvs, priority=critical] confidence: high
  Reason: Provides the standard nomenclature required for clinical reporting and communicating results to clinicians.

✓ **symbol** [source: symbol, priority=recommended] confidence: high
  Reason: Makes the VCF output much more readable by replacing Ensembl IDs with HGNC gene symbols (e.g., BRCA1).

✗ **protein** [source: protein] confidence: medium
  Reason: While useful, the presence of HGVS and gene symbols is usually sufficient for standard clinical interpretation.

✓ **domains** [source: domains, priority=recommended] confidence: high
  Reason: Helps determine if a variant falls within a known functional or binding domain, adding biological context to the pathogenicity prediction.

✓ **gene_phenotype** [source: gene_phenotype, priority=recommended] confidence: high
  Reason: Crucial for linking a candidate gene to the patient's observed clinical phenotype (e.g., via OMIM).

✗ **spliceai** [source: spliceai] confidence: medium
  Reason: While useful for investigating cryptic splice sites, it is not strictly required unless the primary focus is on deep intronic/regulatory splicing variants.

✗ **maxentscan** [source: maxentscan] confidence: medium
  Reason: Not needed unless specifically performing a splice-site centric analysis.

### 3. Generated VEP Command
```bash
vep --input_file patient_variants.vcf --output_file annotated_variants.txt --cache \
--gencode_basic --mane_select --canonical \
--sift b --polyphen b --plugin CADD,snv=/path/to/SNVs.tsv.gz,indels=/path/to/InDels.tsv.gz \
--plugin AlphaMissense,file=/path/to/AlphaMissense_hg38.tsv.gz \
--plugin REVEL,file=/path/to/revel_scores.tsv.gz \
--check_existing --af_gnomade \
--hgvs --symbol --domains --gene_phenotype
```

*Note: The web interface equivalent would involve checking the boxes for SIFT, PolyPhen, CADD, AlphaMissense, ClinVar, gnomAD, and MANE Select.*
