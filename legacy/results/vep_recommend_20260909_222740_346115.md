### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --plugin DosageSensitivity --plugin Phenotypes --custom gnomAD_SV,vcf,exact,overlap_cutoff=80 --check_existing --clinvar --symbol --biotype --regulatory
```
*Note: The `--custom` flag requires a path to a gnomAD SV VCF file. On the Ensembl VEP Web Interface, ensure "Regulatory Build", "Gene Symbol", "Biotype", and "ClinVar" are selected, and use the "Plugins" section to add Dosage Sensitivity and Phenotypes.*
