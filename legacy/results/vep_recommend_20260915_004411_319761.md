### 3. Generated VEP Command
```
vep --input_file input.vcf --output_file output.txt --cache --format vcf --everything --symbol --hgvs --protein --biotype --canonical --domains --sift --maxentscan --phenotypes --check_existing --coding_only --plugin NMD
```
*Note: On the Ensembl Web Interface, ensure you select the correct species (Mus musculus) and check the corresponding boxes for Symbol, HGVS, Protein, Biotype, Canonical, Domains, SIFT, MaxEntScan, Phenotypes, and the NMD plugin. Do not select human-only plugins like ClinVar or PolyPhen.*
