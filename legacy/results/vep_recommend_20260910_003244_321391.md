## User Query
I am currently working through some sequencing results from a mouse model of cancer and I need to figure out how to properly annotate the list of changes we've identified in the tumor tissue. We are looking at single letter changes as well as small additions or removals of DNA, and it is really important for my analysis that I can see both the impact on protein-coding sequences and any potential effects on the control regions surrounding the genes. Ultimately, I need to be able to tell which of these changes look like they might actually be driving the tumor progression.

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Using the default Ensembl/GENCODE core annotation is the standard for driving consequence calculation in non-human species.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Essential for clinical-style interpretation to provide standardized nomenclature for the identified changes.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Helps identify if somatic mutations hit functional protein domains, which is critical for determining driver potential.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Provides gene symbols to make the list of identified changes interpretable for biological context.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Specifically requested to evaluate effects on "control regions" (promoters, enhancers, etc.).
✓ phenotypes [source: phenotypes, priority=recommended] confidence: high
  Reason: Helps link identified changes to known phenotype associations, aiding in the identification of driver mutations.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Helps prioritize the most biologically relevant transcript for each gene during interpretation.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Provides Ensembl protein identifiers (ENSP) to facilitate protein-level analysis of coding changes.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Distinguishes between coding genes and regulatory non-coding elements (e.g., lincRNA).
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, which is vital for precisely locating small indels and single-letter changes.
✓ sift [source: sift, priority=recommended] confidence: high
  Reason: Provides sequence-based prediction of whether missense mutations in the mouse model affect protein function.
✓ maxentscan [source: maxentscan, priority=recommended] confidence: high
  Reason: Essential for scoring the impact of variants on splice sites, which can be a mechanism for driver mutations.

  Reason: Disabled because it conflicts with several recommended options needed for detailed clinical-style interpretation (hgvs, symbol, sift, etc.).

  Reason: NOT APPLICABLE; gnomAD is a human-only database.
✗ clinvar [source: clinvar] confidence: high
  Reason: NOT APPLICABLE; ClinVar is a human-only database.

  Reason: NOT APPLICABLE; dbNSFP is a human-only resource.

### 3. Generated VEP Command
