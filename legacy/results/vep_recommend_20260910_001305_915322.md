### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to define the transcript/gene annotation set (Ensembl/GENCODE) for consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds HGNC gene symbols, making results much more human-readable.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Essential for distinguishing between protein-coding, lincRNA, and other regulatory features.
✓ regulatory [source: regulatory, priority=recommended] confidence: high
  Reason: Required to annotate overlaps with promoters, enhancers, and other regulatory elements.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Specifically provides allele frequencies for structural variants from gnomAD SV.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Crucial for CNV analysis to identify if genes are sensitive to copy number changes (e.g., pHaplo).
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Provides exon/intron numbering, helpful for localizing structural disruptions.
✓ tsl [source: tsl, priority=recommended] confidence: high
  Reason: Adds Transcript Support Level to help prioritize high-quality transcripts.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for identifying if the SVs overlap known short variants or specific IDs.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is primarily for short variants and is not applicable to structural-CNV.
✗ dbnsfp [source: dbnsfp] confidence: high
  Reason: Not applicable to structural variants; focuses on missense single nucleotide variants.
✗ sift [source: sift] confidence: high
  Reason: Missense predictors are not applicable to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: Missense predictors are not applicable to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: Missense/small indel predictors are not applicable to structural variants.
✗ most_severe [source: most_severe] confidence: high
  Reason: For SVs, you need to see all affected genes/features; collapsing to one consequence is counter-productive.
✗ summary [source: summary] confidence: high
  Reason: Detailed annotation of multiple affected features is needed rather than a collapsed summary.

### 3. Generated VEP Command
```bash
vep --input_file <input.vcf> --output_file <output.txt> --cache --format vcf --vcf --symbol --biotype --regulatory --gnomad_sv <path_to_gnomad_sv.vcf.gz> --plugin DosageSensitivity --numbers --tsl --check_existing
```
*Note: On the Ensembl Web Interface, ensure you select "human" and enable the "Regulatory" and "Structural Variant" related plugins/options.*
