## User Query
I am working with human somatic whole exome sequencing data from a series of tumor biopsies and have identified several structural variants and copy number alterations that I need to interpret. Since I am still learning the ropes of setting up my annotation pipeline, I was wondering how I should approach this if my primary goal is just to get a quick top-line call on which protein-coding genes are being disrupted or lost by these large genomic changes, without necessarily needing an exhaustive breakdown of every small-scale nucleotide change at this stage.

- **region_focus**: coding (Specified as "protein-coding genes")

### 2. Recommended Options
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Essential to provide the base Ensembl/GENCODE annotation driving the consequence calculation.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Necessary for a "top-line call" to identify which genes (e.g., BRCA1, TP53) are affected by the CNVs.
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Helps distinguish if the disrupted region is a protein-coding gene or another feature like a lincRNA.
✓ gnomad_sv [source: gnomad_sv, priority=recommended] confidence: high
  Reason: Crucial for structural variant analysis to filter out common population CNVs using gnomAD-SV frequencies.
✓ dosage_sensitivity [source: dosage_sensitivity, priority=recommended] confidence: high
  Reason: Highly relevant for CNVs; identifies if the gene is sensitive to changes in dosage (e.g., pHaplo scores).
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful to see if these large-scale changes overlap with known variants in databases.
✗ hgvs [source: hgvs] confidence: high
  Reason: HGVS nomenclature is for nucleotide/amino acid changes; not applicable/useful for large-scale CNVs in a "top-line" summary.
✗ sift [source: sift] confidence: high
  Reason: SIFT predicts the effect of single nucleotide missense substitutions; not applicable to structural variants.
✗ polyphen [source: polyphen] confidence: high
  Reason: PolyPhen predicts the effect of amino acid substitutions; not applicable to structural variants.
✗ cadd [source: cadd] confidence: high
  Reason: CADD is a scoring system for small-scale variants; not applicable to CNVs.
✗ most_severe [source: most_severe] confidence: medium
  Reason: While you want a "top-line" view, disabling this allows you to see the specific gene/biotype context rather than just a single collapsed term.
✗ summary [source: summary] confidence: medium
  Reason: You need the actual gene symbols and biotypes to make a "top-line call," which a summary mode might obscure.

### 3. Generated VEP Command
```
vep --input_file <input.vcf> --output_file <output.txt> --cache --symbol --biotype --dosage_sensitivity --gnomad_sv <path_to_gnomad_sv.vcf.gz> --check_existing
```
*Note: On the Ensembl Web Interface, ensure you select "Human" as the species, check the boxes for "Gene Symbol", "Transcript Biotype", "Dosage Sensitivity", and use the Custom Tool section to upload/reference gnomAD-SV data.*
