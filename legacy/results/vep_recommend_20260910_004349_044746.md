## User Query
I am currently reviewing exome sequencing results from a cohort of mice used in our recent developmental study. We have identified several single-letter changes and small additions or deletions throughout the genome. For my preliminary report, I just need to quickly identify which of these variations actually alter the protein sequence or create an early stop signal within the coding regions.

- **species**: non-human (mouse)

- **region_focus**: coding (interest is in "which of these variations actually alter the protein sequence")

### 2. Recommended Options
✓ biotype [source: biotype, priority=recommended] confidence: high
  Reason: Adds the biotype of the transcript, which helps confirm the functional category of the annotated features.
✓ canonical [source: canonical, priority=recommended] confidence: high
  Reason: Identifies the canonical transcript for each gene, helping to prioritize the most reliable protein-altering consequences.
✓ check_existing [source: check_existing, priority=optional] confidence: medium
  Reason: Useful for checking if these small variants are already known in mouse variation databases.
✓ core_type [source: core_type, priority=recommended] confidence: high
  Reason: Uses the standard Ensembl/GENCODE core annotation set to drive consequence calculations.
✓ domains [source: domains, priority=recommended] confidence: high
  Reason: Adds overlapping protein domain information, which is highly relevant for assessing the impact of protein-altering changes.
✓ hgvs [source: hgvs, priority=recommended] confidence: high
  Reason: Provides HGVS nomenclature, which is essential for reporting protein-altering changes and early stop signals.
✓ numbers [source: numbers, priority=recommended] confidence: high
  Reason: Adds exon and intron numbering, providing necessary context for the location of the coding changes.
✓ protein [source: protein, priority=recommended] confidence: high
  Reason: Adds the Ensembl protein identifier (ENSP), which is critical for tracking protein-level consequences.
✓ symbol [source: symbol, priority=recommended] confidence: high
  Reason: Adds gene symbols to make the output interpretable for a preliminary report.
✗ coding_only [source: coding_only] confidence: high
  Reason: While the focus is coding, the user asked to identify changes "throughout the genome" that *alter* coding regions; disabling this allows for seeing the context, but since the goal is high-level, it is not strictly required as a filter unless the user wants to prune non-coding noise. However, as a "basic-consequence" recommendation, it is better to provide the full context of the variant's location.
✗ most_severe [source: most_severe] confidence: high
  Reason: This option conflicts with `--hgvs`, `--symbol`, and `--protein`, which are required for the user's specific reporting needs.
✗ af_gnomad [source: af_gnomade] confidence: high
  Reason: Species is non-human; gnomAD is human-only.
✗ polyphen [source: polyphen] confidence: high
  Reason: Species is non-human; PolyPhen is human-only.
✗ cadd [source: cadd] confidence: high
  Reason: Species is non-human; CADD is human-only.
